# 学科点击无反应问题修复说明

## 问题描述 🔍
用户点击学科卡片没有反应，控制台显示localStorage SecurityError错误，导致整个点击事件失效。

## 错误信息 ❌
```
js: Uncaught SecurityError: Failed to read the 'localStorage' property from 'Window': Storage is disabled inside 'data:' URLs.
```

## 问题分析 📊

### 1. 根本原因
- **Qt WebEngine限制**：在Qt WebEngine中，当页面通过`data:` URL加载时，localStorage被禁用
- **错误传播**：localStorage访问失败导致JavaScript执行中断
- **事件阻塞**：未处理的异常阻止了后续的点击事件处理

### 2. 影响范围
- 所有需要localStorage的功能失效
- 学科选择功能完全无法使用
- 状态保存和恢复功能失效
- 用户无法进入脑图页面

### 3. 技术细节
```javascript
// 问题代码 ❌
localStorage.setItem('lastViewedSubject', subjectName);  // 抛出SecurityError

// 后续代码无法执行
document.getElementById('subjectSelectionPage').classList.add('hidden');
```

## 修复方案 ✅

### 1. localStorage安全访问机制

#### 1.1 添加安全检查
```javascript
// 修复前 ❌
localStorage.setItem('lastViewedSubject', subjectName);

// 修复后 ✅
try {
    if (typeof(Storage) !== "undefined" && window.localStorage) {
        localStorage.setItem('lastViewedSubject', subjectName);
        log(`💾 已保存当前学科状态: ${subjectName}`);
    }
} catch (error) {
    log(`⚠️ 无法保存学科状态: ${error.message}`);
}
```

#### 1.2 完整的安全包装函数
```javascript
function safeLocalStorageSet(key, value) {
    try {
        if (typeof(Storage) !== "undefined" && window.localStorage) {
            localStorage.setItem(key, value);
            return true;
        }
    } catch (error) {
        console.warn(`localStorage设置失败: ${error.message}`);
    }
    return false;
}

function safeLocalStorageGet(key) {
    try {
        if (typeof(Storage) !== "undefined" && window.localStorage) {
            return localStorage.getItem(key);
        }
    } catch (error) {
        console.warn(`localStorage读取失败: ${error.message}`);
    }
    return null;
}
```

```javascript
function restorePreviousMindmapState() {
    try {
        if (typeof(Storage) !== "undefined" && window.localStorage) {
            const lastViewedSubject = localStorage.getItem('lastViewedSubject');
            const lastViewedKnowledgePoint = localStorage.getItem('lastViewedKnowledgePoint');
            
            if (lastViewedSubject) {
                log(`🔄 恢复上次查看的学科: ${lastViewedSubject}`);
                setTimeout(() => {
                    selectSubject(lastViewedSubject);
                    
                    if (lastViewedKnowledgePoint) {
                        setTimeout(() => {
                            const nodeId = lastViewedKnowledgePoint;
                            log(`🔄 恢复上次查看的知识点: ${nodeId}`);
                            
                            if (currentMindmapData && currentMindmapData.nodes) {
                                const node = currentMindmapData.nodes.find(n => n.id === nodeId);
                                if (node) {
                                    showKnowledgePointDetail(node);
                                }
                            }
                        }, 1000);
                    }
                }, 500);
            }
        } else {
            log('⚠️ localStorage不可用，跳过状态恢复');
        }
    } catch (error) {
        log(`⚠️ localStorage访问失败: ${error.message}，跳过状态恢复`);
    }
}
```

```javascript
// 使用内存存储作为localStorage的替代
const memoryStorage = {
    data: {},
    setItem(key, value) {
        this.data[key] = value;
    },
    getItem(key) {
        return this.data[key] || null;
    },
    removeItem(key) {
        delete this.data[key];
    }
};

// 智能存储选择
function getStorage() {
    try {
        if (typeof(Storage) !== "undefined" && window.localStorage) {
            return localStorage;
        }
    } catch (error) {
        console.warn('localStorage不可用，使用内存存储');
    }
    return memoryStorage;
}
```
