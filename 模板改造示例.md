# 模板文件改造示例

## 改造要点

### 1. 移除QWebChannel相关代码

**改造前（Qt版本）**：
```html
<!-- 移除这些代码 -->
<script src="qrc:///qtwebchannel/qwebchannel.js"></script>
<script>
    new QWebChannel(qt.webChannelTransport, function(channel) {
        window.pybridge = channel.objects.bridge;
        console.log('WebChannel连接成功');
    });
</script>
```

**改造后（Flask版本）**：
```html
<!-- 添加API封装 -->
<script src="{{ url_for('static', filename='js/api.js') }}"></script>
<script>
    console.log('API模块加载完成');
</script>
```

### 2. 修改API调用方式

#### 示例1：提取知识点

**改造前（Qt版本）**：
```javascript
// Qt WebChannel方式
function extractKnowledge(text) {
    window.pybridge.extractKnowledgePoints(text, function(result) {
        const data = JSON.parse(result);
        console.log('提取结果:', data);
        displayKnowledgePoints(data);
    });
}
```

**改造后（Flask版本）**：
```javascript
// Fetch API方式（推荐）
async function extractKnowledge(text) {
    try {
        const data = await KnowledgeAPI.extract(text);
        console.log('提取结果:', data);
        displayKnowledgePoints(data);
    } catch (error) {
        console.error('提取失败:', error);
        alert('提取知识点失败: ' + error.message);
    }
}

// 或者使用兼容层（最小改造）
function extractKnowledge(text) {
    window.pybridge.extractKnowledgePoints(text, function(result) {
        const data = JSON.parse(result);
        console.log('提取结果:', data);
        displayKnowledgePoints(data);
    });
}
```

#### 示例2：保存文件

**改造前（Qt版本）**：
```javascript
function saveNote() {
    const content = editor.getValue();
    const path = currentFilePath;
    
    window.pybridge.saveFile(path, content, function(result) {
        const data = JSON.parse(result);
        if (data.success) {
            alert('保存成功');
        }
    });
}
```

**改造后（Flask版本）**：
```javascript
async function saveNote() {
    const content = editor.getValue();
    const path = currentFilePath;
    
    try {
        await FileAPI.save(path, content);
        alert('保存成功');
    } catch (error) {
        alert('保存失败: ' + error.message);
    }
}
```

## 改造策略选择

### 策略1：完全重写（推荐）
- **优点**：代码更现代化，使用async/await
- **缺点**：需要修改所有API调用
- **适用**：长期维护的项目

```javascript
// 新代码风格
async function handleAction() {
    try {
        const result = await API.method();
        processResult(result);
    } catch (error) {
        handleError(error);
    }
}
```

### 策略2：使用兼容层（最小改造）
- **优点**：改造量最小，只需添加api.js
- **缺点**：保留了回调风格
- **适用**：快速迁移

```javascript
// 保持原有代码不变
function handleAction() {
    window.pybridge.method(params, function(result) {
        processResult(result);
    });
}
```

### 策略3：渐进式改造
- **优点**：平滑过渡，风险低
- **缺点**：需要维护两套代码一段时间
- **适用**：大型项目

```javascript
// 同时支持两种方式
async function handleAction() {
    if (window.KnowledgeAPI) {
        // 新方式
        const result = await KnowledgeAPI.method();
    } else {
        // 旧方式（兼容）
        window.pybridge.method(params, callback);
    }
}
```

## 常见问题

### Q1: 为什么提供兼容层？
A: 为了最小化改造量。兼容层模拟了pybridge的接口，让大部分现有代码无需修改就能工作。

### Q2: 应该选择哪种改造策略？
A: 建议先使用兼容层快速迁移，然后逐步重写为async/await风格。

### Q3: 如何处理文件上传？
A: 使用FormData和fetch API，参考FileAPI.upload方法。

### Q4: 如何处理实时通信？
A: 可以使用WebSocket或Server-Sent Events，后续可以添加。
