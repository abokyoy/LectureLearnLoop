# LectureLearnLoop 主程序功能架构分析

## 概述

LectureLearnLoop 学习系统包含两个主要应用程序：

1. **overlay_drag_corgi_app.py** - 现代化主程序入口文件，采用 Qt6 + WebEngine 架构，实现了一个功能完整的学习助手应用。该文件包含 9537 行代码，是整个系统的核心控制器。

2. **app_qt.py** - 传统Qt桌面应用程序，专注于实时语音转写和文本处理功能。该文件包含 3020 行代码，提供丰富的文本编辑和AI对话功能。

## 系统架构概览

### 1. 核心架构模式
- **MVC 架构**：Model（数据层）+ View（WebEngine前端）+ Controller（Python后端）
- **桥接模式**：通过 `CorgiWebBridge` 实现 Python 与 JavaScript 的双向通信
- **单页应用（SPA）**：前端采用动态内容加载，无需页面刷新
- **模板系统**：使用 Jinja2 模板引擎实现前后端分离

### 2. 主要技术栈

#### overlay_drag_corgi_app.py (现代化应用)
- **后端框架**：PySide6 (Qt6 Python绑定)
- **前端引擎**：QWebEngineView (Chromium内核)
- **通信机制**：QWebChannel (JavaScript ↔ Python)
- **模板引擎**：Jinja2 + TemplateManager
- **UI框架**：Tailwind CSS + Material Icons
- **AI集成**：多LLM提供商支持（Ollama、Gemini、DeepSeek、Qwen）
- **音频处理**：PyAudio + Whisper/Faster-Whisper
- **数据存储**：SQLite + 文件系统

#### app_qt.py (传统Qt应用)
- **UI框架**：PySide6 QtWidgets (原生Qt组件)
- **文本处理**：QTextEdit + 自定义富文本编辑器
- **语法高亮**：QSyntaxHighlighter (Markdown支持)
- **多线程**：QThread + QObject (录音、转写、总结)
- **AI集成**：共享LLM提供商工厂
- **音频处理**：PyAudio + Whisper
- **配置管理**：共享config.py模块

### 3. 界面渲染机制

#### 重要说明：UI文件夹与实际界面的关系
- **UI/ 文件夹**：包含25个设计稿文件，仅用于设计参考，与实际项目无关
- **实际界面**：全部通过 `templates/` 目录下的模板文件渲染

#### 模板系统架构
```
templates/
├── base.html (204KB)           # 基础模板，包含CSS/JS框架
├── spa_layout.html (12KB)      # SPA布局模板
├── components/                 # 组件模板
│   ├── sidebar.html           # 菜单栏组件
│   └── header.html            # 头部组件
└── pages/ (18个文件)           # 页面模板
    ├── dashboard.html (4KB)           # 工作台
    ├── learn_from_materials.html (201KB)  # 资料学习
    ├── online_course_notes.html (314KB)   # 网课笔记
    ├── practice_materials.html (169KB)    # 练习脑图
    ├── settings.html (25KB)              # 系统设置
    └── ...                               # 其他功能页面
```

#### 界面渲染流程
1. **用户操作** → 点击菜单项
2. **前端JavaScript** → 调用 `handleMenuClick(content_id)`
3. **API调用** → `window.pybridge.loadContent(content_id)`
4. **后端处理** → `CorgiWebBridge.loadContent()`
5. **模板渲染** → `template_manager.render_page_content(content_id)`
6. **HTML生成** → Jinja2渲染对应模板文件
7. **前端显示** → 更新页面内容区域

## 关键设计模式

### 1. 桥接模式（Bridge Pattern）
- **实现**：CorgiWebBridge类
- **目的**：分离前端界面与后端逻辑
- **优势**：技术栈独立，易于维护

### 2. 工厂模式（Factory Pattern）
- **实现**：LLMProviderFactory
- **目的**：统一管理多个LLM提供商
- **优势**：易于扩展新的AI服务

### 3. 观察者模式（Observer Pattern）
- **实现**：Qt Signal/Slot机制
- **目的**：实现组件间松耦合通信
- **优势**：响应式更新，事件驱动

### 4. 模板方法模式（Template Method Pattern）
- **实现**：各种内容生成方法
- **目的**：统一页面生成流程
- **优势**：代码复用，结构清晰
