# 调试面板输出指南

## 📋 概述

本文档说明如何在LectureLearnLoop项目中正确输出调试信息到自定义调试面板。

## 🎯 调试面板系统

### 调试面板结构
- **面板ID**: `practice-debug-panel`
- **日志容器ID**: `debug-log`
- **显示位置**: 页面右侧浮动面板
- **激活方式**: 按F12键或快捷键

### 核心函数

#### 1. `addDebugLog(message)`
**用途**: 输出调试信息到自定义调试面板

**函数实现**:
```javascript
function addDebugLog(message) {
    console.log(message);  // 同时输出到浏览器控制台
    
    let debugPanel = document.getElementById('practice-debug-panel');
    if (!debugPanel) {
        debugPanel = createDebugPanel();  // 自动创建面板
    }
    
    const logContainer = debugPanel.querySelector('#debug-log');
    if (logContainer) {
        const timestamp = new Date().toLocaleTimeString();
        logContainer.innerHTML += `<div>[${timestamp}] ${message}</div>`;
        logContainer.scrollTop = logContainer.scrollHeight;  // 自动滚动到底部
    }
}
```

**调用位置**: `templates/base.html` 第826-840行

#### 2. `globalDebugLog(message)`
**用途**: 全局调试日志函数（可能输出到其他位置）

**注意**: 推荐使用 `addDebugLog()` 确保输出到正确的调试面板

## 🔧 使用方法

### 基本用法
```javascript
// ✅ 正确用法 - 输出到自定义调试面板
addDebugLog('🔥 功能被调用');
addDebugLog('📊 数据长度: ' + data.length);
addDebugLog('⚠️ 警告信息');
addDebugLog('❌ 错误信息: ' + error.message);
```

### 高级用法
```javascript
// 输出复杂对象
addDebugLog('📋 对象数据: ' + JSON.stringify(obj));

// 输出带时间戳的信息
addDebugLog('⏰ 当前时间: ' + new Date().toISOString());

// 输出函数执行状态
try {
    someFunction();
    addDebugLog('✅ 函数执行成功');
} catch(e) {
    addDebugLog('❌ 函数执行失败: ' + e.message);
}
```

### 错误处理
```javascript
// 安全的调试输出（推荐）
try {
    addDebugLog('🔍 调试信息: ' + data);
} catch(e) {
    console.log('调试输出失败:', e);
}
```

## 🎨 日志格式建议

### 表情符号约定
- 🔥 函数调用/执行
- 🔍 检测/发现
- 📊 数据信息
- ⚠️ 警告
- ❌ 错误
- ✅ 成功
- 🖱️ 用户操作
- 📋 对象/列表数据
- ⏰ 时间相关

### 消息格式
```javascript
// 功能调用
addDebugLog('🔥 [函数名] 被调用，参数: ' + params);

// 数据检测
addDebugLog('🔍 检测到 [内容类型]: "' + content + '"');

// 状态报告
addDebugLog('📊 [模块名] 状态: ' + status);

// 错误报告
addDebugLog('❌ [功能名] 失败: ' + error.message);
```

## 🔧 调试面板操作

### 打开调试面板
- 按 **F12** 键
- 或使用快捷键触发

### 面板功能
- **实时显示**: 调试信息实时追加
- **自动滚动**: 新信息自动滚动到底部
- **时间戳**: 每条信息都有时间戳
- **持久显示**: 信息会保持显示直到页面刷新

## 📝 注意事项

1. **性能考虑**: 不要在高频循环中使用调试输出
2. **信息量控制**: 避免输出过长的字符串导致面板卡顿
3. **错误处理**: 始终用try-catch包装调试代码
4. **清理代码**: 生产环境前记得移除或注释调试代码

## 🎯 最佳实践

1. **使用表情符号**: 让日志更易读
2. **添加上下文**: 包含足够的上下文信息
3. **分级输出**: 区分普通信息、警告、错误
4. **及时清理**: 调试完成后及时清理调试代码
5. **文档记录**: 记录重要的调试发现
