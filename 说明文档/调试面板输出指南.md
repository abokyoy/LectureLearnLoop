# 调试面板输出指南

## 📋 概述

本文档说明如何在LectureLearnLoop项目中正确输出调试信息到自定义调试面板。

## 🎯 调试面板系统

### 调试面板结构
- **面板ID**: `practice-debug-panel`
- **日志容器ID**: `debug-log`
- **显示位置**: 页面右侧浮动面板
- **激活方式**: 按F12键或快捷键

### 核心函数

#### 1. `addDebugLog(message)`
**用途**: 输出调试信息到自定义调试面板

**函数实现**:
```javascript
function addDebugLog(message) {
    console.log(message);  // 同时输出到浏览器控制台
    
    let debugPanel = document.getElementById('practice-debug-panel');
    if (!debugPanel) {
        debugPanel = createDebugPanel();  // 自动创建面板
    }
    
    const logContainer = debugPanel.querySelector('#debug-log');
    if (logContainer) {
        const timestamp = new Date().toLocaleTimeString();
        logContainer.innerHTML += `<div>[${timestamp}] ${message}</div>`;
        logContainer.scrollTop = logContainer.scrollHeight;  // 自动滚动到底部
    }
}
```

**调用位置**: `templates/base.html` 第826-840行

#### 2. `globalDebugLog(message)`
**用途**: 全局调试日志函数（可能输出到其他位置）

**注意**: 推荐使用 `addDebugLog()` 确保输出到正确的调试面板

## 🔧 使用方法

### 基本用法
```javascript
// ✅ 正确用法 - 输出到自定义调试面板
addDebugLog('🔥 功能被调用');
addDebugLog('📊 数据长度: ' + data.length);
addDebugLog('⚠️ 警告信息');
addDebugLog('❌ 错误信息: ' + error.message);
```

### 高级用法
```javascript
// 输出复杂对象
addDebugLog('📋 对象数据: ' + JSON.stringify(obj));

// 输出带时间戳的信息
addDebugLog('⏰ 当前时间: ' + new Date().toISOString());

// 输出函数执行状态
try {
    someFunction();
    addDebugLog('✅ 函数执行成功');
} catch(e) {
    addDebugLog('❌ 函数执行失败: ' + e.message);
}
```

### 错误处理
```javascript
// 安全的调试输出（推荐）
try {
    addDebugLog('🔍 调试信息: ' + data);
} catch(e) {
    console.log('调试输出失败:', e);
}
```
