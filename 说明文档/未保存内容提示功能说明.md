# 未保存内容提示功能说明

## 功能概述

本功能实现了一个通用的未保存内容检测和提示系统，当用户在编辑文件时尝试离开页面或切换到其他页面时，系统会自动检测是否有未保存的更改，并弹出保存提示对话框，防止用户意外丢失编辑内容。

## 核心特性

### 🛡️ 智能检测
- **实时监控**：自动监控编辑器内容变化
- **状态跟踪**：准确跟踪文件的保存状态
- **多元素支持**：支持监控多个编辑器元素

### 💬 用户友好的提示
- **保存对话框**：美观的Material Design风格对话框
- **三种选择**：保存、不保存、取消
- **状态指示器**：实时显示编辑状态和未保存提示

### 🔄 自动保存机制
- **页面切换时自动保存**：用户切换标签页或窗口时自动保存
- **窗口失去焦点时保存**：用户切换到其他应用时自动保存
- **页面卸载前提示**：浏览器原生的beforeunload事件提示

    return new Promise((resolve, reject) => {

}

## 集成示例

### 网课笔记页面集成
```javascript
function initUnsavedChangesDetection() {
    const editContent = document.getElementById('edit-content');
    if (editContent && window.registerEditor) {
        window.registerEditor(editContent, currentFilePath, function() {
            return new Promise((resolve, reject) => {
                if (window.pybridge && window.pybridge.save_file) {
                    window.pybridge.save_file(currentFilePath, editContent.value, function(result) {
                        const response = JSON.parse(result);
                        if (response.success) {
                            resolve();
                        } else {
                            reject(new Error(response.error));
                        }
                    });
                }
            });
        });
    }
}
```

### 从资料学习页面集成
```javascript
function initUnsavedChangesDetection() {
    const editContent = document.getElementById('edit-content');
    if (editContent && window.registerEditor) {
        window.registerEditor(editContent, currentFilePath, function() {
            return new Promise((resolve, reject) => {
                if (window.pybridge && window.pybridge.saveMarkdownFile) {
                    const success = window.pybridge.saveMarkdownFile(currentFilePath, editContent.value);
                    if (success) {
                        resolve();
                    } else {
                        reject(new Error('保存失败'));
                    }
                }
            });
        });
    }
}
```

## API 参考

### 全局函数

#### registerEditor(element, filePath, saveCallback)
注册需要监控的编辑器元素
- `element`: DOM元素（textarea、input或contenteditable）
- `filePath`: 文件路径（可选）
- `saveCallback`: 保存回调函数，返回Promise

#### unregisterEditor(element)
取消监控编辑器元素
- `element`: 要取消监控的DOM元素

#### canNavigate(callback)
检查是否可以导航
- `callback`: 导航继续时的回调函数
- 返回: boolean，true表示可以直接导航，false表示需要用户确认

#### markAsSaved()
手动标记当前内容为已保存状态

### 事件

#### unsavedChangesStateChange
未保存状态变化时触发的自定义事件
```javascript
window.addEventListener('unsavedChangesStateChange', function(event) {
    console.log('未保存状态:', event.detail.hasUnsavedChanges);
});
```

## 用户体验

### 视觉指示器
1. **保存按钮**：有未保存更改时显示橙色保存按钮
2. **页面标题**：未保存时在标题后添加 "*" 标记
3. **状态文本**：显示当前编辑状态

### 交互流程
1. 用户编辑内容 → 系统检测到更改 → 显示未保存指示器
2. 用户尝试离开页面 → 弹出保存提示对话框
3. 用户选择：
   - **保存**：执行保存操作后继续导航
   - **不保存**：直接导航，丢弃更改
   - **取消**：停留在当前页面

### 自动保存场景
- 用户切换浏览器标签页
- 用户切换到其他应用程序
- 用户最小化窗口
- 页面即将卸载时
