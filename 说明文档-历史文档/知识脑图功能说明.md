# 知识脑图功能实现说明

## 功能概述

基于用户需求，成功实现了"练-基于学习资料练习"功能的知识脑图可视化系统。该功能通过AI分析知识点关系，生成直观的脑图界面，帮助用户更好地理解和练习学习内容。

## 核心功能特性

### 1. 学科选择与统计
- **学科列表显示**：左侧面板展示所有包含知识点的学科
- **知识点数量统计**：每个学科显示对应的知识点数量
- **动态加载**：通过API实时获取最新的学科数据

### 2. 知识脑图生成
- **AI智能分析**：调用LLM分析知识点之间的关系
- **自动归类**：AI可创建新的分类节点对知识点进行归类
- **关系映射**：支持包含、依赖、相关、前置等多种关系类型

### 3. 可视化交互
- **D3.js渲染**：使用专业图形库实现美观的脑图展示
- **力导向布局**：节点自动排列，避免重叠
- **缩放控制**：支持放大、缩小、重置视图
- **拖拽交互**：节点可拖拽调整位置

### 4. 搜索与导航
- **实时搜索**：输入关键词高亮匹配的知识点
- **节点点击**：点击知识点节点查看详情信息
- **视图控制**：工具栏提供完整的视图操作

## 技术架构

### 后端实现（严格遵循分层架构）

#### 数据访问层（DAL）
- **数据库表设计**：
  ```sql
  -- 知识脑图表
  CREATE TABLE knowledge_mindmaps (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      user_id TEXT NOT NULL DEFAULT '0001',
      subject_name TEXT NOT NULL,
      mindmap_data TEXT NOT NULL,
      version INTEGER DEFAULT 1,
      created_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
      updated_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
      UNIQUE(user_id, subject_name)
  );
  ```

#### 业务逻辑层（BLL）
- **MindmapManager类**：负责脑图的生成、存储和读取
- **核心方法**：
  - `get_mindmap()`: 获取已存储的脑图
  - `save_mindmap()`: 保存脑图数据
  - `generate_mindmap_with_llm()`: 调用LLM生成脑图

#### 控制层（Controller）
- **API方法**：
  - `getSubjectsWithKnowledgeCount()`: 获取学科列表
  - `getOrGenerateMindmap()`: 获取或生成脑图
  - `saveMindmap()`: 保存脑图
  - `getKnowledgePointDetail()`: 获取知识点详情

### 前端实现（模板与业务分离）

#### 模板文件
- **位置**：`templates/pages/practice_materials.html`
- **结构**：
  - 页面头部：标题和刷新按钮
  - 左侧面板：学科选择列表
  - 右侧区域：脑图工具栏和显示区域

#### JavaScript实现
- **KnowledgeMindmap类**：封装所有前端逻辑
- **核心功能**：
  - 学科数据加载和显示
  - D3.js脑图渲染
  - 用户交互处理
  - API通信管理

## 数据流程

### 1. 学科加载流程
```
前端加载 → getSubjectsWithKnowledgeCount() → 
KnowledgeManagementSystem.get_subject_stats() → 
数据库查询 → 返回学科统计 → 前端渲染列表
```

### 2. 脑图生成流程
```
选择学科 → getOrGenerateMindmap() → 
检查现有脑图 → 如无则调用LLM → 
MindmapManager.generate_mindmap_with_llm() → 
LLM分析知识点关系 → 生成JSON数据 → 
保存到数据库 → 返回前端 → D3.js渲染
```

### 3. 知识点详情流程
```
点击节点 → 提取知识点ID → getKnowledgePointDetail() → 
数据库查询知识点信息 → 返回详情数据 → 前端显示
```

## LLM集成

### 提示词设计
- **输入**：学科名称和知识点列表（包含ID和名称）
- **输出**：标准化的JSON脑图数据
- **要求**：
  - 知识点节点ID使用"kp_"前缀
  - 分类节点ID使用"category_"前缀
  - 包含节点坐标和关系信息

### 数据格式
```json
{
    "nodes": [
        {
            "id": "kp_1",
            "name": "知识点名称",
            "type": "knowledge_point",
            "level": 1,
            "x": 100,
            "y": 100
        }
    ],
    "edges": [
        {
            "source": "category_1",
            "target": "kp_1",
            "relation": "包含"
        }
    ]
}
```
