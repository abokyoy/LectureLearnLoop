# 🔧 转写文件重复创建问题修复说明

## 🐛 **发现的问题**

用户反馈转写功能存在严重问题：
- **问题描述**：每次追加转写内容都会新建一个文件
- **问题现象**：产生一堆文件，每个文件比上一个多一次转写内容
- **期望行为**：应该只有一个文件，始终保持最新内容

## 🔍 **问题根本原因**

### **错误的文件命名逻辑**
```python
# ❌ 问题代码：每次都用当前时间生成新文件名
else:
    # 新会话，使用当前时间生成文件名
    now = datetime.now()  # 每次调用都是不同的时间！
    filename = f"transcript_{now.strftime('%Y%m%d_%H%M%S')}.json"
    file_path = os.path.join(audio_text_dir, filename)
```

**问题分析**：
1. **时间变化**：每次保存时 `datetime.now()` 都返回不同时间
2. **文件名变化**：导致每次生成不同的文件名
3. **重复创建**：每次保存都创建新文件而不是更新原文件

### **文件创建过程示例**
```
第1次转写保存：transcript_20250925_171401.json
第2次转写保存：transcript_20250925_171402.json  # 时间差1秒
第3次转写保存：transcript_20250925_171403.json  # 时间差2秒
第4次转写保存：transcript_20250925_171404.json  # 时间差3秒
...
```

## ✅ **修复方案**

### **核心思路**
使用 **sessionId** 生成固定的文件名，而不是每次都用当前时间。

### **1. 前端修改：传递文件路径信息** ✅

**修改保存函数**：
```javascript
function saveTranscriptSession() {
    if (window.bridge && window.bridge.saveTranscriptSession) {
        const sessionData = {
            sessionId: currentTranscriptSession.sessionId,
            startTime: currentTranscriptSession.startTime,
            transcripts: currentTranscriptSession.transcripts,
            saveTime: new Date().toISOString(),
            isLoadedFromFile: currentTranscriptSession.isLoadedFromFile || false,
            originalFilePath: currentTranscriptSession.filePath || null  // 传递已知的文件路径
        };
        
        window.bridge.saveTranscriptSession(JSON.stringify(sessionData), function(filePath) {
            if (filePath) {
                currentTranscriptSession.filePath = filePath;  // 记录文件路径
                debugLog('转写会话已保存到: ' + filePath);
            }
        });
    }
}
```

**关键改进**：
- ✅ 传递 `originalFilePath`：如果已知文件路径，传递给后端
- ✅ 记录返回路径：后端返回的文件路径会被记录，下次使用

### **2. 后端修改：固定文件路径逻辑** ✅

**修改文件路径生成逻辑**：
```python
# 确定文件路径：载入文件使用原路径，新会话使用sessionId生成固定路径
if 'originalFilePath' in session_data and session_data['originalFilePath']:
    # 如果有原始文件路径，直接使用（载入的文件或已创建的文件）
    file_path = session_data['originalFilePath']
    self.logger.info(f"使用原始文件路径: {file_path}")
else:
    # 新会话或没有原始路径，从sessionId生成固定文件名
    session_id = session_data.get('sessionId', 'unknown')
    if session_id.startswith('transcript_'):
        timestamp_str = session_id.replace('transcript_', '')
        try:
            # 尝试解析时间戳
            timestamp = int(timestamp_str)
            dt = datetime.fromtimestamp(timestamp / 1000)  # JavaScript时间戳是毫秒
            filename = f"transcript_{dt.strftime('%Y%m%d_%H%M%S')}.json"
            self.logger.info(f"从sessionId生成文件名: {filename}")
        except Exception as e:
            # 如果解析失败，使用当前时间
            self.logger.warning(f"解析sessionId失败: {e}，使用当前时间")
            now = datetime.now()
            filename = f"transcript_{now.strftime('%Y%m%d_%H%M%S')}.json"
    file_path = os.path.join(audio_text_dir, filename)
```

**关键改进**：
- ✅ **优先使用已知路径**：如果前端传递了文件路径，直接使用
- ✅ **sessionId生成固定名称**：从sessionId中的时间戳生成固定文件名
- ✅ **一次生成，永久使用**：同一个sessionId始终对应同一个文件名

### **3. sessionId与文件名的对应关系** ✅

**sessionId格式**：
```javascript
// 前端生成sessionId
sessionId: 'transcript_' + now.getTime()
// 例如：transcript_1727252841000
```

**文件名生成**：
```python
# 后端从sessionId提取时间戳
timestamp_str = session_id.replace('transcript_', '')  # "1727252841000"
timestamp = int(timestamp_str)  # 1727252841000
dt = datetime.fromtimestamp(timestamp / 1000)  # 转换为datetime对象
filename = f"transcript_{dt.strftime('%Y%m%d_%H%M%S')}.json"
# 例如：transcript_20250925_171401.json
```

**对应关系**：
- `sessionId: transcript_1727252841000`
- `fileName: transcript_20250925_171401.json`
- **固定不变**：同一个sessionId始终生成相同的文件名

## 🔧 **技术实现细节**

### **文件路径状态管理**
```javascript
let currentTranscriptSession = {
    sessionId: null,           // 会话ID（固定）
    startTime: null,           // 开始时间
    transcripts: [],           // 转写记录
    filePath: null,            // 文件路径（第一次保存后确定）
    isLoadedFromFile: false,   // 是否从文件载入
    originalFileName: null     // 原始文件名
};
```

### **保存流程优化**
1. **第一次保存**：
   - 前端：`filePath` 为 `null`
   - 后端：从 `sessionId` 生成文件名，创建文件
   - 返回：文件路径给前端
   - 前端：记录 `filePath`

2. **后续保存**：
   - 前端：传递已知的 `filePath`
   - 后端：使用传递的路径，更新同一文件
   - 返回：相同的文件路径
   - 前端：确认路径不变

### **载入文件处理**
```javascript
// 载入文件时记录原始路径
currentTranscriptSession = {
    sessionId: sessionData.sessionId,
    filePath: sessionData.originalFilePath,  // 记录原始文件路径

    // ...
};
```
