# 有向脑图和关系文字功能说明

## 功能概述
为知识脑图添加了有向箭头和关系文字功能，使脑图能够清晰地展示知识点之间的逻辑关系和学习路径。

## 主要改进

### 1. 大模型输出格式优化

#### 增强的提示词设计
- **有向关系**：明确要求生成有向的知识关系脑图
- **关系描述**：每条边必须包含具体的关系描述
- **层次结构**：要求包含中心节点、分类节点、知识点的三层结构
- **方向标识**：添加direction字段表示关系方向

#### 新的JSON格式
```json
{
    "nodes": [
        {
            "id": "center",
            "name": "学科名称",
            "type": "center",
            "level": 0
        }
    ],
    "edges": [
        {
            "source": "center",
            "target": "category_1",
            "relation": "包含",
            "direction": "forward"
        }
    ]
}
```

#### 丰富的关系类型
- **包含**：学科包含分类
- **细分为**：分类细分为具体知识点
- **依赖于**：知识点之间的依赖关系
- **前置条件**：学习的先后顺序
- **应用于**：理论到实践的应用
- **扩展为**：知识的延伸和拓展

### 2. 前端D3.js渲染优化

#### 有向箭头实现
```javascript
// 定义箭头标记
const defs = svg.append('defs');
defs.append('marker')
    .attr('id', 'arrow')
    .attr('viewBox', '0 -5 10 10')
    .attr('refX', 20) // 避免与圆圈重叠
    .attr('refY', 0)
    .attr('markerWidth', 8)
    .attr('markerHeight', 8)
    .attr('orient', 'auto')
    .append('path')
    .attr('d', 'M0,-5L10,0L0,5')
    .attr('fill', '#666');
```

#### 关系文字显示
```javascript
// 绘制关系文字
const linkLabels = g.append('g')
    .selectAll('text')
    .data(edges)
    .enter().append('text')
    .attr('class', 'link-label')
    .attr('text-anchor', 'middle')
    .attr('dy', -5)
    .style('font-size', '10px')
    .style('font-weight', 'bold')
    .style('fill', '#555')
    .text(d => d.relation || '关联');
```

#### 动态位置更新
```javascript
// 更新关系文字位置（在连线中点）
linkLabels
    .attr('x', d => (d.source.x + d.target.x) / 2)
    .attr('y', d => (d.source.y + d.target.y) / 2);
```

## 技术实现细节

### 1. 箭头标记系统
- **SVG Marker**：使用SVG的marker元素定义箭头
- **自动定向**：`orient="auto"`让箭头自动朝向连线方向
- **位置调整**：`refX=20`避免箭头与节点圆圈重叠
- **样式统一**：箭头颜色与连线保持一致

### 2. 关系文字系统
- **中点定位**：文字显示在连线的中点位置
- **背景增强**：使用text-shadow创建白色背景效果
- **事件穿透**：`pointer-events: none`防止文字阻挡鼠标操作
- **动态更新**：文字位置随节点移动实时更新

### 3. 力导向图优化
- **增大距离**：连线距离从100增加到120，为文字留出空间
- **增强排斥**：节点排斥力从-300增加到-400，避免重叠
- **碰撞检测**：碰撞半径从40增加到50，适应更大的节点

## 视觉效果提升

### 1. 有向连线
- **清晰方向**：箭头明确指示知识的流向和依赖关系
- **层次感强**：从中心到分类到知识点的层次结构清晰
- **学习路径**：可以清楚地看到知识的学习顺序

### 2. 关系描述
- **语义明确**：每条连线都有具体的关系描述
- **学习指导**：帮助用户理解知识点之间的逻辑关系
- **可读性强**：文字带有白色阴影，在任何背景下都清晰可见

### 3. 整体布局
- **更大间距**：节点之间有更多空间显示关系文字
- **更少重叠**：优化的力导向参数减少节点和文字重叠
- **更好交互**：文字不会阻挡鼠标操作

## 数据流程

### 1. LLM生成阶段
1. **知识点分析**：LLM分析学科的所有知识点
2. **关系推理**：推断知识点之间的逻辑关系
3. **层次构建**：构建中心-分类-知识点的三层结构
4. **关系标注**：为每条边添加具体的关系描述

### 2. 前端渲染阶段
1. **数据验证**：验证edges数组包含relation字段
2. **箭头定义**：创建SVG箭头标记
3. **连线绘制**：绘制带箭头的有向连线
4. **文字添加**：在连线中点添加关系文字
5. **动态更新**：实时更新文字位置

## 示例关系类型

### 学科层面
- **学科 → 分类**：包含、涵盖、分为
- **分类 → 知识点**：细分为、具体化为、实现为

### 知识点层面
- **基础 → 进阶**：前置条件、基础为、支撑
- **理论 → 实践**：应用于、实现为、体现在
- **核心 → 扩展**：扩展为、延伸到、关联

### 逻辑关系
- **因果关系**：导致、引起、产生
- **包含关系**：包含、组成、构成
- **依赖关系**：依赖于、基于、需要
