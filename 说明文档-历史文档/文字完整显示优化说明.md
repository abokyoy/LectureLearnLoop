# 文字完整显示优化说明

## 问题描述
知识脑图中圆圈内的文字存在截断情况，无法完整展示知识点名称，影响用户体验。

## 优化方案

### 1. 动态圆圈大小
**根据文字长度自动调整圆圈大小**：
```javascript
// 根据文字长度动态调整大小
nodeGroups.append('circle')
    .attr('r', d => {
        const textLength = d.name.length;
        if (d.type === 'center') {
            return Math.max(50, textLength * 4); // 最小50，每字符4px
        }
        if (d.type === 'category') {
            return Math.max(40, textLength * 3.5); // 最小40，每字符3.5px
        }
        return Math.max(35, textLength * 3); // 知识点：最小35，每字符3px
    })
```

**优势**：
- 短文字：使用最小半径，保持美观
- 长文字：自动扩大圆圈，确保完整显示
- 不同类型节点有不同的缩放比例

### 2. 智能文字分行
**移除截断逻辑，完整显示所有文字**：

#### 原有问题
- 固定每行字符数限制
- 固定最大行数限制
- 超出部分用省略号截断
- 不考虑圆圈实际大小

#### 新的智能分行
```javascript
// 智能分行：根据圆圈大小决定每行字符数
const maxWidth = radius * 1.6; // 圆圈直径的80%作为文字宽度
const avgCharWidth = fontSize * 0.6; // 平均字符宽度
const maxCharsPerLine = Math.max(4, Math.floor(maxWidth / avgCharWidth));
```

**特性**：
- 根据圆圈实际大小计算每行字符数
- 支持中英文混合文本的智能分词
- 按自然断点分行（空格、括号、标点等）
- 无行数限制，完整显示所有文字

### 3. 中英文混合处理
```javascript
// 如果包含英文，按单词分割；否则按字符分割
if (/[a-zA-Z]/.test(text)) {
    words = text.split(/(\s+|\(|\)|（|）|,|，|、|：|:|-)/);
} else {
    words = text.split('');
}
```

**优势**：
- 英文单词不会被强制断开
- 中文按字符自然换行
- 保留标点符号和括号的完整性

### 4. 优化视觉效果
**字体和阴影优化**：
```javascript
.style('font-size', fontSize + 'px')
.style('font-weight', 'bold')
.style('text-shadow', '1px 1px 2px rgba(0,0,0,0.5)')
```

**改进**：
- 增大字体大小：中心14px，分类12px，知识点11px
- 增强文字阴影，提高可读性
- 白色文字在彩色背景上更清晰

### 5. 力导向图优化
**适应动态圆圈大小**：
```javascript
.force('collision', d3.forceCollide().radius(d => {
    const textLength = d.name.length;
    if (d.type === 'center') {
        return Math.max(50, textLength * 4) + 10; // 额外10px间距
    }
    if (d.type === 'category') {
        return Math.max(40, textLength * 3.5) + 8;
    }
    return Math.max(35, textLength * 3) + 6;
}))
```

**优化**：
- 碰撞检测半径与圆圈大小同步
- 增加额外间距，避免重叠
- 增大连线距离和排斥力，适应更大的节点

### 6. 连线位置调整
**动态计算连线起终点**：
```javascript
const getNodeRadius = (node) => {
    const textLength = node.name.length;
    if (node.type === 'center') {
        return Math.max(50, textLength * 4);
    }
    if (node.type === 'category') {
        return Math.max(40, textLength * 3.5);
    }
    return Math.max(35, textLength * 3);
};

const sourceRadius = getNodeRadius(d.source);
const targetRadius = getNodeRadius(d.target);
```

**效果**：
- 连线准确连接到圆圈边缘
- 箭头位置正确，不被遮挡
- 适应不同大小的圆圈

## 技术实现细节

### 1. 文字布局算法
1. **获取圆圈半径**：从DOM中读取实际半径
2. **计算可用宽度**：半径×1.6作为文字区域
3. **估算字符宽度**：字体大小×0.6
4. **计算每行字符数**：可用宽度÷字符宽度
5. **智能分词**：按自然断点分行
6. **垂直居中**：计算总高度，居中显示

### 2. 动态半径计算
```javascript
// 半径计算公式
radius = Math.max(minRadius, textLength * scaleFactor)

// 不同类型的参数
center: minRadius=50, scaleFactor=4
category: minRadius=40, scaleFactor=3.5  
knowledge_point: minRadius=35, scaleFactor=3
```

### 3. 性能优化
- 避免重复计算半径
- 使用高效的文字分行算法
- 最小化DOM操作
- 合理的力导向图参数
