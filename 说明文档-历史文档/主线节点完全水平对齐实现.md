# 主线节点完全水平对齐实现

## 🎯 **问题解决**

**用户需求**：希望所有主线节点都在水平位置，形成一条直线，而不是波浪状。

**问题原因**：力导向图的动态特性导致节点会有轻微的上下浮动。

## ✅ **解决方案**

### 1. **固定位置初始化**

```javascript
// 预设主线节点的固定位置
const mainLineNodes = nodes.filter(n => n.type === 'start' || n.type === 'stage' || n.type === 'end');
const totalMainNodes = mainLineNodes.length;
const containerWidth = 1600;
const padding = 50;
const availableWidth = containerWidth - 2 * padding;
const spacing = totalMainNodes > 1 ? availableWidth / (totalMainNodes - 1) : 0;

// 为主线节点设置固定的初始位置
nodes.forEach(node => {
    if (node.type === 'start' || node.type === 'stage' || node.type === 'end') {
        node.x = padding + node.level * spacing; // 固定X坐标
        node.y = 350; // 固定Y坐标
        node.fx = node.x; // 固定X位置
        node.fy = node.y; // 固定Y位置
    }
});
```

### 2. **强制水平对齐**

```javascript
// 更新位置 - 强制主线节点保持水平
simulation.on('tick', () => {
    // 强制主线节点保持在固定的水平线上
    nodes.forEach(d => {
        if (d.type === 'start' || d.type === 'stage' || d.type === 'end') {
            d.y = 350; // 强制主线节点Y坐标固定为350
        }
    });
    
    // 更新连线和节点位置
    links.attr('x1', d => d.source.x).attr('y1', d => d.source.y)
         .attr('x2', d => d.target.x).attr('y2', d => d.target.y);
    
    nodeGroups.attr('transform', d => `translate(${d.x},${d.y})`);
});
```

### 3. **拖拽约束**

```javascript
function dragged(event, d) {
    if (d.type === 'start' || d.type === 'stage' || d.type === 'end') {
        // 主线节点只能水平拖拽，Y坐标固定
        d.fx = event.x;
        d.fy = 350; // 强制保持在水平线上
    } else {
        // 知识点节点可以自由拖拽
        d.fx = event.x;
        d.fy = event.y;
    }
}

function dragended(event, d) {
    if (!event.active) simulation.alphaTarget(0);
    if (d.type === 'start' || d.type === 'stage' || d.type === 'end') {
        // 主线节点保持固定位置
        d.fx = d.x;
        d.fy = 350;
    } else {
        // 知识点节点释放固定
        d.fx = null;
        d.fy = null;
    }
}
```

## 🔧 **技术实现**

### 三重保障机制：

1. **初始化固定**：`node.fx` 和 `node.fy` 设置固定位置
2. **动态强制**：每次 `tick` 事件强制重置Y坐标
3. **拖拽约束**：拖拽时限制主线节点只能水平移动
