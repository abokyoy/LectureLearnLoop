# 脑图页面导航问题修复说明

## 🔍 **问题现象**

用户反馈的问题：
1. ✅ 第一次进入脑图页面 - 正常显示
2. ✅ 点击知识点查看详情 - 正常显示正确内容
3. ✅ 知识点ID映射已修复 - 描述和错题匹配正确
4. ❌ 返回科目选择页面，再次点击机器学习 - **脑图无法显示**

## 🔍 **根因分析**

### 问题根源
页面状态管理问题，具体表现为：

1. **D3.js状态冲突**：
   - 之前的`simulation`力导向图没有正确停止
   - SVG元素没有清理，导致渲染冲突
   - 全局变量状态混乱

2. **DOM状态异常**：
   - 页面切换后DOM元素状态不正确
   - 详情面板可能仍然显示
   - 加载状态没有重置

3. **WebChannel连接**：
   - 虽然连接正常，但页面状态异常可能影响渲染

## 🔧 **修复方案**

### 修复1：在`selectSubject`函数中添加状态清理

```javascript
function selectSubject(subjectName) {
    // === 新增：页面状态清理 ===
    try {
        // 1. 清理之前的脑图渲染
        if (simulation) {
            simulation.stop();
            simulation = null;
        }
        
        // 2. 清理SVG内容
        const svg = d3.select("#mindmapSvg");
        if (!svg.empty()) {
            svg.selectAll("*").remove();
        }
        
        // 3. 重置全局变量
        currentMindmapData = null;
        g = null;
        zoom = null;
        
        // 4. 清理详情面板状态
        const detailPanel = document.getElementById('knowledgePointDetail');
        if (detailPanel) {
            detailPanel.classList.add('hidden');
        }
        
        // 5. 重置加载状态
        hideLoading();
        
    } catch (error) {
        log(`⚠️ 清理过程中出现错误: ${error.message}`);
    }
    // === 清理逻辑结束 ===
    
    // 原有逻辑继续...
}
```

### 修复2：在`generateMindmap`函数中添加页面状态检查

```javascript
async function generateMindmap(subjectName) {
    // === 新增：生成前检查 ===
    try {
        // 检查页面状态
        const mindmapPage = document.getElementById('mindmapPage');
        const subjectPage = document.getElementById('subjectSelectionPage');
        
        if (!mindmapPage || mindmapPage.classList.contains('hidden')) {
            // 修复页面状态
            if (mindmapPage) {
                mindmapPage.classList.remove('hidden');
            }
            if (subjectPage) {
                subjectPage.classList.add('hidden');
            }
        }
        
        // 检查SVG容器
        const svgContainer = document.getElementById('mindmapSvg');
        if (!svgContainer) {
            log(`❌ SVG容器不存在`);
            hideLoading();
            return;
        }
        
    } catch (error) {
        log(`❌ 页面状态检查失败: ${error.message}`);
        hideLoading();
        return;
    }
    // === 检查逻辑结束 ===
    
    // 原有逻辑继续...
}
```
