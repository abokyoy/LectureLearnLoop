## 🔍 **可能的重复调用来源**

### 来源1：事件重复绑定
```javascript
// 可能的问题：onclick和addEventListener都绑定了
<div onclick="selectSubject('机器学习')">  ← HTML中的onclick
document.addEventListener('click', function(e) {  ← JavaScript中的监听器
    selectSubject(subjectName);
});
```

### 来源2：页面状态恢复
```javascript
// 虽然已禁用，但可能仍有残留
restorePreviousMindmapState();  ← 自动恢复
selectSubject('机器学习');      ← 用户点击
```

### 来源3：异步时序问题
```javascript
// 第一次调用还没完成，第二次调用就开始了
generateMindmap('机器学习');  ← 第一次
// ... 某种原因触发第二次
generateMindmap('机器学习');  ← 第二次
```

## 🔧 **根据调试结果的修复方案**

### 如果是事件重复绑定
移除HTML中的onclick，只使用JavaScript事件监听器

### 如果是页面状态恢复
完全禁用自动恢复功能

### 如果是异步时序问题
增强防重复机制，使用更严格的锁定
