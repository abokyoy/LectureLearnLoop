# 知识点详情弹窗练习功能实现

## 🎯 **功能需求**

用户要求在知识点详情弹窗中增加两个练习功能按钮：
1. **基于笔记练习**：基于知识点的关联笔记生成练习题
2. **举一反三练习**：基于知识点的错题记录生成类似题目

### 2. **基于笔记练习功能**

#### 核心流程：
```javascript
async function startNoteBasedPractice() {
    // 1. 获取知识点关联笔记
    const response = await window.bridge.getKnowledgePointNotes(nodeId);
    
    // 2. 检查笔记数量
    if (!result.notes || result.notes.length === 0) {
        showToast('该知识点暂无关联笔记，无法生成练习', 'warning');
        return;
    }
    
    // 3. 构建笔记内容
    const notesContent = result.notes.map(note => {
        return `【笔记标题】: ${note.title}\n【笔记内容】:\n${note.content}`;
    }).join('\n\n---\n\n');
    
    // 4. 生成练习提示词
    const practicePrompt = `请基于以下笔记内容，为知识点"${knowledgePointName}"生成一套练习题...`;
    
    // 5. 调用AI生成练习
    generatePracticeQuestionsForAI(practicePrompt, practiceId);
}
```

#### 提示词设计：
```
**要求：**
1. 仔细阅读上述笔记内容，找到与知识点相关的原文内容
2. 严格基于笔记中的原文内容出题，不要超出原文的范畴
3. 题目类型包括：选择题、判断题、填空题、简答题
4. 每种题型2-3道，总共8-10道题
5. 题目难度适中，既考查基础理解，也考查应用能力

**返回格式要求（严格按照以下格式）：**
## 选择题
**1. [题目内容]**
A. [选项A] B. [选项B] C. [选项C] D. [选项D]
**答案：** [正确答案字母]
**解析：** [详细解析]
```

### 3. **举一反三练习功能**

#### 核心流程：
```javascript
async function startAnalogyPractice() {
    // 1. 获取知识点错题记录
    const response = await window.bridge.getKnowledgePointQuestions(nodeId);
    
    // 2. 检查错题数量
    if (!result.questions || result.questions.length === 0) {
        showToast('该知识点暂无错题记录，无法生成举一反三练习', 'warning');
        return;
    }
    
    // 3. 构建错题内容
    const errorQuestions = result.questions.map((q, index) => {
        return `【错题${index + 1}】
题目: ${q.question}
题型: ${q.type || '未知'}
正确答案: ${q.correct_answer || '未知'}
用户答案: ${q.user_answer || '未知'}
错误原因: ${q.error_reason || '理解有误'}`;
    }).join('\n\n');
    
    // 4. 生成练习提示词
    const practicePrompt = `请基于以下错题记录，为知识点生成举一反三练习题...`;
    
    // 5. 调用AI生成练习
    generatePracticeQuestionsForAI(practicePrompt, practiceId);
}
```

#### 提示词设计：
```
**要求：**
1. 分析上述错题的题型、考查点和错误原因
2. 保持与错题相同的题型和难度水平
3. 出类似的题目供用户练习，但不要完全相同
4. 重点针对用户容易出错的知识点进行强化练习
5. 每种错题题型生成2-3道类似题目

**返回格式要求：**
包含易错提醒和常见错误注意事项
```

### 4. **按钮状态管理**

#### 状态更新函数：
```javascript
async function updatePracticeButtonsState(detail, nodeId) {
    const noteBasedBtn = document.getElementById('noteBasedPracticeBtn');
    const analogyBtn = document.getElementById('analogyPracticeBtn');
    
    // 检查关联笔记数量
    const notesCount = detail.notes_count || 0;
    if (notesCount > 0) {
        noteBasedBtn.disabled = false;
        noteBasedBtn.title = `基于 ${notesCount} 篇关联笔记生成练习`;
    } else {
        noteBasedBtn.disabled = true;
        noteBasedBtn.title = '该知识点暂无关联笔记';
    }
    
    // 检查错题数量（异步获取）
    const response = await window.bridge.getKnowledgePointQuestions(realId);
    const result = JSON.parse(response);
    
    if (result.success && result.questions && result.questions.length > 0) {
        analogyBtn.disabled = false;
        analogyBtn.title = `基于 ${result.questions.length} 道错题生成举一反三练习`;
    } else {
        analogyBtn.disabled = true;
        analogyBtn.title = '该知识点暂无错题记录';
    }
}
```
