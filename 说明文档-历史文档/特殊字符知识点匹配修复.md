# 特殊字符知识点匹配修复

## 🚨 **问题现象**

用户反馈：包含特殊符号的知识点着色不对，也不支持点击。

### 问题知识点示例：
```
38	0001	机器学习	`compact`  命令	用于在下一轮对话中保留前序结果，并自动对历史上下文进行总结。
39	0001	机器学习	`compaq`  命令	用于执行上下文总结与记忆管理，但效果一般。
40	0001	机器学习	`cost`  命令	用于查看API调用成本或资源消耗。
41	0001	机器学习	`login/logout`  命令	用于账户切换。
42	0001	机器学习	`model`  设置	选择不同模型以优化性能和成本。
43	0001	机器学习	`status`  命令	查看系统当前状态，包括ID集成状态、工作目录、版本信息等。
44	0001	机器学习	`Gauntlet`  命令	提供对云环境的管理能力。
```

## 🔍 **问题分析**

### 1. **特殊字符干扰匹配**
- **反引号** (`): markdown代码标记
- **斜杠** (/): 路径分隔符
- **空格**: 不同位置的空格
- **大小写**: 不一致的大小写

### 2. **原始匹配逻辑局限**
```python
# 原始匹配逻辑（有问题）
if (kp_name.lower() in node_name.lower() or 
    node_name.lower() in kp_name.lower() or
    kp_name.replace(' ', '').lower() in node_name.replace(' ', '').lower()):
```
- 只处理空格和大小写
- 无法处理反引号、斜杠等特殊字符
- 导致 `compact` 命令 无法匹配 compact命令

## 🔧 **修复方案**

### 1. **增强文本清理函数**
```python
def clean_text(text):
    import re
    # 移除常见特殊字符：反引号、斜杠、空格等
    cleaned = re.sub(r'[`/\s\-_()（）【】\[\]{}]', '', text.lower())
    return cleaned
```

**清理规则**：
- **反引号** (`): 移除
- **斜杠** (/): 移除  
- **空格** (\s): 移除
- **连字符** (-_): 移除
- **括号** (()（）【】[]{}): 移除
- **大小写**: 统一转小写

### 2. **多策略匹配逻辑**
```python
# 多种匹配策略
if (kp_name.lower() in node_name.lower() or 
    node_name.lower() in kp_name.lower() or
    clean_kp_name in clean_node_name or
    clean_node_name in clean_kp_name or
    kp_name.replace(' ', '').lower() in node_name.replace(' ', '').lower()):
```

**匹配策略**：
1. **直接匹配**: 原始文本包含匹配
2. **清理后匹配**: 移除特殊字符后匹配
3. **去空格匹配**: 兼容性匹配

### 3. **前端点击样式修复**
