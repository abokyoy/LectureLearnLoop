## 🔄 **完整的用户流程**

### **步骤1：触发错题入库**
- 用户在评估详情弹窗点击"错题入库"按钮
- 系统自动调用 `addToErrorBank` API
- 进行错题切片，获取学科列表

### **步骤2：选择学科**
- 显示学科选择界面
- 用户点击选择目标学科
- 显示加载动画："正在为学科 XXX 匹配知识点..."

### **步骤3：知识点匹配**
- 调用 `matchKnowledgePointsForSubject` API
- 使用原版embedding相似度算法
- 为每道错题计算与该学科所有知识点的相似度
- 按相似度降序排列知识点选项

### **步骤4：查看和调整**
- 显示三列错题表格
- 每道错题显示：题目内容、用户答案、匹配知识点
- 知识点下拉框显示格式：`学科 - 知识点名称 (相似度分数)`
- 用户可手动调整每道题的知识点归属

### **步骤5：批量入库**
- 用户可选择"入库选中"或"全部入库"
- 调用 `saveErrorsToKnowledgeBase` API
- 保存到原版知识管理系统
- 显示保存结果："已保存 X 条错题到知识库"
