# 网课笔记截图功能实现说明

## 功能概述
为网课笔记页面实现了完整的截图功能，用户可以在学习过程中快速截图并插入到Markdown编辑器中，支持图片的保存和预览显示。

## 核心功能实现

### 1. 截图覆盖层 (ScreenshotOverlay)
- **位置**: `overlay_drag_corgi_app.py` 第8541-8633行
- **功能**: 全屏截图选择界面，支持鼠标拖拽选择截图区域
- **特性**:
  - 全屏半透明遮罩
  - 鼠标拖拽选择区域
  - 实时预览选中区域
  - 支持双击确认或按Enter键确认
  - 按Esc键取消截图
  - HiDPI屏幕支持

### 2. 截图功能后端实现
- **方法**: `takeScreenshot()` (第3791-3811行)
- **回调**: `_on_screenshot_captured()` (第3813-3870行)
- **功能流程**:
  1. 获取主屏幕对象
  2. 创建截图覆盖层
  3. 用户选择截图区域
  4. 保存图片到attachments目录
  5. 自动插入到MD编辑器

### 3. 图片保存逻辑
- **保存路径**: 当前文档同目录下的`attachments/`文件夹
- **文件命名**: `screenshot_YYYYMMDD_HHMMSS.png`
- **目录创建**: 如果attachments目录不存在，自动创建
- **备选路径**: 如果没有当前文档，保存到`course_notes/attachments/`

### 4. 前端界面集成
- **截图按钮**: 橙色相机图标按钮，位于录音控制区域
- **按钮样式**: `bg-orange-500 hover:bg-orange-600`
- **图标**: Material Icons的`camera_alt`
- **点击事件**: 调用`takeScreenshot()`函数

### 5. Markdown编辑器支持
- **图片插入**: 自动插入`![截图](attachments/filename.png)`格式
- **路径处理**: 支持相对路径的图片显示
- **预览渲染**: 在预览模式下正确显示图片
- **文件协议**: 自动转换为`file:///`协议以支持本地图片显示

## 技术架构

### 后端技术栈
- **Qt框架**: 使用PySide6的截图和图像处理功能
- **信号槽机制**: 通过Qt信号实现异步截图处理
- **文件系统**: 自动管理attachments目录结构
- **JSON通信**: 前后端通过JSON格式交换数据

### 前端技术栈
- **JavaScript**: 处理用户交互和UI更新
- **Markdown渲染**: 使用marked.js库渲染Markdown内容
- **图片路径处理**: 自动转换相对路径为绝对路径
- **CSS样式**: 响应式图片显示样式

## 使用流程

### 基本使用步骤
1. **打开网课笔记页面**: 选择或创建一个笔记文档
2. **切换到编辑模式**: 确保处于编辑模式以插入截图
3. **点击截图按钮**: 点击橙色的相机图标按钮
4. **选择截图区域**: 在全屏覆盖层中拖拽选择要截图的区域
5. **确认截图**: 双击或按Enter键确认截图
6. **自动插入**: 截图自动插入到编辑器光标位置
7. **预览查看**: 切换到预览模式查看插入的图片

### 快捷键操作
- **Enter键**: 确认当前选择的截图区域
- **Esc键**: 取消截图操作
- **双击**: 快速确认截图区域

### Markdown图片渲染
```javascript
// 处理图片路径，支持相对路径显示
html = html.replace(/<img([^>]*?)src="([^"]*?)"([^>]*?)>/g, function(match, beforeSrc, src, afterSrc) {
    if (src.startsWith('attachments/') && currentFilePath) {
        const docDir = currentFilePath.substring(0, currentFilePath.lastIndexOf('/'));
        const fullImagePath = docDir + '/' + src;
        return `<img${beforeSrc}src="file:///${fullImagePath.replace(/\\/g, '/')}"${afterSrc}>`;
    }
    return match;
});
```

## 故障排除

### 常见问题
1. **截图按钮无响应**: 检查bridge对象是否正确初始化
2. **图片不显示**: 确认attachments目录是否存在且图片文件完整
3. **路径错误**: 检查currentFilePath变量是否正确设置
4. **权限问题**: 确认应用有屏幕截图权限（macOS需要）

### 调试方法
- 查看浏览器控制台的JavaScript日志
- 检查Python应用日志中的截图相关信息
- 验证attachments目录和图片文件是否正确创建
