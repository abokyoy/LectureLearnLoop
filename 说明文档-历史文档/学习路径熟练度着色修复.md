# 学习路径熟练度着色修复

## 🚨 **问题现象**

用户反馈：所有已有知识点都显示为灰白色，但实际上很多知识点是有熟练度数据的。

## 🔍 **问题诊断**

### 1. **前端着色逻辑正确**
- ✅ `getKnowledgePointColor(mastery_score)` 函数已正确实现
- ✅ 颜色映射表完整：-1(灰色) → 0-100分(橙色到红色渐变)
- ✅ 文本颜色逻辑正确：浅色背景用深色文字，深色背景用白色文字

### 2. **后端数据合并问题**
❌ **根本问题**：`_merge_knowledge_point_info`方法只处理`type == 'knowledge_point'`的节点
- 学习路径使用的是`existing_kp`和`supplement_kp`类型
- 导致所有节点的`mastery_score`都是undefined，显示为灰色

## 🔧 **修复方案**

### 1. **扩展节点类型处理**
```python
# 修复前（有问题）
if node.get('type') == 'knowledge_point':

# 修复后（正确）
if node.get('type') in ['existing_kp', 'supplement_kp', 'knowledge_point']:
```

### 2. **改进匹配算法**
```python
# 更宽松的匹配条件
if (kp_name.lower() in node_name.lower() or 
    node_name.lower() in kp_name.lower() or
    kp_name.replace(' ', '').lower() in node_name.replace(' ', '').lower()):
```

### 3. **完善默认值处理**
```python
if not matched:
    if node.get('type') == 'existing_kp':
        node['mastery_score'] = 50  # 默认中等熟练度
    else:
        node['mastery_score'] = -1  # 补充知识点默认未评估
```

### 4. **添加详细日志**
```python
print(f"📊 开始合并知识点信息，共有{len(kp_name_map)}个已有知识点")
print(f"🔍 处理节点: {node_name} (类型: {node.get('type')})")
print(f"  ✅ 匹配成功: {node_name} → {kp_name} (熟练度: {kp_info.get('mastery_score', 50)})")
print(f"🔗 已合并知识点信息到学习路径节点，成功匹配 {merged_count} 个节点")
```

## 🎯 **技术要点**

### 1. **数据流程**
```
1. 获取学科知识点 → 包含mastery_score
2. LLM生成学习路径 → 包含existing_kp节点
3. 合并知识点信息 → 将mastery_score添加到节点
4. 前端渲染 → 根据mastery_score着色
```

### 2. **匹配策略**
- **精确匹配**：节点名称完全相同
- **包含匹配**：节点名称互相包含
- **去空格匹配**：去除空格后匹配
- **大小写不敏感**：统一转换为小写

### 3. **默认值策略**
- **已有知识点未匹配**：默认50分（中等熟练度）
- **补充知识点**：默认-1分（未评估）
- **匹配成功**：使用数据库中的实际熟练度
