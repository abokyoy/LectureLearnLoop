## ✅ **修复方案**

### **1. 修正正则表达式**

**修复前**：
```python
pattern = r"(\d+)\.[ \t]*原题[：:][ \t]*\n?(.*?)(?=(?:\n----|\n\d+\.[ \t]*原题[：:]|\n整体评价|\Z))"
```

**修复后**：
```python
pattern = r"(\d+)\.[ \t]+(.*?)(?=(?:\n----|\n\d+\.[ \t]+|\n整体评价|\Z))"
```

**变化**：
- 移除了 `原题[：:]` 的匹配
- 直接匹配数字后的内容
- 简化了边界条件

### **2. 修正题目内容提取**

**修复前**：
```python

```

**修复后**：
```python
question_match = re.search(r"(.*?)(?=\n用户答案[：:]|$)", inner_content, re.DOTALL)
```

**变化**：
- 移除了对"原题："的查找
