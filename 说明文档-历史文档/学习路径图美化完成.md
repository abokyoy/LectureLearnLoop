### 🔧 **技术实现**

#### 动态半径计算
```javascript
.attr('r', d => {
    if (d.type === 'start' || d.type === 'end') return 35;
    if (d.type === 'milestone') return 30;
    
    const textLength = d.name ? d.name.length : 5;
    let baseRadius = 25;
    
    if (textLength > 8) {
        baseRadius = Math.max(25, Math.min(45, textLength * 2.5));
    }
    
    return baseRadius;
})
```

#### 边框区分
```javascript
.attr('stroke', d => {
    if (d.type === 'supplement') return '#C2185B';      // 深粉色
    if (d.type === 'foundation') return '#7B1FA2';      // 深紫色
    return '#fff';                                      // 白色
```
