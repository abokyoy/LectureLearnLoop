# 🔧 转写历史记录载入功能修复说明

## 🐛 **发现的问题**

用户反馈载入历史记录功能没有正确实现：
- **问题描述**：点击载入按钮后无法选择文件载入
- **根本原因**：前后端调用方式不匹配，后端使用同步返回，前端期望异步回调

## 🔍 **问题分析**

### **原始实现问题**
```python
# 后端：同步返回方式
@Slot(result=str)
def loadTranscriptHistory(self):
    # ... 文件选择和读取 ...
    return json.dumps(session_data, ensure_ascii=False)
```

```javascript
// 前端：期望异步回调方式
window.bridge.loadTranscriptHistory(function(result) {
    // 处理结果
});
```

**冲突点**：
- 后端使用同步返回值
- 前端期望异步回调函数
- QFileDialog在主线程中可能阻塞UI

## ✅ **修复方案**

### **后端修改：异步回调机制**
```python
@Slot()
def loadTranscriptHistory(self):
    """载入历史转写记录"""
    def on_file_selected():
        # 打开文件选择对话框
        file_path, _ = QFileDialog.getOpenFileName(
            self.main_window,
            "选择转写历史记录",
            audio_text_dir,
            "JSON文件 (*.json);;所有文件 (*.*)"
        )
        
        result = ""
        if file_path:
            try:
                # 读取文件内容
                with open(file_path, 'r', encoding='utf-8') as f:
                    session_data = json.load(f)
                result = json.dumps(session_data, ensure_ascii=False)
            except Exception as e:
                self.logger.error(f"❌ 读取文件失败: {e}")
                result = ""
        
        # 通知前端结果
        if self.main_window and self.main_window.web_view:
            js_code = f"""
            try {{
                if (typeof window.onTranscriptHistoryLoaded === 'function') {{
                    window.onTranscriptHistoryLoaded({json.dumps(result, ensure_ascii=False)});
                }}
            }} catch(e) {{
                console.error('载入历史记录回调出错:', e);
            }}
            """
            self.main_window.web_view.page().runJavaScript(js_code)
    
    # 使用QTimer延迟执行，避免阻塞UI
    QTimer.singleShot(100, on_file_selected)
```

### **前端修改：回调函数机制**
```javascript
// 载入触发函数
window.loadTranscriptHistory = function() {
    debugLog('载入历史转写记录');
    
    if (window.bridge && window.bridge.loadTranscriptHistory) {
        // 调用后端方法（无参数，使用回调机制）
        window.bridge.loadTranscriptHistory();
    } else {
        alert('载入功能不可用');
    }
};

// 后端载入完成的回调函数
window.onTranscriptHistoryLoaded = function(result) {
    debugLog('收到后端载入结果: ' + (result ? '有数据' : '无数据'));
    
    if (result && result.trim()) {
        try {
            const sessionData = JSON.parse(result);
            loadTranscriptSessionData(sessionData);
            debugLog('历史记录载入成功');
            alert('历史记录载入成功！');
        } catch (error) {
            debugError('解析历史记录失败: ' + error.message);
            alert('载入历史记录失败：文件格式错误');
        }
    } else {
        debugLog('用户取消载入或没有选择文件');
    }
};
```
