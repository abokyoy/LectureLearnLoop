# 熟练度颜色显示修复说明

## 问题描述
用户反馈"过拟合"知识点（ID为6，熟练度55分）在脑图中显示为灰色，而不是预期的中等深度橙色。同时，熟练度-1（未评估）的知识点文字颜色不够显眼。

## 问题分析 🔍

### 1. 数据验证
通过数据库查询确认：
```sql
ID 6: 过拟合 (Overfitting) - 熟练度: 55
```
数据库中的熟练度数据是正确的。

### 2. 根本原因
- **脑图缓存问题**：旧的脑图缓存中没有熟练度信息
- **文字颜色问题**：所有节点文字都硬编码为白色，在灰色背景上不够显眼
- **颜色映射缺失**：后端生成的脑图数据可能没有正确包含熟练度信息

## 技术实现细节

### 1. 后端数据合并
```python
def _merge_mastery_scores(self, mindmap_data: Dict, knowledge_points: List[Dict]) -> None:
    """将原始知识点的熟练度信息合并到脑图节点中"""
    mastery_map = {}
    for point in knowledge_points:
        point_id = str(point.get('id', ''))
        mastery_score = point.get('mastery_score', -1)
        mastery_map[point_id] = mastery_score
        mastery_map[f"kp_{point_id}"] = mastery_score
    
    # 为脑图节点添加熟练度信息
    for node in mindmap_data.get('nodes', []):
        if node.get('type') == 'knowledge_point':
            node_id = node.get('id', '')
            node['mastery_score'] = mastery_map.get(node_id, -1)
```

### 2. 前端颜色计算
```javascript
function getKnowledgePointColor(masteryScore) {
    if (masteryScore === -1) return '#E5E7EB';
    
    const score = Math.max(0, Math.min(100, masteryScore));
    const colors = [
        '#FEF3C7', '#FDE68A', '#FCD34D', '#FBBF24', '#F59E0B',
        '#D97706', '#B45309', '#92400E', '#78350F', '#451A03'
    ];
    
    const colorIndex = Math.floor(score / 10);
    return colors[Math.min(colorIndex, colors.length - 1)];
}
```
