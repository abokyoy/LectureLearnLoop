# 箭头显示问题修复说明

## 问题描述
用户反馈在知识脑图中看不到箭头，连线应该显示有向箭头来表示关系方向。

## 问题分析

### 可能的原因
1. **箭头位置不当**：refX值设置过大，箭头显示在节点圆圈之外
2. **箭头被遮挡**：连线直接连到圆心，箭头被圆圈遮挡
3. **箭头样式问题**：颜色、大小或路径定义有误
4. **SVG渲染问题**：marker定义或引用有误

## 修复措施

### 1. 优化箭头定义
```javascript
// 修复前：refX=20 (太大，箭头在圆圈外)
// 修复后：refX=10 (合适位置)
defs.append('marker')
    .attr('id', 'arrow')
    .attr('viewBox', '0 -5 10 10')
    .attr('refX', 10) // 箭头尖端位置
    .attr('refY', 0)
    .attr('markerWidth', 12)
    .attr('markerHeight', 12)
    .attr('orient', 'auto')
    .append('path')
    .attr('d', 'M0,-5L10,0L0,5')
    .attr('fill', '#3498db')
    .attr('stroke', '#3498db')
    .attr('stroke-width', 1);
```

### 2. 调整连线终点
```javascript
// 连线不直接连到圆心，而是连到圆圈边缘
const targetX = d.target.x - (dx / distance) * (targetRadius + 5); // 留出箭头空间
const targetY = d.target.y - (dy / distance) * (targetRadius + 5);
```

### 3. 增强视觉效果
- **箭头颜色**：使用蓝色 `#3498db` 与连线保持一致
- **连线颜色**：使用蓝色 `#3498db` 统一视觉风格
- **连线粗细**：增加到3px，更加明显
- **箭头大小**：markerWidth和markerHeight设为12，更大更清晰

### 4. 防止渲染错误
```javascript
// 避免除零错误
if (distance === 0) return;

// 清空之前的箭头定义，避免累积
svg.selectAll('defs').remove();
```

## 技术细节

### SVG Marker 参数说明
- **viewBox**: `"0 -5 10 10"` - 定义箭头的坐标系统
- **refX**: `10` - 箭头尖端在连线上的位置
- **refY**: `0` - 箭头在垂直方向的偏移
- **markerWidth/Height**: `12` - 箭头的显示大小
- **orient**: `"auto"` - 箭头自动朝向连线方向

### 路径定义
```
M0,-5L10,0L0,5
```
- M0,-5: 移动到左上角
- L10,0: 画线到右中点（箭头尖端）
- L0,5: 画线到左下角
- 形成一个三角形箭头

### 颜色方案
- **箭头**: `#3498db` (蓝色) - 与连线保持一致
- **连线**: `#3498db` (蓝色) - 统一视觉风格
- **文字**: `#555` (深灰) - 保持可读性
