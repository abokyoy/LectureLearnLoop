# 鱼骨图学习路径功能说明

## 🐟 **功能概述**

根据用户需求，已将学习路径图重新设计为**鱼骨图结构的线性学习计划**，提供更清晰的学习顺序指导。

### 🎯 **核心设计理念**

#### 线性学习计划
```
A ——— B ——— C ——— D ——— E  (主线：学习阶段)
|      |      |      |      |
xxx    yyy    zzz    www    vvv  (分支：具体知识点)
xxx    yyy    zzz    www    vvv
```

#### 鱼骨图结构
- **主干**：线性的学习阶段序列
- **分支**：每个阶段包含的具体知识点
- **归类**：现有知识点归属到相应阶段
- **补充**：LLM为每个阶段补充必要知识

## 🔄 **功能升级对比**

| 特性 | 旧版本（网状图） | 新版本（鱼骨图） |
|------|------------------|------------------|
| **结构** | 复杂网状关系 | 线性主线 + 分支 |
| **学习指导** | 关系展示 | 明确学习顺序 |
| **知识归类** | 分散展示 | 阶段性归类 |
| **视觉清晰度** | 复杂交错 | 主线清晰，分支明确 |
| **学习计划** | 需要自己规划 | 直接提供学习计划 |

## 🤖 **新的LLM提示词**

### 核心要求
```
作为一名{学科}领域的专家教师，请为学生制定一个**线性学习计划**，类似鱼骨图结构。

**任务要求：**
1. **设计线性主线**：制定5-7个学习阶段，形成A→B→C→D→E的线性路径
2. **知识点归类**：将学生的现有知识点归类到相应的学习阶段中
3. **补充缺失知识**：为每个阶段补充必要的前置知识或核心概念
4. **鱼骨图结构**：主线是学习阶段，知识点作为每个阶段的子节点
```

### 设计原则
- **线性进阶**：A→B→C→D→E，每个阶段有明确的学习目标
- **知识归类**：现有知识点必须归属到某个学习阶段
- **查漏补缺**：为缺少知识点的阶段补充必要内容
- **鱼骨结构**：主干是阶段，分支是具体知识点

## 🎨 **新的节点类型系统**

### 节点类型定义
- 🔵 **start**: 学习起点
- 🟠 **stage**: 学习阶段（主线节点）
- 🟢 **existing_kp**: 学生已有知识点
- 🩷 **supplement_kp**: LLM补充的知识点
- 🔴 **end**: 学习终点

### 视觉设计
- **学习阶段**：🟠 橙色 + 深橙色粗边框（4px）
- **已有知识点**：🟢 绿色 + 白色边框（2px）
- **LLM补充知识点**：🩷 粉色 + 深粉色边框（3px）

### 连线设计
- **主线连接**：🟠 橙色粗线（5px）+ 箭头
- **分支连接**：🟢 绿色细线（2px）+ 无箭头

## 🎨 **前端渲染优化**

### 鱼骨图布局算法
```javascript
// 主线节点水平排列
.force('x', d3.forceX(d => {
    if (d.type === 'start' || d.type === 'stage' || d.type === 'end') {
        return 100 + d.level * 150; // 水平主线
    }
    return d.x; // 知识点节点自由排列
}).strength(0.8))

// 主线节点在中央，知识点在上下分布
.force('y', d3.forceY(d => {
    if (d.type === 'start' || d.type === 'stage' || d.type === 'end') {
        return 250; // 主线在中央
    }
    return 250 + (Math.random() - 0.5) * 200; // 知识点上下分布
}).strength(0.3))
```

### 连线差异化
```javascript
.attr('stroke', d => {
    // 主线使用橙色粗线，分支使用绿色细线
    if ((d.source.type === 'start' || d.source.type === 'stage') && 
        (d.target.type === 'stage' || d.target.type === 'end')) {
        return '#FF9800'; // 橙色主线
    }
    return '#4CAF50'; // 绿色分支线
})
```
