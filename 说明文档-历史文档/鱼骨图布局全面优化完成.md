### 2. **知识点围绕分布算法**

#### 智能分组：
```javascript
// 按父阶段分组知识点
const stageGroups = {};
knowledgeNodes.forEach(node => {
    const parentStage = node.parent_stage || 'unknown';
    if (!stageGroups[parentStage]) {
        stageGroups[parentStage] = [];
    }
    stageGroups[parentStage].push(node);
});
```

#### 围绕分布：
```javascript
// 为每个阶段的知识点设置围绕分布
const radius = 120; // 围绕半径
const angleStep = (2 * Math.PI) / knowledgePoints.length;

knowledgePoints.forEach((kp, index) => {
    const angle = index * angleStep;
    // 上下交替分布，避免都在一侧
    const side = index % 2 === 0 ? 1 : -1;
    kp.x = stageX + Math.cos(angle) * radius;
    kp.y = stageY + side * (80 + Math.sin(angle) * 40);
});
```

### 3. **减少排斥力混乱**

#### 大幅降低排斥力：
```javascript
.force('charge', d3.forceManyBody().strength(d => {
    // 从-1200/-600大幅减少到-300/-150
    if (d.type === 'stage') return -300; // 减少主线节点排斥力
    return -150; // 减少知识点排斥力
}))
```

#### 优化连接距离：
```javascript
// 知识点连接距离从100px减少到80px，避免过度拉扯
return 80; // 阶段到知识点的距离
```
