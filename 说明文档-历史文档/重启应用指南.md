# 重启应用指南

## 🔄 **为什么需要重启**

我们刚才修改了学习路径功能的核心代码，从测试版本升级为真正的LLM调用版本。Python应用程序需要重启才能加载新的代码。

## 📋 **重启步骤**

### 1. **关闭当前应用**
在终端中按 `Ctrl+C` 停止应用程序，或者直接关闭应用窗口。

### 2. **重新启动应用**
```bash
python overlay_drag_corgi_app.py
```

### 3. **验证重启成功**
重启后，您应该看到应用程序重新初始化的日志：
```
✅ 使用 faster-whisper 包
📁 模板管理器初始化完成，模板目录: templates
🔗 开始设置WebChannel
...
```

## 🧪 **测试学习路径功能**

重启后，请按以下步骤测试：

1. **进入脑图页面**：选择"机器学习"学科
2. **点击"梳理知识点"按钮**
3. **观察日志变化**：

### 预期的正确日志（重启后）：
