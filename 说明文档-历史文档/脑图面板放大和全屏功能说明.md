# 脑图面板放大和全屏功能说明

## 功能概述
为"练-基于学习资料练习"页面的知识脑图添加了面板放大和全屏显示功能，提供更好的学习体验。

## 主要改进

### 1. 脑图面板放大
**容器尺寸优化**：
- 最大宽度：`max-w-6xl` → `max-w-7xl` (更宽的显示区域)
- 脑图容器高度：`min-h-96` (384px) → `min-height: 700px` (增大82%)
- SVG显示区域：`height: 500px` → `height: 600px` (增大20%)

**视觉效果提升**：
- 更大的显示空间，脑图节点分布更合理
- 减少节点重叠，提高可读性
- 更好的缩放和拖拽体验

### 2. 全屏功能实现

#### 全屏按钮
- **位置**：页面头部右侧，与返回按钮对称
- **样式**：蓝色背景，带全屏图标和文字
- **图标**：Material Icons的`fullscreen`图标
- **交互**：悬停效果，点击切换全屏

#### 全屏模式特性
- **完全覆盖**：占据整个屏幕空间 (100vw × 100vh)
- **最高层级**：z-index: 9999，确保在最顶层
- **自适应布局**：SVG区域自动调整为 `calc(100vh - 140px)`
- **无边距限制**：移除所有容器宽度限制

#### 退出全屏
- **工具栏按钮**：红色退出按钮，带`fullscreen_exit`图标
- **键盘快捷键**：ESC键快速退出
- **自动调整**：退出时自动恢复原始布局

## 技术实现

### CSS样式类
```css
.fullscreen-mode {
    position: fixed !important;
    top: 0 !important;
    left: 0 !important;
    width: 100vw !important;
    height: 100vh !important;
    z-index: 9999 !important;
    background: white !important;
    padding: 20px !important;
    margin: 0 !important;
    max-width: none !important;
}
```

### JavaScript功能函数

#### 全屏切换
```javascript
function toggleFullscreen() {
    if (!isFullscreen) {
        enterFullscreen();
    } else {
        exitFullscreen();
    }
}
```

#### 进入全屏
```javascript
function enterFullscreen() {
    // 添加全屏样式类
    mindmapPage.classList.add('fullscreen-mode');
    
    // 切换按钮显示
    fullscreenBtn.classList.add('hidden');
    exitFullscreenBtn.classList.remove('hidden');
    
    // 重新调整SVG尺寸
    setTimeout(() => {
        const container = document.getElementById('mindmapSvgContainer');
        const rect = container.getBoundingClientRect();
        svg.attr('width', rect.width).attr('height', rect.height);
        svg.call(zoom.transform, d3.zoomIdentity);
    }, 100);
}
```

#### 退出全屏
```javascript
function exitFullscreen() {
    // 移除全屏样式类
    mindmapPage.classList.remove('fullscreen-mode');
    
    // 恢复按钮显示
    fullscreenBtn.classList.remove('hidden');
    exitFullscreenBtn.classList.add('hidden');
    
    // 重新调整SVG尺寸
    setTimeout(() => {
        // SVG尺寸自适应调整
    }, 100);
}
```

### 键盘快捷键支持
```javascript
document.addEventListener('keydown', function(e) {
    // F11键切换全屏
    if (e.key === 'F11') {
        e.preventDefault();
        toggleFullscreen();
    }
    // ESC键退出全屏
    if (e.key === 'Escape' && isFullscreen) {
        exitFullscreen();
    }
});
```
