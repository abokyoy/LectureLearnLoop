# 🎯 转写内容多选总结功能实现说明

## 📋 **用户需求**

用户要求实现转写内容的多选功能：

1. **多选机制**：每一块转写内容可以被点击选中，支持多选
2. **AI总结**：选中多条内容后，点击"手动总结选中内容"按钮调用大模型进行总结
3. **智能插入**：总结内容插入到文档预览区中打开的文档，优先选择光标位置，无光标则插入到文档末尾
4. **已总结标记**：被总结过的内容前面显示小√图标

## ✅ **完成的功能实现**

### **1. 多选机制改造** ✅

**修改前**：单选模式
```javascript
// 移除其他选中状态，只能选中一个
const allItems = transcriptDiv.querySelectorAll('.flex');
allItems.forEach(item => {
    item.classList.remove('bg-bg-light-green');
});

// 选中当前项
this.classList.add('bg-bg-light-green');
selectedTranscriptText = text; // 单个文本变量
```

**修改后**：多选模式
```javascript
// 切换选中状态，支持多选
const isSelected = this.classList.contains('bg-bg-light-green');

if (isSelected) {
    // 取消选中
    this.classList.remove('bg-bg-light-green');
    const index = selectedTranscriptTexts.findIndex(item => item.text === text);
    if (index > -1) {
        selectedTranscriptTexts.splice(index, 1);
    }
} else {
    // 选中
    this.classList.add('bg-bg-light-green');
    selectedTranscriptTexts.push({
        text: text,
        element: this,
        timestamp: timestamp.textContent
    });
}
```

### **3. 按钮状态管理** ✅

**新增函数**：`updateManualSummarizeButton()`
```javascript
function updateManualSummarizeButton() {
    const btn = document.getElementById('manual-summarize-btn');
    if (!btn) return;
    
    if (selectedTranscriptTexts.length > 0) {
        btn.disabled = false;
        const totalChars = selectedTranscriptTexts.reduce((sum, item) => sum + item.text.length, 0);
        btn.innerHTML = `<span class="material-icons-outlined mr-2 text-sm">auto_awesome</span>总结选中内容 (${selectedTranscriptTexts.length}条, ${totalChars}字)`;
    } else {
        btn.disabled = true;
        btn.innerHTML = '<span class="material-icons-outlined mr-2 text-sm">auto_awesome</span>手动总结选中内容';
    }
}
```

**按钮状态显示**：
- **无选中**：`手动总结选中内容` (禁用状态)
- **有选中**：`总结选中内容 (3条, 156字)` (启用状态)
- **总结中**：`AI总结中...` (加载动画)

**光标位置检测**：
```javascript
function insertSummaryToDocument(summary) {
    if (isEditMode) {
        const editContent = document.getElementById('edit-content');
        let cursorPos = editContent.selectionStart;
        
        // 如果光标位置为0或者编辑器没有焦点，插入到文档末尾
        if (cursorPos === 0 && editContent !== document.activeElement) {
            cursorPos = editContent.value.length;
        }
        
        const summaryText = '\n\n## 🤖 AI总结\n\n' + summary + '\n\n';
        // 在指定位置插入总结内容
    }
}
```

**插入逻辑**：
- **优先级1**：光标位置（如果编辑器有焦点且光标不在开头）
- **优先级2**：文档末尾（如果没有明确的光标位置）
- **自动切换**：如果在预览模式，提示用户切换到编辑模式

### **6. 已总结标记** ✅

**标记函数**：
```javascript
function markTranscriptItemsAsSummarized() {
    selectedTranscriptTexts.forEach(item => {
        const element = item.element;
        const timestamp = element.querySelector('span');
        
        // 检查是否已经有标记
        if (!timestamp.querySelector('.summarized-mark')) {
            // 添加小√图标
            const checkMark = document.createElement('span');
            checkMark.className = 'summarized-mark text-green-500 ml-1';
            checkMark.innerHTML = '✓';
            checkMark.title = '已总结';
            timestamp.appendChild(checkMark);
        }
    });
}
```

### **7. 选中状态管理** ✅

**清空选中函数**：
```javascript
function clearTranscriptSelection() {
    selectedTranscriptTexts.forEach(item => {
        const element = item.element;
        element.classList.remove('bg-bg-light-green');
        const textP = element.querySelector('p');
        if (textP) {
            textP.classList.remove('text-text-dark-brown');
            textP.classList.add('text-text-medium-brown');
        }
    });
    selectedTranscriptTexts = [];
}
```
