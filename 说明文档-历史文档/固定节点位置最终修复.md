## 📊 **fx/fy 固定位置的工作原理**

### D3.js 力导向图中的位置控制：
- `node.x, node.y` - 当前位置，会被力导向图动态改变
- `node.fx, node.fy` - 固定位置，力导向图不能改变这些值
- 当设置了`fx, fy`后，节点会被"钉"在指定位置

### 修复前：
```javascript
kp.x = calculatedX;  // 设置初始位置
kp.y = calculatedY;  // 但力导向图会改变这些值
// 结果：节点被力导向图"吹"到其他位置
```

### 修复后：
```javascript
kp.x = calculatedX;   // 设置初始位置
kp.y = calculatedY;   
kp.fx = kp.x;        // 固定X位置
kp.fy = kp.y;        // 固定Y位置
// 结果：节点被"钉"在精确位置，不会移动
```
