### 2. **修复拖动子节点飞到屏幕外的问题**

#### 问题根因：
在`dragended`函数中，知识点节点的固定位置被错误地释放：
```javascript
// 问题代码
} else {
    // 知识点节点释放固定
    d.fx = null;  // ❌ 这会让节点被力导向图拉走！
    d.fy = null;  // ❌ 导致节点飞到意外位置！
}
```

#### 修复方案：
```javascript
// 修复后的代码
} else if (d.type === 'existing_kp' || d.type === 'supplement_kp') {
    // 知识点节点：保持在当前拖动位置，不要释放固定
    d.fx = d.x;  // ✅ 固定在拖动后的X位置
    d.fy = d.y;  // ✅ 固定在拖动后的Y位置
    log(`🔒 拖动结束，固定知识点 ${d.name} 在新位置: (${d.fx}, ${d.fy})`);
} else {
    // 其他节点释放固定
    d.fx = null;
    d.fy = null;
}
```

## 🎯 **技术要点**

### 1. **D3.js固定位置机制**
- `d.fx, d.fy` - 固定位置，力导向图不会改变
- `d.x, d.y` - 当前位置，可以被力导向图改变
- 设置`d.fx = null`会释放固定，让节点受力导向图控制

### 2. **拖动事件处理**
- `dragstarted` - 开始拖动时设置固定位置
- `dragged` - 拖动过程中更新位置
- `dragended` - 拖动结束时决定是否保持固定

### 3. **节点类型区分**
```javascript
if (d.type === 'start' || d.type === 'stage' || d.type === 'end') {
    // 主线节点：始终固定在水平线上
} else if (d.type === 'existing_kp' || d.type === 'supplement_kp') {
    // 知识点节点：拖动后固定在新位置
} else {
    // 其他节点：可以自由移动
}
```
