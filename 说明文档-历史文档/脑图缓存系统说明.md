# 脑图缓存系统说明

## 功能概述
实现了智能的脑图数据缓存系统，第一次点击进入时检查数据库是否有缓存，如果没有则调用大模型生成，如果有则直接显示缓存，大大提升了用户体验和系统性能。

## 核心功能

### 1. 智能缓存检查
**自动缓存检测**：
- 用户点击学科时，系统首先检查数据库中是否存在该学科的脑图缓存
- 如果存在缓存，直接加载显示，响应速度极快
- 如果不存在缓存，调用LLM生成新脑图并自动保存到缓存

**缓存状态显示**：
```javascript
// 前端显示缓存状态
if (cacheStatus === 'from_cache') {
    log(`💾 使用缓存的脑图数据`);
    cacheStatusElement.innerHTML = `<span class="text-green-600">💾 缓存数据</span> | 版本: ${version}`;
} else if (cacheStatus === 'newly_generated') {
    log(`🆕 使用新生成的脑图数据`);
    cacheStatusElement.innerHTML = `<span class="text-blue-600">🆕 新生成</span> | 已缓存`;
}
```

### 2. 数据库缓存存储
**缓存表结构**：
```sql
knowledge_mindmaps (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL DEFAULT '0001',
    subject_name TEXT NOT NULL,
    mindmap_data TEXT NOT NULL,  -- JSON格式的脑图数据
    version INTEGER DEFAULT 1,
    created_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, subject_name)
)
```

**缓存策略**：
- 每个用户每个学科只保存一份最新的脑图缓存
- 支持版本管理，可以追踪缓存的更新历史
- 自动记录创建和更新时间

### 3. 缓存管理功能
**手动刷新缓存**：
- 页面右上角提供"刷新"按钮
- 点击后清除当前学科的缓存，重新调用LLM生成
- 支持加载状态显示，用户体验友好

## 技术实现

### 1. 后端缓存逻辑
**优化的缓存检查**：
```python
def generate_or_get_mindmap(self, subject_name: str) -> Optional[Dict]:
    """生成或获取学科的知识脑图（带缓存优化）"""
    print(f"🔍 检查学科 '{subject_name}' 的脑图缓存...")
    
    # 首先尝试获取现有脑图缓存
    existing_mindmap = self.mindmap_manager.get_mindmap(subject_name)
    if existing_mindmap:
        print(f"✅ 找到缓存脑图 - 版本: {existing_mindmap.get('version', 1)}")
        return existing_mindmap
    
    print(f"❌ 未找到缓存，开始生成新脑图...")
    # 调用LLM生成新脑图并保存到缓存
```

**详细的日志记录**：
- 缓存命中/未命中的详细日志
- LLM生成过程的进度跟踪
- 缓存保存成功/失败的状态记录

### 2. 前端缓存状态显示
**实时状态更新**：
- 页面头部显示当前数据的缓存状态
- 区分缓存数据、新生成数据、加载失败等状态
- 使用不同颜色和图标表示不同状态

**用户交互优化**：
- 刷新按钮带有加载动画
- 操作过程中禁用按钮防止重复点击
- 详细的操作日志显示在调试面板

### 3. 数据流程优化
**高效的数据流**：
1. **用户点击学科** → 前端调用`getOrGenerateMindmap`
2. **后端缓存检查** → 查询`knowledge_mindmaps`表
3. **缓存命中** → 直接返回缓存数据，标记`cache_status: 'from_cache'`
4. **缓存未命中** → 调用LLM生成 → 保存到缓存 → 返回数据，标记`cache_status: 'newly_generated'`
5. **前端渲染** → 显示缓存状态 → 渲染D3.js脑图
