# 节点筛选功能说明

## 功能概述
实现了点击绿色和蓝色圆圈时的智能节点筛选功能，用户可以专注查看特定分类或中心节点的子节点，提供更清晰的知识结构视图。

## 核心功能

### 1. 智能节点筛选
**点击筛选**：
- 点击蓝色圆圈（中心节点）：显示该学科的所有直接分类
- 点击绿色圆圈（分类节点）：显示该分类下的所有知识点
- 点击橙色圆圈（知识点）：显示知识点详情（原有功能）

**视觉效果**：
- 相关节点：保持正常显示（opacity: 1）
- 点击的节点：添加蓝色光晕高亮效果
- 无关节点：半透明显示（opacity: 0.1）
- 相关连线：正常显示
- 无关连线：半透明显示

### 2. 一键还原功能
**双击还原**：
- 再次点击同一个节点：自动还原显示所有节点
- 点击"清除筛选"按钮：手动还原显示

**状态管理**：
- 自动显示/隐藏"清除筛选"按钮
- 重新渲染脑图时自动重置筛选状态

### 3. 用户界面优化
**视觉提示**：
- 工具栏添加操作提示：💡 点击 🔵🟢 筛选子节点
- 筛选时显示紫色"清除筛选"按钮
- 详细的操作日志反馈

## 技术实现

### 1. 全局状态管理
```javascript
// 全局变量
let filteredNodeId = null; // 当前筛选的节点ID
let originalNodesVisibility = new Map(); // 保存原始节点可见性状态
```

### 2. 节点关系分析
```javascript
// 获取所有边数据来找出子节点
const edges = currentMindmapData.edges || [];
const childNodeIds = new Set();

// 找出所有以当前节点为源的边的目标节点
edges.forEach(edge => {
    if (edge.source === clickedNode.id || (typeof edge.source === 'object' && edge.source.id === clickedNode.id)) {
        const targetId = typeof edge.target === 'object' ? edge.target.id : edge.target;
        childNodeIds.add(targetId);
    }
});
```

### 3. 视觉效果处理
```javascript
// 节点筛选显示
nodeGroups.each(function(d) {
    const nodeGroup = d3.select(this);
    if (childNodeIds.has(d.id)) {
        // 显示相关节点，添加高亮效果
        nodeGroup.style('opacity', 1)
                 .style('filter', d.id === clickedNode.id ? 'drop-shadow(0 0 10px rgba(59, 130, 246, 0.8))' : 'none');
    } else {
        // 隐藏不相关节点
        nodeGroup.style('opacity', 0.1);
    }
});
```

### 4. 连线和标签处理
```javascript
// 只显示相关的连线
links.each(function(d) {
    const link = d3.select(this);
    const sourceId = typeof d.source === 'object' ? d.source.id : d.source;
    const targetId = typeof d.target === 'object' ? d.target.id : d.target;
    
    if (childNodeIds.has(sourceId) && childNodeIds.has(targetId)) {
        link.style('opacity', 1);
    } else {
        link.style('opacity', 0.1);
    }
});
```

## 使用场景

### 1. 学科结构分析
**点击中心节点（蓝色）**：
- 场景：想了解某个学科的主要分类
- 效果：只显示学科的直接分类，隐藏具体知识点
- 用途：获得学科的宏观结构视图

### 2. 分类深入学习
**点击分类节点（绿色）**：
- 场景：专注学习某个特定分类
- 效果：只显示该分类下的所有知识点
- 用途：深入学习特定领域，避免干扰

### 3. 知识点详情查看
**点击知识点（橙色）**：
- 场景：查看具体知识点的详细信息
- 效果：弹出知识点详情面板
- 用途：获取知识点的完整描述和相关信息

## 交互流程

### 1. 筛选操作流程
1. **用户点击** → 绿色或蓝色圆圈
2. **系统分析** → 找出所有子节点关系
3. **视觉筛选** → 高亮相关节点，淡化无关节点
4. **界面更新** → 显示"清除筛选"按钮
5. **日志反馈** → 显示筛选结果统计

### 2. 还原操作流程
1. **用户操作** → 再次点击同一节点 或 点击"清除筛选"按钮
2. **状态重置** → 清除筛选状态变量
3. **视觉还原** → 所有节点和连线恢复正常显示
4. **界面更新** → 隐藏"清除筛选"按钮
5. **日志反馈** → 确认还原完成
