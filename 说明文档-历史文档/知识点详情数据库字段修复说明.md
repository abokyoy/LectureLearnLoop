# 知识点详情数据库字段修复说明

## 问题描述
用户反馈知识点详情页面出现错误：`no such column: subject_name`，需要修正数据库查询中的字段名称问题。

## 问题分析

### 1. 数据库表结构确认

#### knowledge_points表（正确）
```sql
CREATE TABLE knowledge_points (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL DEFAULT '0001',
    subject_name TEXT NOT NULL,
    point_name TEXT NOT NULL,
    core_description TEXT NOT NULL,  -- 描述字段
    mastery_score INTEGER DEFAULT 50,
    created_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### practice_records表（正确）
```sql
CREATE TABLE practice_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL DEFAULT '0001',
    subject_name TEXT NOT NULL,
    knowledge_point_id INTEGER NOT NULL,
    question_content TEXT NOT NULL,
    user_answer TEXT NOT NULL,
    is_correct INTEGER NOT NULL,
    practice_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### notes表（实际结构）
```sql
CREATE TABLE notes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL,
    note_uuid TEXT,
    file_name TEXT,
    file_path TEXT,
    title TEXT,
    content_hash TEXT,  -- 注意：没有content字段
    created_time TIMESTAMP,
    updated_time TIMESTAMP
);
```

### 2. 错误原因分析

**主要问题**：
1. `notes`表没有`content`字段，只有`content_hash`字段
2. `notes`表没有`subject_name`字段
3. `favorite_questions`表可能不存在

**错误查询示例**：
```sql
-- 错误：notes表没有content和subject_name字段
SELECT COUNT(*) FROM notes 
WHERE subject_name = ? AND content LIKE ?
```

## 修复方案

### 1. 知识点描述获取
**修复前**：错误地查询不存在的字段
**修复后**：正确使用`core_description`字段
```python
cursor.execute(
    """SELECT id, point_name, core_description, mastery_score, subject_name, created_time
       FROM knowledge_points WHERE id = ?""",
    (knowledge_point_id,)
)
# 正确映射：result[2] -> core_description
detail["description"] = result[2]
```

### 2. 练习记录统计
**用户需求**：获取所有练习记录数量，不仅仅是错题
**修复前**：
```python
SELECT COUNT(*) FROM practice_records 
WHERE knowledge_point_id = ? AND is_correct = 0  -- 只统计错题
```

**修复后**：
```python
SELECT COUNT(*) FROM practice_records 
WHERE knowledge_point_id = ?  -- 统计所有练习记录
```

### 3. 关联笔记查询
**修复前**：使用不存在的字段
```python
SELECT COUNT(*) FROM notes 
WHERE subject_name = ? AND content LIKE ?  -- 错误字段
```

**修复后**：只使用存在的字段
```python
SELECT COUNT(*) FROM notes 
WHERE title LIKE ?  -- 只通过标题匹配
```

### 4. 收藏题目查询
**修复前**：没有异常处理
**修复后**：添加try-catch处理
```python
try:
    cursor.execute(
        """SELECT COUNT(*) FROM favorite_questions 
           WHERE knowledge_point_id = ?""",
        (knowledge_point_id,)
    )
    favorite_count = cursor.fetchone()[0]
except Exception as favorite_error:
    self.logger.warning(f"获取收藏题目数量失败: {favorite_error}")
    favorite_count = 0
```
