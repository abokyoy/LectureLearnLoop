# 脑图视觉效果优化说明

## 优化目标
解决"练-基于学习资料练习"页面中脑图的视觉问题：圆圈太小，文字太大，文字超出圆圈范围。

## 优化内容

### 1. 圆圈大小优化
**修改前**：
- 中心节点：半径 30px
- 分类节点：半径 25px  
- 知识点：半径 20px

**修改后**：
- 中心节点：半径 45px (+50%)
- 分类节点：半径 38px (+52%)
- 知识点：半径 32px (+60%)

### 2. 文字大小优化
**修改前**：
- 中心节点：14px
- 其他节点：12px

**修改后**：
- 中心节点：13px (略微减小)
- 分类节点：11px (适中)
- 知识点：10px (更小更精致)

### 3. 文字显示优化

#### 多行文本支持
- **中心节点**：最多2行，每行6个字符
- **分类节点**：最多2行，每行5个字符
- **知识点**：最多2行，每行4个字符

#### 智能文字处理
- 自动换行：按字符数限制分行
- 省略号处理：超出限制时自动添加".."
- 垂直居中：多行文本在圆圈中垂直居中显示

#### 视觉增强
- 添加文字阴影：`1px 1px 2px rgba(0,0,0,0.3)`
- 改善文字可读性和立体感
- 保持白色文字在彩色背景上的对比度

## 技术实现

### 圆圈大小动态设置
```javascript
.attr('r', d => {
    if (d.type === 'center') return 45;      // 中心节点
    if (d.type === 'category') return 38;    // 分类节点
    return 32;                               // 知识点
})
```

### 多行文本处理算法
```javascript
// 将文本分行
const words = d.name.split('');
const lines = [];
let currentLine = '';

for (let i = 0; i < words.length; i++) {
    if (currentLine.length < maxCharsPerLine) {
        currentLine += words[i];
    } else {
        lines.push(currentLine);
        currentLine = words[i];

    }
}
```
