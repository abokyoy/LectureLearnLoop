# 学习路径知识点详情功能实现

## 🎯 **功能需求**

用户要求：在学习路径图中支持点击已经存在的知识点，打开对应的知识详情页面，显示正确的信息，保持和知识脑图一致。

## 🔍 **问题分析**

### 现状：
1. **知识脑图**：已有完整的知识点详情功能，点击`knowledge_point`类型节点可查看详情
2. **学习路径图**：节点类型为`existing_kp`，与知识脑图的`knowledge_point`不同
3. **数据结构差异**：学习路径中的节点使用`original_kp_id`字段存储真实的知识点ID

### 需要解决：
- 统一两种页面的知识点详情显示逻辑
- 正确处理学习路径中`existing_kp`类型节点的ID映射
- 确保LLM推荐的节点（如果有对应数据库记录）也能被点击

## 🔧 **实现方案**

#### 修改后：
```javascript
// 支持知识脑图的knowledge_point和学习路径的existing_kp类型
if (window.bridge && window.bridge.getKnowledgePointDetail && 
    (node.type === 'knowledge_point' || node.type === 'existing_kp')) {
    
    let realId;
    
    // 学习路径中的existing_kp节点使用original_kp_id
    if (node.type === 'existing_kp' && node.original_kp_id) {
        realId = node.original_kp_id;
        log(`🔍 学习路径节点，使用original_kp_id: ${realId}`);
    } else {
        // 知识脑图中的knowledge_point节点，提取真实的知识点ID（去掉kp_前缀）
        realId = node.id.startsWith('kp_') ? node.id.substring(3) : node.id;
        log(`🔍 知识脑图节点，提取ID: ${realId}`);
    }
    // ...
}
```

### 2. **增强点击交互逻辑**

#### 鼠标样式设置：
```javascript
.style('cursor', d => {
    if (d.type === 'stage') return 'pointer';
    if (d.type === 'existing_kp' && d.original_kp_id) return 'pointer';
    
    // 检查LLM推荐节点是否有original_kp_id（可点击）
    const llmRecommendedNodes = [
        '账户登录与切换', '模型配置', '云环境管理', 
        '系统状态查看', '成本监控', 'login', 'logout',
        'model', 'status', 'cost', 'gauntlet', 'compact', 'compaq'
    ];
    const nodeName = (d.name || '').toLowerCase();
    const isLLMRecommended = llmRecommendedNodes.some(keyword => 
        nodeName.includes(keyword.toLowerCase()) || 
        keyword.toLowerCase().includes(nodeName)
    );
    
    if (isLLMRecommended && d.original_kp_id) return 'pointer';
    
    return 'default';
});
```

#### 点击事件处理：
```javascript
.on('click', function(event, d) {
    if (d.type === 'stage') {
        event.stopPropagation();
        highlightStageAndChildren(d);
    } else if (d.type === 'existing_kp' && d.original_kp_id) {
        event.stopPropagation();
        showKnowledgePointDetail(d);
    } else {
        // 检查LLM推荐节点是否有original_kp_id（可点击）
        const llmRecommendedNodes = [...];
        const nodeName = (d.name || '').toLowerCase();
        const isLLMRecommended = llmRecommendedNodes.some(keyword => 
            nodeName.includes(keyword.toLowerCase()) || 
            keyword.toLowerCase().includes(nodeName)
        );
        
        if (isLLMRecommended && d.original_kp_id) {
            event.stopPropagation();
            showKnowledgePointDetail(d);
        }
    }
})
```

## 📊 **支持的节点类型**

### 1. **知识脑图节点**
- **类型**：`knowledge_point`
- **ID格式**：`kp_123`（需要去掉kp_前缀）
- **数据源**：直接使用处理后的ID查询数据库

### 2. **学习路径已有知识点**
- **类型**：`existing_kp`
- **ID字段**：`original_kp_id`（直接使用）
- **数据源**：使用original_kp_id查询数据库

### 3. **LLM推荐节点**
- **类型**：可能是`existing_kp`或其他
- **识别方式**：通过节点名称关键词匹配
- **条件**：必须有`original_kp_id`才可点击

## 🎨 **交互效果**

### 可点击节点的视觉标识：
- **鼠标悬停**：显示手型光标（`pointer`）
- **点击反馈**：阻止事件冒泡，打开详情层

### 不可点击节点：
- **鼠标悬停**：显示默认光标（`default`）
- **点击无效果**：不响应点击事件

## 🔄 **数据流程**

```
1. 用户点击学习路径中的知识点
   ↓
2. 检查节点类型和original_kp_id
   ↓
3. 调用showKnowledgePointDetail(node)
   ↓
4. 识别节点类型：existing_kp
   ↓
5. 使用original_kp_id查询后端
   ↓
6. 调用window.bridge.getKnowledgePointDetail(realId)
   ↓
7. 解析响应并更新详情层
   ↓
8. 显示知识点详情（与知识脑图一致）
```
