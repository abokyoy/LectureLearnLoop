# 学习路径图功能实现说明

## 🎯 **功能概述**

在知识脑图页面新增"梳理知识点"功能，生成学习路径图，区别于知识脑图：

- **知识脑图**：展示知识点的关系和分类
- **学习路径图**：展示学习的先后顺序和依赖关系，指导学习路径

## ✅ **核心功能实现**

### 1. **前端界面** ✅
- **按钮位置**：在刷新和全屏按钮之间
- **按钮样式**：绿色背景，树形图标，"梳理知识点"文字
- **视图切换**：支持脑图视图和学习路径视图的切换
- **返回功能**：学习路径视图中显示"返回脑图"按钮

### 2. **后端API** ✅
- **`getOrGenerateLearningPath(subject_name)`**：获取或生成学习路径
- **`clearLearningPathCache(subject_name)`**：清除学习路径缓存
- **数据库表**：`learning_paths`表存储学习路径数据

### 3. **LLM路径生成** ✅
- **智能分析**：分析知识点的学习顺序和依赖关系
- **路径设计**：确定基础前置知识、依赖关系、高级内容
- **结构化输出**：生成符合D3.js渲染的JSON格式数据

### 4. **可视化渲染** ✅
- **层次化布局**：按学习层级排列节点
- **方向性连线**：带箭头的连线表示学习顺序
- **节点类型区分**：
  - 🔵 **start**: 学习起点（蓝色）
  - 🟢 **knowledge_point**: 具体知识点（绿色）
  - 🟠 **milestone**: 重要里程碑（橙色）
  - 🔴 **end**: 学习终点（红色）

### 5. **缓存机制** ✅
- **数据库存储**：学习路径数据保存到`learning_paths`表
- **版本管理**：支持版本号和更新时间
- **缓存优先**：优先使用缓存，缓存失效时重新生成

## 🏗️ **技术架构**

### 数据库设计
```sql
CREATE TABLE learning_paths (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL DEFAULT '0001',
    subject_name TEXT NOT NULL,
    path_data TEXT NOT NULL,
    version INTEGER DEFAULT 1,
    created_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, subject_name)
);
```

## 🎨 **前端实现特点**

### 视图管理
- **双视图模式**：知识脑图视图 ↔ 学习路径视图
- **状态保持**：切换视图时保持数据状态
- **标题更新**：动态更新页面标题显示当前视图

### 渲染特性
- **层次化力导向图**：按level层级排列，体现学习顺序
- **方向性箭头**：绿色箭头表示学习路径方向
- **节点大小区分**：不同类型节点使用不同大小
- **颜色编码**：通过颜色区分节点类型和重要性

### 交互功能
- **拖拽支持**：节点可拖拽调整位置
- **防重复调用**：避免重复生成学习路径
- **加载状态**：生成过程中显示加载动画

## 🔄 **使用流程**

1. **进入脑图页面**：选择学科，查看知识脑图
2. **点击梳理知识点**：点击绿色"梳理知识点"按钮
3. **LLM分析生成**：后端调用LLM分析知识点关系
4. **路径图渲染**：前端渲染学习路径图
5. **查看学习路径**：按照路径顺序规划学习
6. **返回脑图**：点击"返回脑图"切换回知识脑图
