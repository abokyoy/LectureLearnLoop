## 3. 接口契约表（r2 新增/变更端点）

通用：全部 `Bearer` 鉴权（缺失→401）；响应 `{success, data|error}`（kp-polish 蓝图为平铺 `{success, ...}`）；跨用户 id 引用→404。

### 3.1 共享三件套（routes_knowledge.py）
| 端点 | 方法 | 入参 | 正常出参 | 异常 |
|---|---|---|---|---|
| /api/kb/`kind`/`rid`/stars | POST | kind∈{kp,error}；difficulty?/importance?（0-10 分，服务端截断） | data.updated | kind 非法/双空 400；ValueError 400；行不存在 404 |
| /api/kb/`kind`/`rid`/mastery_manual | POST | value 0-100 | data.{mastery, manual:true}；写曲线历史；置 mastery_manual=1 | 越界 400；404 |
| /api/kb/`kind`/`rid`/curve | GET | — | data.{points:[{ts,mastery,retrievability}],count}（error 的 R 为 null） | 404（实体不存在/非本人，R2-008 后与 stars 同口径） |

业务规则：手动熟练度=最高优先级，标记期间 decay_flush 不改写；下一次真实复习 apply_review 自动清标记恢复 FSRS 派生。

### 3.2 kp-polish 蓝图
| 端点 | 方法 | 要点 |
|---|---|---|
| /api/kp-polish/subjects | GET | 科目名列表 |
| /api/kp-polish/kps | GET | sort=created\|importance\|difficulty\|last_review\|learn_count\|mastery；dir/subject/limit/offset；非法→400 |
| /api/kp-polish/kp/`pid`/detail | GET | 含星值/manual 标记/学习次数 |
| /api/kp-polish/extract-file | POST | 带 suggested_{difficulty,importance}_score（0-10，0 不回退）；积分不足 credits_insufficient |
| /api/kp-polish/confirm | POST | items[{action:new\|merge\|skip,...}]；merge 默认不覆盖星值，stars_override 显式才写 |

### 3.3 err-polish 蓝图
| 端点 | 方法 | 要点 |
|---|---|---|
| /api/err-polish/subjects-stats | GET | 各科错题数/平均熟练度/今日到期 |
| /api/err-polish/errors | GET | sort 8 维含 kp/error_rate；learn_count/wrong_count/error_rate 按 question_hash 聚合（老数据题干兜底）；keyword/kp_id 筛选；非法参数 400；limit 超上限钳位到 200（容错设计，R2 裁定） |
| /api/err-polish/errors | POST | 直插+三级星继承，返回 stars_source |
| /api/err-polish/sprint | POST | count 1-50（前端 5/10）；整卷一次生成；池不足注明；**空池 practice_id=null 不落会话** |
| /api/err-polish/sprint/`pid` | GET | 回取续做 |
| /api/err-polish/sprint/`pid`/submit | POST | Q1 按错题行 min 折叠，逐题 rating 仅返回体；finish=false 部分结算；use_llm 积分不足→402 无副作用 |
| /api/err-polish/error/`eid`/attempt | POST | 单题流水+排期；已删实体→404 且零流水 |
| /api/kb/errors/`eid`（PUT，变更） | PUT | 入池冻结题干→409 |

### 3.4 memory 蓝图
| 端点 | 方法 | 要点 |
|---|---|---|
| /api/memory/cards | POST | {card_type,ref_id,front?,back?}；幂等（重复 created=false 返既有卡）；缺省自动快照；非法 400/实体缺失 404 |
| /api/memory/cards | GET | card_type/subject 过滤，含熟练度摘要 |
| /api/memory/cards/`id` | GET/DELETE | user_id 隔离 |
| /api/memory/cards/`id`/rate | POST | self_assessment 4 档→apply_review(card_type,ref_id)；非法档 400 |
| /api/memory/recommend | POST | {card_type,count,difficulty_mix?,subject?,type?}；池不足返回实际数+note |

### 3.5 桥层变更（routes_bridge.py，旧协议保持）
generate-questions / practice/new：LLM prompt 带难度/重要度输出，`data` 保持纯文本，新增 `questions_meta`；evaluate-answers：透传 `judgement`+`answer_quality`；save-errors：逐条入库+hash/题干快照/星值补写，支持整卷 meta 回链；generate-assessment：JSON 增 difficulty_star/importance_star→写 0-10 分。
