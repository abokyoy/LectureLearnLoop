## 一、系统组成

| 组件 | 位置 | 说明 |
|------|------|------|
| Python 服务端 | `server/`（Flask 3，监听 `127.0.0.1:6001`） | 多用户认证(JWT)、知识点/错题/脑图/学科业务库、笔记 vault（按用户隔离）、DeepSeek LLM 封装、Deepgram key 下发 |
| Electron 客户端（源码） | `desktop/` | 主窗口加载服务端页面；悬浮录音窗、Deepgram 流式 WS 代理、框选截屏在主进程实现 |
| Electron 客户端（便携版） | `dist/win-unpacked/LectureLearnLoop.exe` | win-unpacked 打包产物（317MB，免安装，双击即用） |
| 一键启动 | `start_app.ps1` | 拉起服务端（若未运行）+ 客户端；`-Dev` 分支带 CDP 9222 供自动化 |

配置与密钥：全部在 `server/.env`（`DEEPGRAM_API_KEY` / `DEEPSEEK_API_KEY` / `JWT_SECRET` 等），源码零硬编码。

## 二、快速开始

### 方式 A：便携版（推荐验收用）
```powershell
# 前提：本机装有 Python 3.10+，并执行过 pip install -r server\requirements.txt
powershell -ExecutionPolicy Bypass -File E:\LLM\LectureLearnLoop\start_app.ps1
```
或手动：先 `python server\app.py`（工作目录 server），再双击 `dist\win-unpacked\LectureLearnLoop.exe`。

### 方式 B：源码开发模式
```powershell
python server\app.py                                  # 终端1
powershell -ExecutionPolicy Bypass -File .\start_app.ps1 -Dev   # 终端2（Electron + CDP:9222）
```

### 重新打包便携版（客户端代码变更后）
```powershell
powershell -ExecutionPolicy Bypass -File server\tests\p7_package.ps1
```
纯离线复制 Electron dist + 注入 `resources/app`，不依赖网络打包器。

## 三、功能清单（已全部迁移并测试通过）

1. **注册/登录**：开放注册（用户名+密码，JWT 7 天）；老数据归 admin（user_id=0001）；新用户空库
2. **7 个页面 1:1**：工作台 / 资料学习 / 网课笔记 / 练习脑图 / 知识库 / 设置 / LLM 日志（SPA 外壳与页面 JS 原样保留，55 个 pybridge 桥方法由 `api.js` 兼容层背实为 HTTP+JWT）
3. **资料学习闭环**：贴文本 + 选学科 → DeepSeek 提取知识点 → 相似度匹配（阈值 0.35）→ merge/new/skip 确认 → 入库
4. **悬浮录音窗**（豆包式）：主窗 Header 🎧 按钮或后台唤起 → 360×480 置顶无边框小窗
   - 音源：系统声音 loopback（getDisplayMedia）或 文件音源（演示/验收通道）
   - 声波动画指示录音中；下方小窗 **Deepgram 实时转写字幕**（interim+final）
   - **每 60 秒自动段落总结**（DeepSeek），转写全文+总结持续写入 vault 笔记
   - 📷 框选截屏：全屏遮罩拉矩形 → 主进程裁原屏 → 存 vault/截图/ 并把 markdown 插入当前笔记
   - 语言选择：中文(zh-CN，默认) / 英文 / 多语言 —— 见掉坑笔记 P007（multi 对中文无效）
5. **练习闭环**：知识点/错题两种出题（10 题×4 选项）→ 答题 → 熟练度按难度加权全量重算（容易1.0/中等1.2/困难1.5）→ 错题入库（默认熟练度 20）→ 渐进更新（学习率 0.2 / 遗忘率 0.3）→ 错题推荐池
6. **笔记**：vault 目录按用户隔离（realpath 防越权）；未保存修改守卫；追问/对话历史接口可用

## 四、你如何亲自做业务验收（10 分钟路径）

1. **启动**：运行 `start_app.ps1`，出现"柯基学习小助手"窗口 → 注册账号登录
2. **悬浮窗实录**：打开任意网页视频（如 B 站/YouTube 公开课）→ 点 Header 🎧 打开悬浮窗 → 音源选"系统声音" → 点"开始学习" → 应看到声波跳动 + 底部字幕实时出现 → 等 1 分钟出现第一条段落总结 → 点"📷 截屏（框选）"拉框截图
3. **笔记确认**：回到"网课笔记"页 → 打开自动创建的笔记 → 应含转写全文、段落总结、截图引用
