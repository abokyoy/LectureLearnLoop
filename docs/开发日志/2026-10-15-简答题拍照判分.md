# 2026-10-15 简答题拍照判分（错题练习升级增量，用户新需求）

## 业务变更（业务语言）

练习错题时，**问答题（简答题）**在原来只能打字输入的基础上，新增**拍照上传手写解题过程**：

- 学生在纸面写好解题过程 → 点「上传手写过程」拍照（可多张）→ 与文字输入可并存，缩略图可逐张删除，往返切题不丢已传照片
- 提交后判分方式**与录入错题时的解析方式同一条链路**：照片交给视觉模型真正「看图批改」——用户自配视觉端点优先（不扣分），系统 VL 兜底（扣分），同一计费链，积分不足直接提示充值
- 纯文字简答判分行为完全不变（原 LLM 批量文本判分）；单选/判断/填空不受影响
- 题干本身带图的错题（错题照片录入常见）答简答时也自动路由到视觉批改
- 上传进行中锁定上一题/下一题/提交按钮，防止切题竞态导致照片传错题或丢图

## 关键规则口径

- **判分分流**在公共判分函数 `_grade_practice_set` 内实现：知识点练习提交（practice-submit）与错题混合卷提交（error-set-submit）**两个通道自动生效**，零复制
- 答案存储形态 = `文字 + 换行的 ![手写解答](截图/x.png) 行`，与错题解析的图片引用格式同构（user_answer 字段零迁移）
- 视觉题任一失败 → **整批失败不落库**（与文字通道同口径，避免半批静默判错）
- **视觉批改先于文字批量**（评审 m1）：防止文本通道已扣分后视觉才失败、已扣不退造成计费泄漏
- 坏图（不存在/空文件/不可解码）丢弃留痕不阻断判分，仅剩纯文字则回落文字通道
- 知识点详情页页内练习面板本次不加上传 UI（用户此前裁定本期不迁 pmPractice；判分走同一公共函数，后端天然兼容）

## 顺带修复的既存产品缺口

- **practice_errors.html 从未加载 marked/DOMPurify**：MD 渲染插槽 `hydrateMdSlots` 永远走纯文本回退——错题练习页的图片题干、答案图片此前**从不显示**（KaTeX 公式正常系回退分支也 applyMath，旧断言无法区分）。本次补上与知识库页同版本 CDN，拍照照片在结果面板得以显示，同时修复了该缺口
- 定性过程：harness 连续 3 次 FAIL 后加诊断 dump（img 元素存在性/桥可用性）一次跑实锤根因，符合「先核事实再定性」
