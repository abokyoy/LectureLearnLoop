# 2026-11-12 课文追问笔记树（框选追问 + 服务端笔记本 + 全屏沉浸阅读 + 提取右栏）

## 任务来源
用户四点裁定并批准计划：① 课文阅读框选文字出浮动菜单「追问 / 请老师讲课」，追问在锚点下生成虚线淡黄子章节、可无限嵌套（追问的追问）、Vditor 可编辑问答；② 「请老师讲课」= 扩展现有 `/api/board/assign` 指派链（kind='text'）跳黑板自动开课，不另开链路；③ 笔记树服务端持久化（新表 lesson_notes，"学习笔记本"跨会话不丢），锚定=文本内容锚定（anchor_text，不改 content_md，失锚降级右栏索引不静默丢）；④ 移除右上旧问答输入框、阅读全屏沉浸、知识点提取内置阅读右栏。追问回答 prompt 纪律「尽可能图文并茂」（mermaid 思路图/表格/$公式$），空回答即失败不重试。

## 落地

## CodeReview 子代理评审 + 修复
- **Critical-1**：`wrapAnchorText` 尾巴节点 `keep` 的 start 回填漏算左偏移 a（`it.start+(b-a)` 应为 `it.start+b`）——段落中部锚选（最常见场景）会把匹配段外的尾巴错包成同 nid 锚（下划线多出一条、点击误触发），并覆盖原 nodes[i+1] 打乱遍历。已修。
- **Warn-2**：`openAskPop` 提交回调无 flow 快照——思考期间切课文会把 A 课笔记塞进 B 课 notes。修复：同 `loadNotes` 口径 `var f = flow; if (flow !== f) return;`。
- **Warn-3**：POST 落库不截 answer 但 PUT 硬顶 20000——超长答案入库后编辑保存永远 400。修复：落库前统一 `[:_NOTE_ANSWER_MAX]`。
- **Warn-4**：500 上限「先 COUNT 后 INSERT」跨两连接并发双过（白扣积分）。修复：COUNT+INSERT 同事务 + `pg_advisory_xact_lock(lid)`。
- **Suggest-5**：`_ASSIGN_KINDS` 常量声明未用。修复：`set_assign` 入口非法 kind 抛 ValueError。
- 评审确认无问题面：父链环检测双保险、越权 404 语义、三条渲染管线 XSS 兜底（cgEsc/DOMPurify）、空答不落脏行、事件委托单次挂载、占位 span hydrate 顺序、assign 稳定哈希与 TTL 消费。
- 修复后回归：单测四文件 245 passed、learn_goals.html 7 个 script 块语法校验 OK、重启 9992 后 CDP 17/17 重跑 PASS。

## 过程事故（详见掉坑笔记 2026-11-12 轮）
① KaTeX 对分离文档碎片静默不渲染——笔记链占位 span 必须先入 DOM 再 `cgHydrateMath`（两真凶排查过程）；② anchorNotes 全量重锚不清旧组导致子章节叠加重复；③ built-in `hash()` 有进程盐，跨重启指派 id 不稳须用 md5 稳定哈希；④ Vditor 把 `.vditor` 类挂在挂载体**本身**，CDP 断言用后代选择器 `#x .vditor` 永远假 FAIL（现例 `_ocn_edit_assert` 用 `m.classList.contains('vditor')`）；⑤ PowerShell 下 node -e 内嵌引号被吃、`$env:` 前缀被外层转义吞掉（改 `[Environment]::SetEnvironmentVariable`）、restart_9992.ps1 需 `-ExecutionPolicy Bypass`。

## 上线后实弹故障修复（追问报 Unexpected token '<'）
用户实弹追问报前端 JSON 解析错。定性（stderr 栈尾）：真因是 DeepSeek 隧道端点 HTTP 530（cloudflared 连接器掉线，环境问题），provider 抛裸 Exception 不在 CourseError 继承链，`_gen_guard` 未捕 → Flask 默认 HTML 500 错误页 → 前端 `r.json()` 炸「Unexpected token '<'」，真因被解析器术语掩盖。两层修复：
- `routes_courses.py` `_gen_guard` 末尾加 `except Exception` 兜底 → JSON 502 带真实原因（生成链任何未控异常不再冒 HTML）；
- `app.py` 新增全局 `@app.errorhandler(Exception)`：仅 `/api/` 前缀回 JSON（HTTPException 回其 code，其余 500），页面路由 `raise e` 保持默认，异常同步进 debug_logger——任意未来新端点的未控异常也不再产 HTML 进前端解析链。
验证（临时复现脚本，跑完已删）：越权 404 JSON、路由不存在 404 JSON、`/learn_goals` 页面仍 text/html、真生成链回 JSON（临时用户积分为 0 报 402，证明无 HTML 泄漏），清理零残留；回归 test_course_notes/flow/extract 52 passed。**限制**：隧道 530 未恢复前追问实际生成仍会失败，修复只保证失败以 JSON 正确呈现真实原因，需源站 cloudflared 隧道恢复后功能方可用。
