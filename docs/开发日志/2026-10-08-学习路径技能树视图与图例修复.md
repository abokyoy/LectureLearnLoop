# 2026-10-08 学习路径技能树视图 + 图例可读性修复（知识脑图 → 梳理知识点）

## 需求（用户提出）

1. 线性学习路径图上的「节点类型说明」方框特别小、文字看不清，且节点能放大缩小它不能——要修到清晰可读；
2. 梳理知识点支持两类图，**节点完全相同、只是组织形式不同**：
   - 线性路径（现状）：一条链看前序/后续；
   - 技能树（新增）：游戏技能树式 DAG，从左到右分层，一个知识点可有**多个前序**（学 C 需先点亮 A+B），最右侧是「掌握该学科」目标节点；颜色如实反映学习状态（黄=已学、灰=未评估、绿=AI补充、蓝=最终目标），用户一眼看出「前序已点亮哪些、还差哪个」，自主学习顺序；
   - 页面 Tab 切换两图。

业务裁定（用户选 A）：老缓存没有前序依赖数据时，**首次切到技能树 Tab 自动触发一次重新生成**（消耗一次 LLM 积分），之后两图共用新缓存。

## 改动内容（业务语言）

### 后端（server/knowledge_management.py）

- 学习路径生成 prompt 新增**前序依赖契约**：每个知识点节点必带 `prerequisites` 数组（可多个、只引用本次输出中的知识点节点、真实反映知识依赖、不成环、无前序为 []）；
- 新增清洗：LLM 输出不可信，统一过滤不存在 id / 自引用 / 重复 / 非数组，并**强制破环**（DFS 回边删除），保证落盘缓存必然是 DAG，前端不会被画崩。

### 前端（server/templates/pages/practice_materials.html）

- **图例修复**：原 SVG 图例被 viewBox（3200×700 显示约 1200px）整体压缩到 0.37 倍，12px 字实际约 4px，且不随缩放联动。改为 **HTML 悬浮卡片**（右下角，字号固定清晰），线性/树两视图共用；
- **Tab 切换**：工具栏新增「线性路径 / 技能树」两档；
- **技能树渲染**：按依赖深度分层（记忆化 DFS 求最长链、防环）、左→右列布局、多前序连线缩到圆边缘、叶子全连「掌握XX」目标节点、动态画布适配内容尺寸、节点颜色/点击详情与线性图完全复用同一套函数；无依赖数据时退化为按阶段串联不断图；
- **A 方案自动升级**：老缓存缺依赖时首次切树自动 清缓存→重新生成→渲染；一次性标记防反复烧积分；升级未成功自动回退线性 Tab 保持状态一致；
- 切学科/返回脑图时正确复位视图状态与临时 UI。
