# 2026-10-15 笔记选择窗（note_picker）树形化改版

## 任务背景

学习悬浮窗点"录制"时弹出的"选择学习笔记"窗口（note_picker）原来是**平铺文件列表**，与「学」模块的文件结构视图不一致。用户裁定：

> 完全保持和当前文件列表 1:1 一致，也就是树形结构。用户可以在这个树形结构里搜索定位、选择，或者新建。只要保持跟文件列表里的操作完全一致就行。并且支持搜索：上面有一个搜索，也有一个筛选按键搜索。然后输入关键字，就对名字进行筛选和定位。

## 业务说明（用业务语言）

改版后，录音前的选笔记窗口与「学」页看到的文件夹结构**完全一样**：

- **树形展示**：文件夹/子文件夹/笔记逐层展开，同一套图标（文件夹/文档/展开箭头）、同一行高与缩进、同一配色语义（可作笔记的文件蓝色、不可用的置灰斜体）；
- **同一套操作**：点文件夹=把它设为"新建落点"；点笔记=选中待打开；右键=新建子文件夹/新建笔记/重命名/删除；双击笔记=直接开始录音写入；拖拽=移动文件换目录；新建后内联输入名字（与「学」页链路一致）；
- **树内搜索**（新功能，两种模式用"筛选"按键切换）：
  - 筛选模式：输入关键字后只显示名称匹配的笔记及其所在文件夹链，自动展开并选中第一个命中；
  - 定位模式：整棵树保持可见，命中的笔记加橙色描边高亮，Enter/Shift+Enter 在命中项之间正反循环跳转；
- **离线可用**：树控件的主题样式与图标资源全部本地化（`server/static/css/jstree/`），客户机无外网也能正常显示；
- 悬浮窗回传契约不变（选中笔记的绝对路径+名称 → 录音写入该笔记）。

## 技术落点

- `server/templates/note_picker.html`：全量重写（平铺列表 → jsTree 3.3.16）
  - 数据源 `/api/vault/tree-nested`（与「学」同源，节点 id=服务端绝对路径）；
  - 结构与「学」页 1:1：32px 行高、每层 24px 缩进、Material folder/description 图标、ocl 撑满行高、leaf 无假箭头（直接复用同日打磨的对齐口径）；
  - 操作链路同「学」：`resolveTarget` 落点、`insertAndEdit` 即时插树+内联重命名、rename/move/delete 走 `okData` 双层契约解包、成功后整树重拉并选回；
  - 搜索双模式：后序遍历 keep 集合（自身命中或含命中后代可见）+ `.ll-hit/.ll-cur` 高亮类；
  - jsTree API 漂移四点适配（详见掉坑笔记 2026-10-15）：无 `scroll_to/open_parent`→原生 `scrollIntoView`+`parents` 逐级 `open_node`；`node.element` undefined→`document.getElementById(id)`；rename 事件载荷 `{node,text,old}`；
  - 事件治理（CodeReview M1）：`bindTreeEvents` 先 `$t.off('.llpick')`，dblclick/contextmenu 改命名空间绑定，防 load 重拉叠加。
- `server/static/css/jstree/`：新增 style.min.css + 32px.png + 40px.png（主题资源，代理下载）。

## 已知限制

- 拖拽移动的真实鼠标链路未在自动化中端到端跑（jsTree dnd 需原生事件序列），move API 与 move_node 处理链已按契约验证；用户在界面上实际拖一次即可最终确认；
- 平铺旧列表移除后，"搜索文件名"能力由树内搜索接替（与「学」页一致：整树重拉口径）。
