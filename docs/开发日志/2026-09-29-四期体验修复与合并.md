# 2026-09-29 · 第四期：体验修复与功能合并

## 概述

本期围绕 11 项体验缺陷做根因修复与功能合并，分 A/B/C/D 四组串行落地：登录与用户设置、数据真实性与串写、录音体验、资料学习合并进网课笔记。全部改动配套 HTTP 自证与回归验收。

## A 组 · 登录与用户设置（问题 1、2）

- **免登录语义修正**：`JWT_TTL_DAYS` 默认 57→**7**（支持环境变量覆盖），登录响应附 `expires_in_days`。`login.html`：勾选"记住登录"→ `ll_token`/`ll_remember` 持久化 localStorage（7 天免登录）；**不勾选 → token 只进 sessionStorage**，关浏览器即失效，不再无条件写 localStorage。
- **全端 token 读取统一**：新增 `window.llGetToken()`（localStorage 优先、回退 sessionStorage），替换 api.js / base.html / spa_layout / overlay / 页面内联 fetch 的 `localStorage.getItem('ll_token')` 读取点；logout 封装清理两处存储。
- **用户设置端点与模态**：`auth.py` 新增 `POST /api/auth/password`（验旧密码改密）、users 表迁移补 `display_name` 列（ALTER ADD COLUMN 容错）、`GET /api/auth/me` 返回 username/display_name/token_exp。`sidebar.html` 头像区改为真实用户名/昵称 + 点击打开新建的 `components/user_settings.html` 模态（昵称编辑、改密表单、免登录剩余天数、时长选择 7/30/57/关闭、取消免登录、退出登录），删除"学习等级 Lv.5"假数据。
- 更新 `r9_acceptance.py` 57 天相关断言为新默认。

## B 组 · 数据真实性与串写修复（问题 3、4、5）

- **工作台真数据**：新增 `GET /api/dashboard/stats`（notes 本周 created/updated、practice_records 正确率、knowledge_points mastery≥80、最近活动）。`spa_layout.html`/`dashboard.html` 移除全部 `default(...)` 假兜底，fetch 真实 stats，"开始学习"按钮指向网课笔记。
- **停止 auto-create 串写**：`learn_from_materials.html` 老"完成知识点管理"流程删除硬编码 `subject:'机器学习'`，改复用三期"保存知识点"选择面板。`routes_bridge.py` batch-save 不再 `add_subject`，科目不存在返回错误"科目不存在，请先创建"（桥协议：HTTP 200 + `data.success=false` + 中文 error）。
- **一次性清理**：`tests/p4_cleanup.py` 仅删除非 admin 用户由老流程 auto-create 的"机器学习"科目及名下知识点，不触碰用户自建科目（如"666"），幂等。

## C 组 · 录音体验（问题 6、7、8、9、10）

- `recorder.js`：新增 `_startMic()`（getUserMedia + 复用 ScriptProcessor 管线），`start()` 支持 `source:'loopback'|'mic'`，缺省改 `'loopback'`；未授权/无轨道给明确 toast 而非 WS 错。
- `overlay.html`：音源下拉只留"系统声音"（默认）/"麦克风"两项，删除"文件音源（演示）"与"选择音频"。
- `online_course_notes.html` 设备面板：整块简化为二选一抹音源，删除"刷新并检测活跃设备"、设备列表、单设备测试按钮；开始录音传所选 source。
- **开始即刷新**：`startRecording` 成功后自动 `loadFileStructure()` 刷新左树并定位新笔记。
- **切菜单不断录**：LLRecorder 升级为全局单例 `window.llGlobalRec`（定义于常驻壳 spa_layout，懒建持有 state/transcript/summaries）；页面片段改用全局实例并按 `llGlobalRec.state` 恢复录制 UI，WS/采集运行于壳层，`updateContentArea` 替换 DOM 不影响录音。

## D 组 · 资料学习合并进网课笔记（问题 11）

- **文件树移植**：把 learn_from_materials 成熟的 fetch 版文件树（新建文件/文件夹、拖拽归类、右键）移植进 online_course_notes，清点并替换全部 `window.pybridge.*` 死代码；采用资料学习灰色系样式。
- **右键菜单统一**：文件树/文本右键合并为一套四项菜单（深入学习、开始练习、重命名、删除），点击时实时读 `window.getSelection()`（打开菜单快照到单一变量），废除双选中文本变量与 `'测试文本'`/`selectedTextForMenu` 演示兜底；未选中时作用于当前笔记全文并明确提示。
- **AI 练习助手恢复**：诊断"练习"tab 白屏（原硬编码演示内容 + pybridge 断链），改接服务端练习生成 API，生成/作答/判题链路可用，清除"机器学习"演示题目兜底。
- **AI 聊天中断**：发送改为携带 `AbortController` 的 fetch（`bridge.abortChat`），请求期间发送按钮切换为"停止"，点击即中断并恢复 UI。
- **菜单与路由**：sidebar 删除"从资料学习"；`/learn_materials` 302 → `/online_course`；`/fragments/learn_from_materials` 白名单移除（返回 404）；模板文件保留作回退备份。
