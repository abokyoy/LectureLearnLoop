# 2026-10-04 · 在线课程页三栏 UI 调整 + PDF 书籍文字格式修复

## 概述

用户实机验收「在线课程笔记」页后提出 4 项体验问题：①知识点面板与 MD 预览之间的分界线有拖拽图标但拖不动；②右侧知识点栏/实时语音栏没有收起按钮；③左栏文件结构收起后裁切不干净（露出根节点三角和半边文件夹），且四列三条分隔线粗细不一、第三条与预览区横向滚动条样式雷同显得凌乱；④《机器学习实战》PDF 转文字后格式混乱——黑体标题丢失、译者序下大量一行一个数字、目录全部粘成一团。本轮全部闭环，改动集中在 `server/templates/pages/online_course_notes.html`（UI①②③）与 `server/services/import_service.py`（PDF④）。

## 一、UI①：右栏可拖宽

- 重写 `initResizer()`：mousedown 在分隔线、mousemove/mouseup 挂在 document，按像素实时调整知识点面板宽度；下限 220px、上限为主内容区 60%。
- **双击分隔线复位**到默认宽度；宽度写入 `localStorage('ocn_rp_width')`，跨会话保持。
- 根因排查：原先面板宽度被 CSS `!important` 锁死，JS 改了样式也不生效，本轮一并解除。

## 二、UI②：右栏收起/展开

- 知识点面板与实时语音栏所在右栏新增收起按钮，收起后压缩为 44px 细栏（竖排展开按钮），同时隐藏对应分隔线（无拖拽对象时不显示）。
- 收起状态记忆在 `localStorage('ocn_rp_collapsed')`，页面载入由 `restorePanelStates()` 恢复宽度与收起态。

## 三、UI③：左栏收起裁切干净 + 分隔线/滚动条统一

- **收起不干净的根因**：页面里遗留了一段"2 秒强制设置文件树样式 + 5 秒看门狗"的调试代码和多条历史强制 CSS（`overflow:visible!important`、`min-width:500px` 撑宽、滚动条强制常驻），运行时把收起样式压掉。本轮整段删除，收起态由 `#file-structure.collapsed { width:60px; overflow:hidden }` 干净裁切。
- **三条分隔线统一**：均为 1px `#EFE9E0` 细线，hover 变橙提示可拖，透明加宽热区（±3px）保证细线仍好抓。
- **滚动条区分**：MD 预览内横向滚动条改为 4px、透明轨道、半透明帽（与 1px 分隔线视觉区分）；文件树横向滚动条 8px、按需出现不再常驻。
- 注意：因存在 `.flex-1:not(...){overflow:hidden!important}` 通配规则，文件树滚动样式必须用长写 + `!important` 内联才能生效（CDP 实测简写无效，已注释防后人改回）。

## 四、PDF④：书籍文字转换格式后处理（规则方案，未引第三方库）

用户问"能不能转完再调一个格式化开源组件"。评估后采用**行级字体元数据 + 三条规则后处理**（`tidy_book_text`），不新增依赖：

- **R1 标题找回黑体字**：统计全页字号众数作为正文基准，行主导字体为黑体/粗体族且字号 ≥1.15× 正文 → 标为 `##` 标题（≥1.8× → `#`）；页面顶/底边距带内的行按页眉/页脚剔除。纯数字行（目录导航图编号）不标标题、连续 ≥3 行纯数字装饰整组剔除（解决"译者序下面 1、2、3…9 各占一行"）。
- **R3 目录列表化**：点线（≥4 个引导点 + 尾页码）目录行改写为 `- 标题 · 页码` 列表项，不再粘成巨型单段。
- **水印/域错误剔除**：「图灵社区会员…专享」水印行、Word 域错误残留行清除。
- **保守降级**：字体元数据与文本行对齐失败（匹配率 <70%）时跳过 R1/R2 元数据规则，纯文本规则照常生效；正文文字逐字保留，只加标记、剔噪声、不改写。
- 真实样本验证（《机器学习实战》前 20 页）：纯数字伪标题 51→11 条、目录点线转列表项 87 条、正文抽样逐字完好、最终 Markdown 无控制字符泄漏。

- **UI 实跑验证**：Electron（CDP 9222）真实点击断言拖拽（变宽/变窄/上下限/双击复位/记忆）、右栏收起展开、跨会话恢复、左栏收起 60px 裁切、分隔线统一样式；截图存档 `design/walkthrough/b5f_final_default.png`、`b5f_fs_collapsed.png`、`b5f_rp_collapsed.png`，识图核对达标。
