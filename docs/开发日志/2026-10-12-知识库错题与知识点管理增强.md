# 2026-10-12 知识库管理增强：知识点 CRUD + 独立错题管理（第五批反馈）

## 业务变更（业务语言）

知识库管理页选中学科后，原来只能看知识点列表；本次升级为**知识点 + 错题双页签的完整管理**：

- **知识点页签**：新增（名称 + Vditor 描述编辑器）、编辑描述、删除（带确认；关联错题自动解绑保留、练习流水保留）
- **错题页签**：本学科全部错题一览，支持**手动录入独立错题**（不依附任何知识点，显示「独立」徽章）、MD 编辑（题干/答案/解析）、删除、与知识点解绑/归属绑定
- **拍照/截图录题**：新增错题弹窗里点「上传」或编辑器内 Ctrl+V 贴图 → 图片自动存知识库「截图/」目录并插入正文 → **自动送 OCR 识别**，识别出的题目文字自动填入编辑器；服务不可用时降级为「只插图、提示手填」，录入功能不受影响
- **闭环接入练/记**：手动错题在「练」页错题本、「记」页翻卡复习正常出现（MD 题干含图片渲染、显示「手动录入」徽章、隐藏无意义的空答题记录），FSRS 复习/熟练度链路照旧可用

## 核心架构决策：影子练习记录

既有链路所有错题读取都是 `error_questions JOIN practice_records`（题干存在流水表）。手动新增错题时同事务插一行 practice_records（题干 MD 存这里，user_answer 空、is_correct=0）+ 一行 error_questions（knowledge_point_id 可 NULL，source='manual'）。既有 JOIN 链路全部原样工作，只放宽 NOT NULL 与容忍空知识点，避免重写十几处 SQL。

## 已知限制

- OCR 依赖 .env 的 PADDLE_OCR_TOKEN（书籍导入已配置可用）；未配置时上传贴图仍入库、仅提示手填
- OCR 任务表为进程内存态，服务重启丢在飞任务（前端轮询收 404 走降级提示，可重新提交）
- 独立错题不参与「基于错题按知识点针对性出题」（无知识点归属），只参与卡片翻复习——设计语义
- 编辑器公式暂以原文展示（vendor 无 katex 资源，见掉坑笔记 2026-10-12）；补全 vendor/katex 后可回改 'KaTeX'

## 验收步骤

1. 知识库页 → 点学科 → 列表上方出现「知识点 | 错题」双页签
2. 知识点页签：+ 新增知识点（Vditor 描述）→ 行上编辑/删除；删已绑错题的知识点 → 错题不消失、变「独立」
3. 错题页签：+ 新增错题 → 弹窗内 Ctrl+V 贴一张题目照片 → 十几秒后识别文字自动填入 → 保存 → 行上出现「手动录入」「独立」徽章、图片正常显示
4. 行上「解绑」仅在已绑知识点时出现；编辑题干加一行字保存 → 列表即时更新
5. 记 → 错题 → 选学科 → 卡片翻：手动错题题面含图渲染、带「手动录入」徽章，背面正常看答案、复习自评照常
6. 断网/去掉 PADDLE_OCR_TOKEN 重走步骤 3 → 图片仍入库、提示「识别失败…可手动补录」，保存不受影响
