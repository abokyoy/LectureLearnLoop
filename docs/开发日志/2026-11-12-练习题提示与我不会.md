# 2026-11-12 练习题查看提示与「我不会」选项（课程域三处题包）

## 任务来源
用户裁定两点并批准计划：① 每题下方隐藏区「查看提示」——展开后解释题干术语+给思考方向，不给答案；② 所有题加「我不会」选项——免猜测，选它视为放弃作答。范围=课程域三处题包（前测/后练/模块考，共用 `renderQuiz` 组件一次覆盖）；知识点练习链/错题页出题不动。

## 落地
- **生成侧**（course_service.py）：三种 `_TEST_PROMPTS` 各加第 4 条 hint 生成要求（术语解释+思考方向，「严禁指出或暗示哪个选项正确，严禁写入能推出答案的结论」），契约 JSON 样例同步 `"hint"` 字段——一次生成零额外 LLM 调用；`validate_questions` hint 为**软字段**：缺失/非法一律降空串、超 `_Q_HINT_MAX=300` 截断、整包不因缺 hint 拒收（区别于 stem/options 硬闸，模型漏写不报废重试成本）。
- **判分链**（routes_courses.py `grade_pack`）：答案校验放开 `-1`（`a == -1 or 0 <= a <= 3`，bool/越界仍拒）；我不会=放弃作答按错题走同一链路（FSRS 最低档/入薄弱点/入错题本，判错逻辑 `ans != answer_index` 天然成立，不另发明豁免）；**负下标雷修复**：流水/错题本「我的作答」`opts[ans] if ans >= 0 else "我不会"`（Python `opts[-1]` 会静默取末选项记成假作答）；`per_question.user_answer` 保持数值 -1（可 JSON 落库回读）；`_pub_questions` 对外透传 hint（不含答案下发安全，旧题包无键降空串）。
- **前端**（learn_goals.html 共用 `renderQuiz`）：每题选项末尾虚线分隔加 value=-1「我不会（不猜，直接记下）」radio（同组互斥，提交循环 `Number(sel.value)` 自然计入已答）；`q.hint` 非空渲染「查看提示」链接（Lucide eye 图标）点击展开/收起浅底区，走 `cgMdSpan`+`cgHydrateMath` 同一公式管线；旧题包无 hint 静默不渲染按钮。三处提交（submitPretest/submitPostquiz/模块考）透传 answers 零改动；判分结果/成绩历史只展示题干+对错，-1 展示面零改动。
