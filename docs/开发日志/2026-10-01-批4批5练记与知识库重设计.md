# 2026-10-01 批4（练/记四页）+ 批5（知识库页）+ 批6（设置页）+ 批7（登录与工具窗）+ 批8（低频管理页）重设计

> 界面重设计计划的第 4、5 批。业务语言详述如下。

## 批4：练/记 四个页面改为真实数据

**涉及页面**：练习知识点（practice_knowledge）、练习错题（practice_errors）、记忆知识点（memory_knowledge）、记忆错题（memory_errors）。

**业务变更**：
1. 四页原先展示写死的假数据（如"156 个知识点""92% 掌握度"），全部改为直连真实后端接口，无数据时显示引导性空态。
2. 错题卡统一结构：题面（点击展开「我的答案 / 正确答案 / 解析」）+ 熟练度进度条 +「待强化 / 已复习」状态 +「标记已复习」按钮。**标记按钮改为常显**（原先藏在折叠区里，用户须先展开才能点，属于主操作路径缺陷，已修正）。
3. 错题记忆页概览「N / M 道已复习，复习完成 X%」与标记操作实时联动；练习错题页支持关键词搜索 + 学科筛选。
4. 四页共用同一套渲染模块（新增 `static/js/pm_pages.js`），学科 chips、错题行、时间显示等逻辑收敛为一份实现，后续页面直接复用。
5. 后端配套：错题查询接口补充返回「复习状态」字段（与工作台"待复习错题"口径一致）。

**质量**：CodeReview 无 Blocker；修复竞态守卫（快速切学科旧响应覆盖新结果）、错误信息注入、非法时间显示 NaN 三项；Playwright 真实点击全链路回归两轮全绿（含真实写库：标记已复习后 25%→50% 联动正确）。

## 批5：知识库页重设计 + 负数显示 bug 修复

**涉及页面**：知识库（knowledge_base）。

**业务变更**：
1. **负数 bug 根因与修复**：知识点的掌握度在建点时默认写入 -1，含义是「尚未评估」，此前界面把 -1 当真实分数展示（出现"-1%"）。现全系统统一：-1/空值一律显示「未评估」，平均掌握度计算剔除未评估项；全部未评估时显示「—」并提示"做几道练习后更新"。
2. 页面完全重写：去除旧 Qt 桥依赖，直连 HTTP 接口；沿用设计系统（学科卡网格、总览三卡、知识点列表、cl-* 组件）。
3. 新增「建学科」入口：页内输入学科名直接创建，创建后学科卡即时出现（此前只能去设置页建）。
4. 知识点徽章按页面用途分档展示：知识库总览用「已掌握 / 学习中 / 待加强 / 未评估」分类标签；练/记页用「掌握 X%」精确值——同为未评估时都显示「未评估」，此为有意设计而非分叉。

**质量**：CodeReview 无 Blocker；修复三项片段重注入/异步竞态（渲染令牌模式）、建学科防连点、空学科标题闪烁。Playwright 验证 8/8 断言通过（负数消除、筛选联动、建学科闭环「建后删」不污染数据、批4 未评估徽章回归），修复后重跑仍全绿。

## 批6：设置页重设计

**涉及页面**：设置（settings）；另修复了 SPA 壳层脚本注入机制（全局受益）。

**业务变更**：
1. 设置页全面改版：去除全部旧手写样式，接入设计系统（积分渐变余额条、卡片分区、开关式勾选、统一表单控件）；五大功能区（我的积分/自备 AI Key/总结设置/LLM 日志/管理员入口）业务逻辑与旧版一一对齐。
2. **日志查看/清空去 Qt 桥依赖**：“查看日志”改为 SPA 内跳转日志页；“清空日志”改走 HTTP 接口（旧版在 Web 端因无桥而按钮必报“功能不可用”）。
3. 积分充值提示中的店铺链接改为安全渲染（仅允许 http/https 链接，防注入）；接口失败反馈全部可读文案化。
4. **壳层修复（重要）**：SPA 片段内“外部脚本+内联脚本”改为严格串行执行（外部加载完再执行内联），根治了切页时“脚本未就绪”报错，后续所有带共享模块的页面同受益；切页时旧脚本链自动停机，不污染新页面。
5. 公共工具收敛：pm_pages.js 导出 pmUtil（tk/esc/getJSON/icon 等），后续新页禁止再自写副本；esc 补全单引号转义。

**质量**：CodeReview 无 Blocker；3 Major（跨模块令牌误伤、清空日志成功判定、脚本链跨生命周期）+ 4 Minor 全部修复。Playwright 验证 10 项断言全过（真实余额/流水/配置回填/开关交互/空卡密拦截/日志页跳转/旧代码下线），修复后批4/批5/批6 三批全量回归全绿，JS 错误零。验证中未点击“清空日志”（全局日志清空会影响所有账号观察数据，端点契约已由代码评审确认）。

## 批8：低频管理页收尾（管理后台 + LLM 调用日志）

**涉及页面**：管理后台·积分与系统配置（admin_credits）、LLM 调用日志（llm_logs）；另修复一处路由鉴权存量缺陷。

**业务变更**：
1. 管理后台全面改版：去紫色手写样式接入设计系统，四大功能区（积分业务参数/系统大模型掩码配置/用户积分总览与调整/充值卡密管理）业务逻辑与端点契约零改动；接入 pmUtil 公共工具（去自写 tk/esc/getJSON 副本），转义覆盖补全（流水类型/卡密状态映射此前未转义直拼）；保存/调整/生成/作废按钮全部防连点；非管理员进入不再卡在“加载中”，表格显示“加载失败（需管理员权限）”。
2. **修复存量缺陷：管理员在 Web 端打不开管理页**。旧路由对页面壳本身加了 Bearer 鉴权，而浏览器 HTML 导航无法携带 Authorization 头，已登录管理员直访 /admin/credits 也只会看到 401 JSON。现改为与其它 SPA 页面壳一致的“壳公开 + 数据端点 require_admin 把关”模式（壳模板不注入任何用户态数据，无敏感信息暴露）。
3. LLM 调用日志页重做：去旧绿主题与 Qt 桥硬依赖（Web 端旧版因无桥必显“日志功能不可用”），改为桥优先、HTTP 回落双通路；搜索框/刷新/导出 CSV 全部真实可用；日志明细（提示词预览/错误信息属半外部数据）全部转义渲染，去除旧版内联 onclick 与全局函数暴露；CSV 导出补双引号转义与公式注入缓解（= + - @ 开头字段加前缀单引号）。

**质量**：CodeReview 1 Major（换选用户未作废在途流水链，旧用户流水可能“复活”冒充）+ 2 Minor（CSV 公式注入、调整后流水面板不刷新）全部修复。验证：HTTP 断言 + Playwright 真实交互 15 项全绿（非管理员 403 提示路径、无残留）；因日志记录存于服务进程内存且测试账号积分不足，另用网络层 fixture（含恶意注入串样本）验证有数据渲染/展开/过滤/刷新/防注入 9 项全绿，JS 错误零。批4~批8 全部回归脚本重跑全绿。截图：`design/walkthrough/b8_*.png`、`b8b_llm_logs_data.png`。

## 批9：侧边栏二级菜单（练/记子功能入口补齐）

**涉及页面**：壳层侧边栏（所有 SPA 页面受益）。

**业务变更**：
1. 修复批1 窄栏改版的遗留缺口：原 Qt 菜单的二级结构（练→知识点/脑图/错题，记→知识点/错题）在 72px 窄栏改版后丢失，导致已重做的「从知识点练/从错题练/记错题」三页无任何界面入口。现窄栏「练」「记」两项 hover（或键盘聚焦）弹出 flyout 二级菜单，五个子项全部直达对应页面；父项点击行为不变（练→脑图练习、记→记知识点）。
2. 窄栏高亮归组沿用既有机制（任意子页内，侧栏对应父项点亮）；键盘可达性（focus-within 展开）按评审建议补齐。

**质量**：CodeReview PASS（无 Critical/Major；1 Minor 键盘可达性已当场修复）；Playwright 真实 hover+点击验证 7 项全绿（默认隐藏/弹出/三子项切页/高亮归组），JS 错误零。截图：`design/walkthrough/b9_flyout_practice.png`。

## 批9c：练/记知识点直达详情（修复“去练习落在脑图首页”）

**业务变更**：
1. 「从知识点练」每张知识点的「去练习」不再落在脑图首页，而是直接进入**该知识点的详情练习页**（掌握情况/错题统计/关联笔记/熟练度评估/基于笔记练习/举一反三）。
2. 「记知识点」页每行新增「巩固」按钮，同样直达对应知识点详情（原页面只有页级按钮，无知识点级入口）。

**质量**：CodeReview 1 Major（陈旧旗标幽灵弹出，已用时间戳过期机制修复）+ 2 Minor（降级分支误显 0 分改 -1 未评估哨兵；iframe 重建竞态作为一次性交接协议权衡接受）。端到端验证：两条链路详情层弹出/标题正确/三动作按钮齐备/旗标消费/可关闭全绿；批4 四页回归、批9 flyout 回归全绿，JS 错误零。截图：`design/walkthrough/b9c_point_detail.png`。存量发现（未动）：脑图页 refreshKnowledgePointDetail 调用的 loadKnowledgePointDetail 全仓无定义，建议单独立项。

## 沉淀的架构约定

- **渲染令牌模式**（掉坑 P024）：所有异步渲染页必须顶部捕获 DOM 引用 + renderToken 守卫丢弃旧响应 + 提交按钮防连点。批6~批8 照此执行。
