# 2026-10-08 学习路径技能树：Dagre 布局 + 卡片节点 + 实际大小显示模式

## 背景（用户反馈）

技能树视图上线后用户反馈两点：
1. **不够美观、非常混乱**——节点连线交叉严重
2. **无法放大到看清楚字体**——放大到极限字仍模糊

## 根因分析（代码事实）

1. **看不清字是数学问题**：实际字大小 = 坐标字号 × (容器px ÷ viewBox宽) × zoom倍数 ≈ 12 × 0.24 × 3 ≈ 8.6px。缩放上限 3 倍 + 全图适配 viewBox 压缩双重叠加，物理上不可能看清。
2. **乱的根因**：手写分列布局列内按名字排序（与依赖无关），跨列依赖边全部交叉；直线连线加剧视觉混乱。

## 方案（用户裁定：推荐组合，线性图保持现状）

| 问题 | 方案 |
|------|------|
| 边交叉乱 | 引入 Dagre（Sugiyama 分层布局，交叉最小化，内置破环） |
| 丑 | 节点圆形 → 圆角卡片（白底+左侧状态色条+投影），边直线 → curveBasis 曲线 |
| 看不清字 | ① 缩放上限 3→8；② 新增"实际大小"1:1 显示模式（viewBox=容器像素，拖拽平移浏览）；③ 悬停 tooltip 显示全名/状态/前序 |

## 实现要点

- **依赖**：`server/static/vendor/dagre.min.js`（@dagrejs/dagre UMD 40KB，本地 vendor，无 CDN 依赖）；`typeof dagre` 判据 + try-catch 双保险，失败回退原手写分列布局
- **双显示模式**：`applyLpFitView()` 统一驱动——全图适配（看结构）/ 实际大小（读字）；进入 1:1 模式取景对准**学习路径起点**（第一列节点中心，`_lpContentFocus`），避免首屏落在连线密集区
- **tooltip**：HTML fixed 定位跟随鼠标，全字段 escape 转义防 XSS；掌握度 -1 哨兵值与 null 统一显示"未评估"
- **状态复位纪律**：initSvg 复位 viewBox + `__zoom`（防跨视图 transform 泄漏）；switchToMindmapView/selectSubject 复位 lpActualSize/tooltip；resetView 在学习路径视图下改走 applyLpFitView（防静默丢失取景）

## CodeReview 结果与修复（1 轮）

无阻塞问题；3 建议全部采纳：
1. resetView 与实际大小模式取景冲突 → 学习路径视图下重置走 applyLpFitView
2. 树渲染空节点早退留空白画布 → 判定上移到 initSvg 前，回退线性视图兜底
3. initSvg 未复位 `__zoom` → 补 `svg.call(zoom.transform, d3.zoomIdentity)`

4 提示亦落实：Tab 切换/切学习路径视图补 hideLpTooltip 兜底、线性视图 1:1 取景对准起点、dagre 异常时 focus 退化到内容中心、回退布局直线端点裁到卡片边界（防箭头被白底盖住）。
