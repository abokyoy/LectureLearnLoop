# 2026-10-12 开发日志：v0.1.7 AI 练习助手考卷化（六题型考卷 + 配置窗 + 错题勾选闭环）

## 任务背景（用户反馈 + 裁定）

用户确认 v0.1.6 生效后提出：①题目展示区/答题区升级为**考卷**（选择/填空/判断/简答/拍照上传，AI 判卷与错题判卷同逻辑）；②生成练习题**之前先弹配置窗**（题型默认全勾、数量、智能/自定义难度）；③生成后直接跳入考卷从前到后做；④错题可加入错题本形成闭环。同时报修三个交互 bug：聊天区按钮二次点击无反应、欢迎页「开始新练习」进白页、练习历史提示暂无记录。

用户四项裁定：智能难度=按知识点熟练度匹配（匹配不到按中等）；**去掉「开始新练习」按钮**（欢迎页只留练习历史，重点升级练习界面）；错题=**结果页勾选后入库**（不自动入库）；历史复看=保持现状载入可看。

## 业务规则变更（已同步《业务规则总览》第十八节）

- 唯一出题入口：学习页选中文本右击「开始练习」→ 配置弹窗（题型/数量/难度 smart|custom）→ 组卷成功后**自动跳入考卷**逐题作答。
- 出题即落库（status='generated'）→ 练习历史不再为空；判卷复用公共判分函数 `_grade_practice_set`（简答拍照走视觉看图批改，与错题判卷同链路）；错题不自动入库，结果页勾选 → 知识点候选匹配 → 既有 save-errors 链入库。
- 聊天区「点击这里开始练习」按钮携带考卷号，重复点击按 pid 从历史恢复（根治二次无反应/白页）。

## 交付后迭代：用户验收第二轮——考卷面板布局 4 项修复（同日，v0.1.7）

用户验收：出题/答题链路正常，但反馈 4 个布局体验问题，全部修复并经 CDP 断言自证：

1. **题目展示区只占版面不到 1/3**：根因是历史 CSS 高度帽（题目区 max-height:300px、主白卡 calc(100vh-300px)）。考卷模式下面板挂 `quiz-mode` 类解除高度帽，题目区实测占版面 ≥45%；旧自由题面模式不变，返回欢迎页自动复位。
2. **相关学习内容占版面/展开应遮住题目区**：改为「收起仅一条入口栏，展开为向上浮出的绝对定位浮层（max-height 45vh，带阴影边框，不推动题目区高度）」。曾用原生 details[open] 方案，CDP 实证在面板动态打开态联动不可靠，改显式按钮 + class 切换。考卷模式下同时隐藏「用户答案记录」区。
3. **最大化助手面板顶部按钮被窗口功能区盖住（老问题）**：Electron 原生 titleBarOverlay（高 56px）永远盖在网页之上，z-index 无法越过——Electron 环境下最大化面板 top 改为 64px，面板历史/最大化/关闭按钮可点。
4. **错题入库成功通知看不见 + 通知必须低于功能区下沿**：发现全仓 showToast 有 4 份副本（页面片段版定义在后、实际覆盖了 base 版），且 base 版函数声明不在全局作用域。收敛为 base.html 唯一实现 + `window.showToast` 全局接管；toast z-index 10050（高于助手面板 9998）、上沿 64px（低于功能区下沿 56px）、pointer-events:none。

**验证**：新增 `desktop/v017_layout_assert.js`（17 项：题目区占比/答案记录隐藏/浮层展开收起几何/通知层级与避让/Electron 顶部避让/复位），17/17 全绿；回归 v017 考卷流程 40/40、v016 练习流程 20/20 全绿。业务规则见总览 18.5；新坑详见掉坑笔记。

## 验收路径（用户）

1. 学页选中一段文字 → 右击「开始练习」→ 出现配置窗（题型/数量/难度）。
2. 确认 → 自动进入练习助手考卷页，从前到后逐题作答；简答题可拍照上传手写解答。
3. 点「提交判卷」→ AI 判卷（含看图批改）→ 结果页看得分与逐题解析。
4. 勾选错题 → 选知识点 → 入库；到错题本确认。
5. 切出后再点聊天区「点击这里开始练习」按钮 → 能再次回到同一份考卷（不再无反应）。
6. 欢迎页「练习历史」→ 应能看到刚才的考卷记录（不为空），点开可复看/续答。
