# 2026-10-13 错题智能分析（Paddle 版面切片 + 视觉大模型整理回填）

## 业务变更（用业务语言）

编辑错题时，只要题目内容里有东西（文字或图片），弹窗里就会出现「🧠 智能分析」按钮。点一下，系统把这道题的图片和文字统一整理成一道规范错题，回填到编辑栏，用户核对后点保存入库。整个流程三步：

1. **图片先给 PaddleOCR 做版面分析**：判断照片里哪些矩形框是文字（并识别出内容）、哪些矩形框是图形（几何图等）。图形框按比例映射回本地原图，裁剪成独立的切片文件存进笔记库。
2. **所有内容打包给能看图的大模型**：MD 原文 + 版面结构（文字块/图形块/切片清单）+ 原图与各切片，让大模型决定怎么重新排版组织这道题，输出规范 Markdown。
3. **按契约回填**：题干（图用 Paddle 切片，不用原图）、用户的解答过程**如实**转录（含错误步骤，并入「解析」开头「## 我的解答」小节）、「## 错在哪里」（错在哪一步、为什么错、大概率哪个知识点薄弱）、正确答案、完整解析。回填前先 confirm，回填后可编辑，点保存才入库。

模型选择（用户裁定）：用户配置了支持视觉的模型用用户的；没配置就用系统配置的视觉大模型（硅基流动 Qwen3-VL-32B，key 复用 AIFinFlowX 存量），扣分口径与文字调用完全一致。草稿没有图片时自动退化走普通文字模型。任何环节失败，用户原内容保留，可重试或手动补录。

## 架构与安全决策

- **三步管线 + 防错双保险**：题干文字逐字采用 OCR 与用户手输内容，大模型只负责排版/理解/错因（OCR 与视觉互为校对）；用户裁定的「图=切片」不依赖模型自觉——`_normalize_stem_images` 代码侧确定性保底（实测 VL 偶发直接引用原图）。
- **TaskRegistry 公共任务表**（新公共件）：create/finish/get(consume)/TTL 统一实现，`error_ocr` 同步切换复用，消除两套近似实现（架构收敛原则）。
- **计费链复用**：`call_llm_vision(uid,…)` 显式传 uid（daemon 线程无 Flask g）；`provider.call` 成功后才 `charge_llm`，因此 5xx 瞬态失败天然不扣分 → provider 层 3 次尝试（递增退避）合法；JSON 解析失败绝不重发（那是已扣分的返回内容失败）。
- **在飞去重（评审 Major1）**：同一（用户+草稿+图清单）命中运行中任务直接复用 task_id——前端轮询窗口早于服务端最坏耗时收尾时，用户重点击不会起第二个任务、不会双扣分。
- **路径安全**：输入图片逐个过 `_safe_vault_path`（vault 内 resolve+relative_to，拒穿越/符号链接/绝对路径）；远程 http/data URL 输入侧剔除，输出侧（模型返回的题干）同样剔除（评审 Major2），入库内容只指向 vault 内文件。
- **网络口径**：paddle/siliconflow 国内直连，`session.trust_env=False` 显式绕开 V2RAYN 代理（实测代理链路 SSL 握手失败）。

## CodeReview 处置（1 轮：2 Major + 4 Minor，修 4 缓 3）

- **Major1（已修）**：客户端 360s 轮询上限 < 服务端最坏耗时 → 用户超时重点击会起第二任务双扣分。修：服务端在飞去重（同内容复用运行中 task_id）+ 前端上限抬至 420s + 结果决议后复查弹窗存活（Minor6 同修）
- **Major2（已修）**：输出侧 `stem_md` 未剔除远程 http/data 图片引用，违反「远程 URL 剔除」规则 → `_strip_remote_images` 与输入侧同口径清洗
- **Minor4（已修）**：视觉 provider 的 `requests.Session` 未关闭 → `with` 显式回收
- **Minor3/5/7（暂缓，已知限制）**：无切片时题干保留原图引用（版面异常下的优雅降级，原图也在 vault 内无安全问题）；切片文件不随取消回收（磁盘占用，保存时无法预知引用集）；`<带空格路径>` 引用不支持（vault 命名无空格，两端一致）
- 修复后回归：离线 33/33 全绿 + 真实链路 UI harness 10/10 全绿

## 已知限制 / 待办

1. 图形切片文件落盘后不随「取消/关窗」回收（永久保存，只占磁盘）；后续可在保存错题时按引用清理孤儿 `_figN`。
2. Paddle 版面异常导致无切片时，题干保留原图引用（降级而非硬失败）；原图同样在 vault 内，无安全问题。
3. 用户自备视觉端点 v1 仅支持 DeepSeek 配置槽的 OpenAI 兼容端点。
4. SiliconFlow Qwen3-VL 瞬态 5xx（code 50507）实测失败率约 4 成，已由 3 次重试+在飞去重消化；若持续故障，前端提示手填降级。
5. 任务表在内存，服务重启丢任务（分钟级任务，与 error_ocr 同口径可接受）。

## 用户验收步骤

1. 知识库 → 选学科 → 错题页签 → 「+ 新增错题」（或编辑既有错题）
2. 拍照/上传图片或输入文字 → 编辑框有内容后出现「🧠 智能分析」按钮
3. 点「智能分析」→ 状态栏提示「智能分析中…约需几十秒」（多图更久）→ 完成后弹 confirm「确定替换？」
4. 确定 → 题目内容变成规范题干（图是裁剪出的图形切片）、正确答案与解析自动填好（解析开头是「## 我的解答」如实转录）→ 可继续编辑 → 点「保存错题」入库
5. 失败场景：任何环节出错原内容保留，状态栏提示可重试或手动补录
