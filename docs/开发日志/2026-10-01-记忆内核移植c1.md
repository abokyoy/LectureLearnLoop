# 2026-10-01 记忆内核移植（路线 B）· c1 后端 + 评审收尾

## 背景

feat/integration 分支线的 FSRS 记忆内核（卡片墙/记忆曲线/过卡流/四档自评）从未合并进 main，
导致用户感知"知识点/错题的记忆曲线没有了"。经用户裁定走**路线 B：按需移植记忆内核**，
保留当前主线形态（翻卡/多题型）。任务拆解 c0~c5，本篇记录 c1（后端移植）闭环。

## c1 改动（业务语言）

1. **掌握度改由 FSRS 间隔重复算法驱动**：知识点测评（assessment）与练习提交（practice-submit）
   不再用"难度加权直写"，改为整批折叠一次复习（同知识点一次测评=一次记忆单元，
   批内取最保守评级：有答错必 Again），并受**正确率封顶**约束（答对 0/8 不会显示精通）。
2. **四个新共享端点**（知识点/错题通用，kind=kp|error）：
   - `POST /api/kb/<kind>/<id>/stars` 调星（0-10 存储分=星×2，服务端截断）
   - `POST /api/kb/<kind>/<id>/mastery_manual` 滑杆手动熟练度（最高优先级，持续到下次真实复习）
   - `GET  /api/kb/<kind>/<id>/curve` 熟练度曲线（kp 带复习时点可提取性；错题表无该列返回 None）
   - `POST /api/kb/<kind>/<id>/rate` 翻卡四档自评（not_at_all/vague/familiar/perfect）
3. **惰性衰减回写（decay_flush）接线**：dashboard、memory_overview、practice_overview 全量回写
   （PG 10 分钟节流）；similar_points 与脑图重建前行级回写。所有统计先回写再取数（两阶段口径）。
4. **SQLite 兜底**：knowledge_points/error_questions 各补 10 个 FSRS 列（幂等 ALTER），
   新建 kp_proficiency_history / memory_cards 表；PG 正式库表/列/存量数据本来就在，无 schema 变更。
5. widgets.js（曲线/星级/滑杆组件）按 integ 口径**页面级懒加载**，c2/c3 做页面时逐个引入。

## 业务规则留痕

- 整批折叠取 `min(ratings)`：用户确认"同知识点一次测评=一次记忆单元"。
- 手动滑杆为最高优先级，但下次真实复习自动接管（清 mastery_manual 标记）。
- 每次真实复习必写一条历史曲线（kp_proficiency_history / error_proficiency_history）。

# c2 记系列全卡片形态（同日接续）

## 业务变更（用户裁定：记都是卡片形式）

1. **记知识点页翻卡化**：默认卡片复习模式（最弱优先，学科加载时冻结队列），正面=知识点名+掌握度徽章+去练习直达，
   背面=核心描述+四档自评（很不熟悉/不熟悉/熟悉/非常熟悉 → POST /api/kb/kp/<id>/rate）；
   自评后自动下一张；保留列表模式（原待加强/已掌握分组不变）。
2. **记错题页背面接 FSRS 四档自评**：取代旧单一「标记已复习，下一题」按钮。
   待复习轮：自评 = FSRS 计分 + 自动标记已复习 + 下一题（链式两请求）；
   巩固轮：自评只计分不改复习状态。列表模式「标记已复习」轻量入口保留。
3. 四档自评组件（CARD_RATINGS/rateBarHtml/bindRateBar）两页共用一套实现；
   四档色条用自定义 CSS 注入（cl.css 预编译产物无未扫描 tailwind 类）。

# c3 记忆曲线接入（详情页 + 卡片背面）

用户诉求「知识点 错题的记忆曲线也没有了」的正面回应：把 integ 线的记忆数据面板（熟练度曲线/难度星/重要度星/手动熟练度滑杆）搬回主线。

## 业务行为（验收口径）

1. **知识点详情页**新增「记忆数据」卡片（动作按钮下方，默认展开）：熟练度曲线（红实线=掌握度，蓝虚线=可提取性）、
   难度/重要度半星步进调星、熟练度滑杆手动设定（手动=最高优先级，持续到下次真实复习）、状态/到期日 meta。
   熟练度评估/笔记练习/举一反三提交后面板自动刷新（新曲线/星级/清手动标记）。
2. **记知识点/记错题页**：每张卡片操作区下方新增「记忆数据」折叠按钮，首次展开才拉数据（懒加载）；
   翻到下一卡面板随卡重置。错题曲线只有熟练度红线（错题历史表无可提取性列，属既定限制非 bug）。
3. 新增只读端点 `GET /api/kb/<kind>/<id>/fsrs`（星值/熟练度/状态/到期/手动标记快照），曲线复用既有 `/curve`。
4. 星值/滑杆写入统一走 c1 的 stars/mastery_manual 端点；曲线历史由 FSRS apply_review/set_mastery_manual 自动追写，页面无自拼 SQL。

## 技术要点

- fsrs_service 新增公共读函数 get_fsrs_view（PG numeric 列归一 float，行缺失/非本人返回 None 走 404 口径）。
- pm_pages.js 公共组件三件套 memoryPanelHtml/mountMemoryWidgets/bindMemoryToggle（三页共用）；widgets.js 页面级引入（三模板 pm_pages.js 之前）。
- cl.css 预编译陷阱：面板星值行初版用了未扫描的 sm:grid-cols-2/gap-y-3，改用已存在的 flex flex-wrap gap-x-8 gap-y-4。
- 异步安全：片段切换/换学科后旧响应丢弃（document.contains 守卫）；重挂前重建骨架防 LLStars 容器级 keydown 监听累积；
  加载失败可「收起再展开」重试（懒挂载标记回滚）。
