# 2026-10-12 出题媒体规则统一与评估材料注入（v0.1.9，用户验收第四轮反馈）

## 用户反馈（业务语言）

对知识点做熟练度评估弹出的选择题经常问"**在表1-1中，什么什么……**"，但题干里根本没有表——题是基于学习材料出的，表却没带出来，学生没法做。用户建议：提示大模型把题目来源的表原样放进题干。

两处裁定（AskUserQuestion）：

1. **评估材料**：熟练度评估出题前自动注入该知识点的**关联笔记原文**（最多 5 篇、每篇截 3000 字，与"基于笔记练习"同口径）；无笔记时回退现状，且 prompt 明令禁止引用不存在的表/图。
2. **表格形态**：材料里的 Markdown 表格**原样复制**进题干，界面排成真正的表。

## 根因（代码实锤）

- 熟练度评估通道 `knowledge_generate_assessment` 的 prompt 只给知识点名称/描述/学科，**零材料**——模型凭描述"回忆"出「表1-1」这种引用，题目自然没法做。
- 三条出题通道（评估 / 笔记练习与举一反三 / 练习助手考卷）的 prompt 都没有表格规则；quiz 通道旧"图片规则"口径也不统一。
- 考卷渲染层 `quizRichHtml`（base.html 手正则管线）不支持 Markdown 表格，即便模型带出表也只会显示竖线源码（知识点页评估弹窗走 marked 管线天然可渲，无需改）。

## 改动内容

### 一、后端统一媒体规则 + 评估材料注入（routes_bridge.py）

- 新增常量 `_MEDIA_RULE_FOR_PROMPT`（单一文案防口径漂移）：看表作答的题必须把材料中完整 Markdown 表**原样复制**进题干；看图作答的题必须原样复制 `![说明](路径)`；**严禁编造/引用材料中不存在的表格/图片及其名称**（含「表x-x」「图x-x」）；无关题目不得提表/图。三通道 prompt 全部引用该常量（quiz 通道旧"图片规则"段整体替换）。
- `knowledge_generate_assessment`：复用公共函数 `_collect_point_notes_text` 取关联笔记，有材料时以「关联笔记内容」块附给模型并要求严格基于原文出题；无材料时不附块，但媒体规则照样生效（禁止无据引用）。

### 二、考卷表格渲染（base.html）

- `quizRichHtml` 管线插入步骤 1.5：`quizTableCells / quizTableHtml / quizRenderTables` 把连续 `|` 包围行 + `---` 分隔行解析为单行 `<table class="quiz-q-table">` HTML，在图片占位之后、公式保护之前执行——单元格内公式仍会被后续 KaTeX 管线正常渲染。答题页与判卷结果页共用同一管线，两处都显示真表。
- 评审两条 Suggestion 全部采纳：
  - S-1 单元格内 `*`/反引号先实体化（`quizCellHtml`），防 `formatMarkdownContent` 行内正则跨单元格配对成 `<em>` 串格；
  - S-2 `\|` 转义竖线先落私用区占位再分列、单元内还原，字面竖线不被拆成多列。

## 已知限制

- 无关联笔记的知识点做评估，仍只按名称/描述出题（模型没见过材料出不出好题是另一个话题），但媒体规则保证不会出现"在表1-1中…"这类无据题目。
- 注入最多 5 篇笔记后评估出题 token 略增（与"基于笔记练习"同口径，用户已裁定接受）。
- 表格单元格若含以 `*` 参与的公式定界（罕见），星号会以实体显示——为防串格刻意取舍，公式 `$...$` 定界不受影响。
