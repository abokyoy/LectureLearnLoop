# 2026-10-01 错题翻卡复习（选项落库 + 卡片翻转 + 推荐直达）

## 需求（用户原话归纳）
用户实测后指出三个缺陷，全部属实：
1. 错题列表里选择题只有题干和答案、**没有选项**——"这样复习怎么复习啊？"（根因在数据层：选项生成后即丢弃，从未落库，不是显示漏了）
2. 记错题以前是**卡片形式，点击可翻转**，要求恢复
3. **智能推荐应进入翻卡页无脑连续翻**——"这是个核心啊，怎么没有了？"

AskUserQuestion 裁定（用户全选推荐项）：
- 存量旧错题**不补选项**，降级显示（标注"该题未保存选项（旧数据）"）
- 翻卡入口 = 记错题页内模式切换（默认卡片，可切列表）；总览推荐「去复习」直达翻卡序列
- 翻卡范围 = 全部待复习错题按推荐序（熟练度升序，未评估最前），翻完可进已复习巩固轮

## 架构与关键决策
- **数据层**：`practice_records` 新增 `question_type TEXT DEFAULT ''` + `options_json TEXT` 两列；PG 走 CREATE + `ADD COLUMN IF NOT EXISTS` 幂等双路径，SQLite 分支同步补列 + try/except 幂等 ALTER（CodeReview Major-3：否则 DB_BACKEND=sqlite 回退时整条落库链路静默断裂）。错题本体（error_questions）不加列，查询 JOIN 流水带回。
- **落库链路**：`save_practice_record` 增尾参 question_type/options（`json.dumps ensure_ascii=False`，非 list 落 NULL）；`save_practice_results` 透传；`/assessment`（固定 single）与 `/practice-submit`（按题实际 type/options，带 isinstance 防御）两个调用点补齐。
- **查询**：`search_error_questions` SELECT 增 `pr.question_type, pr.options_json`，输出 `question_type`、`options`；`_safe_opts` 防御——单行选项 JSON 损坏降级为无选项，不打挂整个错题列表接口（CodeReview Minor-4）。
- **前端翻卡（pm_pages.js bootMemoryErrors 重写）**：
  - 默认 cards 模式 + 列表切换；3D CSS（perspective/rotateY/backface）由 `ensureFlipCss()` 注入一次；操作按钮放卡外避免与翻转点击互扰。
  - 卡正面 = 题型徽标 + 题干 + 选项（不标答案）；背面 = 正确答案/我的答案/选项高亮/解析；存量无选项显示降级提示。
  - 队列 = 待复习按 `profKey` 升序（null/未评估视作 -1 最前，与总览推荐同口径，CodeReview Minor-5 修正 `Number(null)===0` 错排）；「标记已复习，下一题」本地置 review_status=1 重建队列，当前题移出后续顶上；完成页可进巩固轮再翻。
  - **选项字母契约**（CodeReview Major-1）：高亮按索引派生字母 A+idx（与答题页/判分同契约），文本相等仅兜底——原实现按选项文本首字母匹配，中文选项永不命中、以 A 开头的错误项反而被打勾；显示统一加 "A. " 前缀。
  - 标记请求在途禁用全部导航/模式切换 + token 校验丢弃过期回调（CodeReview Minor-6 防跳卡/闪回）。
- **推荐直达**：总览推荐复习按钮改 `data-gorev`（携学科），`goReviewError` 写旗标 `pm_pending_review`（学科+错题 id+ts，10s 过期消费即清，与 pm_pending_point 同口径）；`mountSubjects` 增 preferredSubject 参数——**非第一学科的直达也能落在正确学科队列**（CodeReview Major-2）；翻卡首建队列时按 eid 定位 qi，不在队列从头翻。
- 列表模式 `errorRow` 展开区插 `optionsHtml(e, true)`（带选项错题直接列选项+高亮）。
