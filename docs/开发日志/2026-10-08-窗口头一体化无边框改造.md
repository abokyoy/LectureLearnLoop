# 2026-10-08 桌面端窗口头一体化（去 Windows 原生标题栏）

## 业务变更（业务语言）

- 学习软件主窗口不再有 Windows 蓝色标题栏：页面顶栏（"柯基的学习乐园"+悬浮窗按钮）就是窗口头部，可拖动、双击最大化/还原。
- 最小化/最大化/关闭按钮改为系统 overlay 按钮，颜色与顶栏同色融合（白底灰符号），不再出现"一眼 Windows 窗口"的观感；页面内部依旧不自绘窗口按钮（沿用产品规则）。
- 登录页顶部空白区同样可拖动窗口。
- 浏览器 Web 端完全不受影响（无桌面壳接口时相关样式与拖拽条均不启用）。

## 跨平台说明（macOS）

- Electron 本身跨平台（Windows / macOS / Linux），后端 Flask 亦可跑在 Mac 上。
- 本方案已内置 Mac 分支：窗口用 `titleBarStyle: 'hidden'` + 红绿灯（traffic lights）叠在侧边栏顶部，侧边栏 logo 自动下移避让（`.ll-electron-mac #sidebar`）；Windows 分支用 `titleBarOverlay`。
- 注意：exe 打包脚本 `p7_package.ps1` 仅产出 Windows 便携版；Mac 版需在 macOS 上另行打包（electron-builder 不支持在 Windows 交叉打出 mac 签名包）。

## 改动文件

| 文件 | 改动 |
|------|------|
| `desktop/main.js` | 主窗口 `titleBarStyle:'hidden'`；Win 加 `titleBarOverlay`（#FFFFFF/#78716C/56px），Mac 加 `trafficLightPosition` |
| `server/templates/base.html` | 桌面端环境打标脚本（`ll-electron` / `ll-electron-win` / `ll-electron-mac`） |
| `server/templates/components/header.html` | 顶栏加拖拽区 `ll-titlebar-drag`、按钮区豁免 `ll-titlebar-nodrag`、右侧避让 `ll-titlebar-pad` |
| `frontend/input.css` | 新增 Electron 壳层样式（拖拽区、Win 顶栏避让 170px、Mac 侧边栏避让）；重建 `server/static/css/cl.css` |
| `server/templates/login.html` | 顶部 44px 拖拽条（仅桌面端脚本插入，Win 侧避让 overlay 按钮） |
