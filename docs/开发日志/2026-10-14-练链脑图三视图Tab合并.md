# 2026-10-14 练链·脑图三视图 Tab 合并（u12）

## 任务背景（业务语义变更）

用户验收「练 → 从脑图练」后提出：脑图不应是独立页面，「梳理知识点」的路径视图也不该靠再点一次才出现。要求：

1. 「知识脑图 / 线性路径 / 技能树」合并为同一页面的三个 Tab，脑图第一且默认，可自由切换，不再有「返回脑图」式往返导航
2. 进入科目即后台并行生成脑图 + 学习路径（线性/技能树共用），首次未生成时 Tab 内显示载入框，不需要用户点「梳理知识点」才有路径
3. 「梳理知识点」语义改为**重新生成全部三视图**（脑图 + 线性路径 + 技能树）
4. 修复报障 bug：脑图页点「梳理知识点」再返回后，脑图箭头与节点全部分离（碎图）

## 改动内容（均在前端模板，后端零改动）

### 1. 三 Tab 统一视图（practice_materials.html）

- 工具栏常驻三 Tab（`lpViewTabs`：知识脑图/线性路径/技能树），新增 `switchMainView(view)` 作为唯一顶层切换入口；删除旧的「进入学习路径/返回脑图」按钮及 `generateLearningPath / switchToLearningPathView / switchToMindmapView / switchLpViewMode` 等往返函数
- 顶层状态源 `currentMainView`（'mindmap'|'linear'|'tree'），线性/技能树内部模式 `currentLpViewMode` 由其派生；Tab 高亮、搜索区/实际大小区显隐、标题（`applyViewTitle` 单一源）全部跟随
- 工具/按钮统一加 `whitespace-nowrap`，防窄窗口按钮文字竖排

### 2. 首次自动并行生成

- `selectSubject` 进入科目后：`generateMindmap(科)` + `startLpBackgroundGen()` 同时发起，默认停在脑图 Tab
- 学习路径生成状态机 `lpGenState`（idle/loading/ready/error）；`loadLearningPathData(force)` 为单一数据入口，成功后线性/技能树两图通吃
- 用户提前点线性/技能树 Tab：`ensureLpDataThen` 显示载入框边生成边等；数据迟到跨学科自动丢弃不污染
- 生成失败：遮罩显示「学习路径生成失败：xxx，可再次点击该 Tab 重试，或点右上梳理知识点」，再点 Tab 即重试

### 3. 「梳理知识点」= 全量重生成

`regenerateAllViews()`：按钮置「梳理中...」禁用 → 清脑图缓存重生成 → 清学习路径缓存重生成（线性+技能树一次到位）→ 恢复按钮。复用既有 clear/generate 接口，后端未动。

### 4. 脑图碎掉 bug 根治

根因：`renderMindmap` 直接引用 `currentMindmapData.edges`，`d3.forceLink` 就地把边的 source/target 从字符串 id 改写成**旧节点对象**；二次渲染时连线端点钉死在已销毁节点的坐标上 → 箭头与节点分离。修复：渲染前 `(edges||[]).map(e => ({...e}))` 拷贝（学习路径早已同款修复，脑图漏了）。
