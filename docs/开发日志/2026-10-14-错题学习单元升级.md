# 2026-10-14 错题学习单元升级（练模块错题域改造，P1-P4）

## 业务变更（业务语言）

错题从「一条流水记录」升级为「可管理、可练习、可诊断的学习单元」：

- **看得全**（P1）：错题行展开后正确答案/解析不再截断，公式与题干同管线渲染（MD+KaTeX），展开即完整信息
- **是单元**（P2）：每条错题自带属性（熟练度进度条 + 难度/重要度双星行上调）、记忆曲线面板、练习历史（含举一反三派生流水）；列表前端分页 20/页
- **练得转**（P3）：工具栏「智能练错题」（FSRS 三因子跨知识点组卷）/「勾选练习」/「举一反三」（页级），行级「练这题」「举一反三」；提交后错题熟练度与所属知识点掌握度**双更新**
- **有诊断**（P4，一期做全）：「薄弱点分析」生成文字报告 + 脑图双视图（绿=掌握尚可、红=薄弱，节点带证据错题），薄弱点节点「针对练习」直接出针对性练习题并闭环

## 用户四项裁定（本次落地口径）

1. 练错题提交后：错题熟练度按 FSRS 更新，题目所属知识点掌握度同步更新（与既有 practice-submit 一致）
2. 入池继承：难度按出题标注映射（容易→3/中等→5/困难→8，0-10 存储分），重要度继承知识点当前值；手动录入默认 5.0
3. 智能选题升级为 FSRS 三因子排序（保留率升序→重要度降序→难度升序，复用 `fsrs_service.sprint_sort_key`），替代旧「熟练度升序」
4. 报告闭环一期做全：「根据报告学习」= 薄弱点直接走举一反三链路出题作答
5. 补充：重练答错**不重复入池**（同题干有候选行只更新+记流水）；举一反三每题携 `root_error_id` 挂回错题历史；报告范围=当前学科；判分抽公共函数禁止复制

## 核心架构决策

- **错题域端点独立成套**：`error-pool`/`error-set-submit`/`analogy`/`weakness-report(s)` 新端点与既有 pid 版并存，pid 版行为不动；新参数全部可选保持 save_practice_record 向后兼容
- **pmPractice 公共练习引擎**：组卷→逐题作答→提交→结果面板状态机收敛为 pm_pages.js 顶层公共件，错题页四类入口（single/smart/manual/analogy/针对练习）共用一个浮层；知识点详情页内嵌状态机本期未迁移（依赖 point 作用域变量，迁移风险大于收益，列入后续演进）
- **weakness_report 纯函数服务**：prompt 构建/JSON 抽取（剥围栏+尾逗号本地修复）/严格校验（kind/status/深度/节点数上限/幻觉 evidence 白名单过滤）全部无副作用、`llm_call` 注入；**校验失败不落库不重发**（防重复扣分，同智能分析 15.4 口径）
- **脑图零新依赖**：自绘递归 HTML 树卡片（节点=知识点/总结点，红绿状态+证据错题），不引入第三方脑图库

## 已知限制

- 举一反三/报告为真实 LLM 调用，按现有口径计费；JSON 校验失败整单作废需重新发起（不自动重发防双扣）
- `bootKnowledgePoint` 内嵌练习状态机暂未迁 pmPractice（错题域先收敛，知识点域迁移列入演进）
- 报告脑图深度/节点上限（5/200）外的 LLM 超纲结构直接截断拒绝

## 验收步骤

1. 练 → 错题练习 → 选学科：列表分页 20/页；点题干展开 → 答案/解析完整显示、公式渲染、练习历史与「记忆数据」面板（曲线+双星）出现；点难度星第 4 颗右半 → 刷新后保持
2. 行级「练这题」→ 浮层作答 → 提交 → 判分结果 → 关闭后行上熟练度/历史更新（首评答对熟练度列暂不变属 FSRS 口径，曲线历史 +1）
3. 工具栏「智能练错题」→ 选题量 → 组卷进入逐题作答；「勾选练习」→ 弹窗默认全选当前页 20 行、翻页保留；「举一反三」→ 稍候出新题
4. 行级「举一反三」→ 新题作答提交后，来源错题的练习历史出现派生流水
5. 工具栏「薄弱点分析」→ 全局分析（等待 AI 分析）→ 文字报告（MD+公式）↔ 脑图双视图切换 → 红色薄弱节点「针对练习」出针对性题目；返回列表报告持久化（按日期倒序）
