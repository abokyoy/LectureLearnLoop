# 2026-10-14 练链·脑图体验六项修复（u11）

## 任务背景

用户验收「练 → 从脑图练」链路，反馈 6 组问题：练习总览/脑图/知识点三处页面全屏时不自适应、脑图点知识点偶发白屏、知识点页无法返回刚才的脑图、摘取逻辑需确认并要求带图片、描述编辑器要与「学」页 MD 体验一致、关联题目区布局随列表长度错位。

## 六项修复（业务语言）

### 1. 布局全宽自适应
- 新增 `.cl-page.cl-page-wide`（覆盖 1120px 限宽），练习总览、知识点页应用；重建 cl.css
- 脑图页去掉 max-w-7xl 居中限宽，SVG 容器高度改 `calc(100vh - 250px)`；新增 `fitMindmapView`：力导向收敛（simulation end）后按节点实际边界重设 viewBox，脑图随窗口缩放居中填满，不再四周大片留白
- 科目列表页放宽至 max-w-6xl；练习总览方式卡片 xl 断点 3 列

### 2. 白屏修复（双保险）
- 根因：知识点页依赖 jsDelivr CDN 加载 marked/DOMPurify，代理不畅时脚本挂起，SPA 脚本链卡死在空白骨架
- 修复①：CDN 改本地 `/static/js/vendor/`（同版本 marked 9.1.6 / DOMPurify 3.0.6）
- 修复②：SPA 脚本链加 8 秒看门狗（stepped 防重入 + 成功路径 clearTimeout），外链卡住时止损续链，前端有缺失回退

### 3. 返回脑图（用户重点需求）
- 脑图点知识点节点时写 `pm_mindmap_return {subject, ts}` 旗标（30 分钟 TTL、读取即消费）
- 知识点页面包屑尾部出现「‹ 返回脑图」按钮，点击回到脑图页并自动恢复上次科目的脑图（非科目选择列表）
- 「← 返回」回科目列表时清旗标，避免陈旧恢复

### 4. 摘取逻辑确认与改造
- 核实结论：旧版已扫描全部关联笔记，但①全局限量导致靠后笔记摘不到②合并成一整块无出处③纯图片段被短段过滤丢弃
- 改造 `_extract_note_sections`：每篇笔记独立成节、以「**《标题》**」标明出处不合并；限量按篇生效（6 段/1200 字，总量 4500 字封顶）；命中段相邻的纯图片块（`![[x]]` 或 `![]()`）一并纳入，前后双向对称传播（评审 M-1 修复），无关图片块不白取
- 仍为纯关键字匹配，零 LLM 零计费；图片引用原样保留，前端「学」页同款管线负责归一化 + base64 水合显示

### 5. 描述编辑器对齐「学」页 MD 体验
- 面板右上「预览 | 编辑」分段 Tab（`setDescMode`），互切；编辑态显示 Vditor、预览态 MD 渲染（含图片水合）
- 底部工具条（保存/大模型生成/从关联笔记摘取/整理描述/收起）常显，不再随预览隐藏

### 6. 关联题目区恒定上下结构
- 根因：div 嵌套错误导致题目列表成为 header flex 的子元素，列表长度影响左右分栏
- 修复：header 先闭合，列表为卡片直接子级，任何题数下均为上下结构

## 代码评审（CodeReview 子代理）

- Major-1 图片邻接纳入前/后传播不对称 → 改正/反两遍用最新 flags 传播（反向倒序遍历），自证脚本三场景通过
- Minor-2 节点半径三处内联副本 → 统一 `mindmapNodeRadius` 单一源（渲染/碰撞/贴合）
- Minor-3 看门狗定时器未取消 → 成功路径 clearTimeout
- Minor-4 30 分钟自动恢复语义 → 保留（用户原话即抱怨"回不到刚才的脑图"，自动恢复是预期行为）
