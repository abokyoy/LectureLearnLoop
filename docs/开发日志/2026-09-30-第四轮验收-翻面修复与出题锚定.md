# 2026-09-30 第四轮验收修复：记忆卡片翻面/过卡 与 基于笔记练习出题锚定

> 对应反馈：脑图知识点路径上「基于笔记练习」题目不对点；「学习此知识点」进入的记忆卡片翻过去翻不回来、背面文字镜像、过卡片点翻面后没有然后；基于错题的记忆同样问题。

## 一、用户反馈与业务口径确认

1. **出题不对点**：学习/练习一个知识点，应当基于笔记中"这个知识点讲了哪些内容"来出题（与"重新评估"一样针对该知识点）。→ 确认为业务规则（总览 3.4，Q15）。
2. **跳转链路**（打磨知识点列表→练习→脑图知识点路径→复习该知识点→学习此知识点→卡片列表）：用户逐条求确认，与现行实现一致，本轮未改动（见文末答复）。
3. **记忆卡片交互口径**（总览九，Q16）：
   - 正面显示知识点名称，反面显示知识点描述（错题页：正面题干、背面答案/解析）；
   - 卡片要能翻过去、也能翻回来；
   - 过卡片（推荐学习）：一次一张，四个熟练度自评按钮固定在卡片下方，**翻过来翻过去四个按钮都一样**（不随翻面），用户自行调整熟练程度，**点击一个档位后自动进入下一张**——这才叫过卡片。

## 二、根因（均先从代码取证）

| 问题 | 根因 |
|------|------|
| 背面文字镜像 / 翻不回来 | 翻面容器 `.ll-mc-inner` 同时带 `preserve-3d` 与 Tailwind `overflow-hidden`，Chromium 对 overflow≠visible 的 preserve-3d 容器强制拍平（flattening），背面 `rotateY(180deg)` 失效，正反两面同层叠加显示；且翻面点击只绑在正面，背面无法翻回（掉坑笔记 P032） |
| 过卡"没有然后" | 自评四按钮画在卡片的**背面**，被上述拍平 bug 废掉——点翻面后按钮不可用，无法完成自评，也就永远走不到"自动下一张"（`advanceSprint` 机制本来就在） |
| 出题不对点 | ①`/api/notes/<id>/content` 为兼容旧桥把正文截断为前 1000 字，知识点靠后讲解根本没进材料，LLM 只能围绕笔记开头出题；②prompt 未携带知识点释义，无"只针对该知识点"约束（掉坑笔记 P033） |

## 三、修复内容（业务语言）

1. **两个记忆页（基于知识点记忆 / 基于错题记忆）**：
   - 去掉翻面容器的裁剪属性，裁剪下沉到正/反面卡片自身圆角；翻面恢复真 3D：正面名称、背面描述，文字不镜像；
   - 正面、背面点击均可翻（点按钮/链接/展开区不误触发翻面）；
   - 过卡模式：自评四按钮改为卡片下方固定按钮条，正/反面状态都可见可点，点击档位后自动进入下一张；退出过卡恢复卡片墙（墙上四按钮仍在背面）；
   - 翻面调试日志上报真实方向（back/front）。
2. **基于笔记练习材料链路**：
   - 笔记内容接口新增 `?full=1` 全文模式（单篇上限 12000 字，默认行为不变保持兼容）；"基于笔记练习"取材料改为全文；
   - 生成端材料上限 12000→40000 字（与前端多篇拼接对齐），发生截断写 debug 日志可观测；
   - 出题 prompt 注入知识点释义（core_description 截 200 字），并显式约束"只针对该知识点出题，材料中无关内容不作考点"；材料段声明为纯文本素材，用户数据入 prompt 前去除模板边界符（防材料内容伪造指令）。

## 四、验证

- 语法：py_compile / node --check 全过；Flask（6021）已重启加载新代码。
- API 断言：note290 总长 1183，默认视图 1003 字（兼容截断），full=1 返回 1183 全文；kp 卡 2 张、error 卡 1 张。
- CDP 端到端断言（Electron 真实渲染，两页全绿）：computed `transformStyle=preserve-3d` 且 `overflow=visible`；点正面翻过去、点背面翻回来；过卡开始→按钮条 4 按钮/背面 0 按钮；点"熟悉"自动进入下一张（过卡 1/2→2/2）；退出恢复卡片墙且背面各 4 按钮。断言前对涉及知识点的 FSRS 状态做快照、测后回滚并删除本次历史，不污染用户数据。
- CodeReview 子代理：无 MUST FIX；两条 SHOULD FIX（生成端截断叠加、prompt 注入防御）与一条 CONSIDER（翻面日志方向用真实状态）已按上文落实。一条 CONSIDER（限制"不翻面直接自评"）**不采纳**——用户明确要求四按钮在翻面正反两侧都一样可点。

## 五、已知限制

- 材料截断上限（单篇 12000 / 整批 40000）为经验值，超长笔记仍会截断（已可观测，日志 `generate_practice_material_truncated`）。
- 出题仍限选择题（结构化通道既有设计，多题型走「练」页面）。
- 题目是否"贴点"最终取决于 LLM 对约束的遵循，若仍跑题可读 debug 日志确认是否材料被截断或需进一步做知识点段落召回。
