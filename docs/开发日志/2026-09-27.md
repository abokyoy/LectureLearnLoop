## 22:30 — 统一调试日志模块集成

**任务类型**：架构建设（无业务逻辑改动）

**背景**：实现自我测试、自我迭代的基础设施，Agent 必须通过日志验证功能正确，不要求用户手动测试。

**改动文件**：

| 文件 | 说明 |
|------|------|
| `logger_module.py` | **新建**。后端统一调试日志写入器，线程安全单例，所有日志写 `logs/debug_trace.jsonl`。接口：`debug_logger.log(module, action, status, data)` |
| `static/js/unified_logger.js` | **新建**。前端日志批量上报模块，缓冲区满10条或每5秒自动 POST 到 `/api/debug/log`。页面关闭前通过 `sendBeacon` 强制上报 |
| `app_flask.py` | **改动**：添加 `POST /api/debug/log` 端点（接收前端日志上报），在 `/api/knowledge/extract`、`/api/knowledge/list`、`/api/llm/call` 三个关键端点埋入 `debug_logger` 埋点 |
| `templates/base.html` | **改动**：在 `api.js` 之前加载 `unified_logger.js`，确保所有页面都能用前端日志 |

**技术改动简述**：无业务规则变化，仅增加可观测性基础设施

**日志读取方式**（Agent 测试验证时使用）：
```python
from logger_module import debug_logger
entries = debug_logger.read_recent(n=20)  # 读小20条
for e in entries: print(e)
```
