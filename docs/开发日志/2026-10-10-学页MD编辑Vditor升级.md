# 2026-10-10 学页 MD 编辑框升级 Vditor 即时渲染编辑器（第三批反馈）

## 业务变更（业务语言）

「学」页中点击 MD 文件进入编辑，原来是纯文本 input 框；本次升级为与知识点描述编辑器**同款 Vditor 即时渲染编辑器**：

- 所见即所得编辑（标题/列表/引用等格式即时渲染），顶部带格式工具栏
- **截图可直接 Ctrl+V 粘贴进正文**：图片自动保存到知识库「截图/」目录，正文插入路径引用（不会把巨串 base64 写进 MD 文件）
- 编辑区内已有图片自动显示（相对路径水合），取值时自动换回路径引用，防 base64 入库
- 与既有链路完全兼容：保存、未保存提醒、切文件守卫、AI 总结插入、悬浮窗截图插入等全部照旧（textarea 仍是数据层，编辑器只是显示层）
- 降级兜底：Vditor 组件缺失时自动回退传统 textarea 编辑，功能不中断

## 架构说明

- 公共模块 `server/static/js/note_vditor.js`（NoteVditor.create）：知识点页与学页共用同一编辑器桥接（公共函数注册制），含 pending 队列（ready 前 setValue/insertMD 排队，after 按序冲刷）、图片水合、base64 换回保护
- 学页桥接层 `window.NoteEdBridge`（online_course_notes.html）：show/hide/sync/insertAtCursor/mirror，所有同步读 textarea 的保存/切换入口前置镜像冲刷（Vditor input 有 800ms 去抖）

## 本轮调试闭环（CDP 断言 9/9 全绿）

- 断言脚本 `server/tests/_ocn_edit_assert.js`（A0-A8+Z）：挂载/镜像+脏指示/贴图粘贴入库/保存落盘/预览解析/base64 保护/不虚标脏/截图/文件还原；`_ocn_smoke.js` 保留作回归资产
- 修复 1：删除生产页面遗留开发期自测 `setTimeout(testButtonFunctions, 5000)`（编辑器被神秘收起 + 测试文件被污染的元凶之一）
- 修复 2：note_vditor.js pending 队列（pre-ready setValue 被吞而 insertMD 生效 → 半成品镜像覆写正式文件）
- 修复 3：学页贴图上传回包**双层契约解包 bug**——裸 fetch 读 `d.rel` 永远 undefined（rel 在 `d.data` 内），导致图片落盘成功但插图静默失效；解包口径对齐知识点页 postJSON
- 断言 harness 教训：Vditor 同时渲染 ir/wysiwyg/sv 三个 `.vditor-reset` 容器，DOM 断言必须用 `__vd.vditor.ir.element` 而非 querySelector 首个命中
- 修复 4（用户验收反馈）：编辑器无垂直滚轴、内容超长看不到底部——CSS 豁免通配 `overflow:visible` 杀死 Vditor 内部滚动容器 + `height:'auto'` 随内容撑高被外层裁掉双重叠加；改为编辑器撑满文档区（height:100%）内部滚动，豁免收窄到工具栏/下拉面板；新增 A9 滚动断言，回归 **10/10 全绿**

## 已知限制

- 保存写盘为 CRLF + 尾换行（服务端既有写文件行为，内容语义等价）
- 编辑取值经 Vditor Markdown 规范化，可能与原文有无害格式差异（如空格、转义）

## 验收步骤

1. 打开「学」页 → 左侧文件树点一个 MD 文件 → 点右上「编辑」
2. 正文应为即时渲染样式（标题大字、列表带符号），顶部有格式工具栏
3. 截一张图 Ctrl+V 粘贴 → 图片出现在正文光标处，左侧「截图」目录多一张 png
4. 点「保存」→ 提示保存成功；点「预览」→ 贴图正常显示
5. 不改动直接点「预览」→ 不应弹「有未保存修改」
6. 正文超一屏时编辑器右侧应有垂直滚动条，可滚到最底部（修复 4 验收点）
