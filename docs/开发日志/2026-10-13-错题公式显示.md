# 2026-10-13 错题公式显示（KaTeX 全落点渲染 + 编辑弹窗实时预览）

## 业务变更（用业务语言）

错题里带的数学公式（`$…$` 行内、`$$…$$` 块级 LaTeX）从此**在所有显示位置都是排版好的公式**，不再是一串被 Markdown 咬坏的乱码原文。用户裁定的范围（方案 A + 编辑弹窗）：

1. **知识库错题列表**：题干、答案、解析全部走「Markdown + 公式」管线（答案/解析原来是纯明文直出，公式原文暴露）。
2. **错题练习页 / 错题记忆页**：错题行、翻卡正背面、选项、关联错题同样渲染。
3. **评估与练习面板**：答题时的题干/选项、判分结果里的原题/你的答案/正确答案/解析/AI 点评，全部渲染。
4. **编辑弹窗**（用户裁定"连编辑弹窗也一起支持"）：NoteVditor 的 KaTeX 引擎开回，输入 `$x_1 = -m$` 即时看到排版公式；保存的仍是 MD 原文（`$` 定界保留）。

定界符口径（两种都支持，防 OCR 变体）：`$…$` / `$$…$$` 与 `\(…\)` / `\[…\]`；`\$` 是字面美元符；`$5 和 $6` 这类货币写法不误判为公式（数学式极少以纯数字开头）。

## 架构与安全决策

- **两步法（方案 A，用户裁定）**：marked 之前把公式摘成私用区占位符（`\uE000{序号}\uE001`）→ marked+DOMPurify 处理正文 → **sanitize 之后**再用 KaTeX 回填渲染。两个坑针对性解决：坑1 marked 把 `$x_1$…$x_2$` 的下划线咬成 `<em>`、反斜杠当转义丢弃（事后 auto-render 拿不到完整公式串）；坑2 DOMPurify 默认剥 KaTeX 的 math/svg 产物（故渲染必须发生在清洗之后，**不扩大 sanitizer 白名单**，安全线不松动）。
- **公共件收敛**：新建 `md_render.js`（extract + applyMath），pm_pages 与知识库两处 MD 管线同一口径接入；公式渲染逻辑只此一份。
- **KaTeX 本地化**：vendor 补齐 `dist/js/katex/`（0.16.9，与 Vditor 内部硬编码版本号同一套：katex.min.css/js + mhchem + fonts 60 个），页面全部引用本地文件，原 CDN 0.16.8 引用移除——弱网/离线不依赖外网。当初 Vditor 被设为 `engine:'none'` 就是因为 vendor 缺这些文件（404+pageerror），补齐后开回 KaTeX 引擎。
- **降级链（核心功能降级保底规范）**：KaTeX 脚本缺失 → 公式还原 `$…$` 原文纯文本；单条公式语法错（OCR 误识别）→ 红字错误显示不中断整段；marked/DOMPurify 缺失（错题练习/记忆页本就不加载 MD 库）→ 正文纯文本但**公式仍渲染**（CodeReview Critical-1 修复）；公式件自身异常 try/catch 不阻断图文。
- **XSS 面复核**：KaTeX 默认 `trust:false` 不解析原始 HTML、屏蔽 `\href`/javascript: URL；`output:'html'` 不把公式原文塞进 MathML；`data-md/data-ans/data-exp/data-src` 属性值全部过 `esc()`。

## CodeReview 处置（1 轮：1 Critical + 1 Major + 4 Minor，修 4 缓 2）

- **Critical-1（已修）**：错题练习页/记忆页没加载 marked+DOMPurify，`hydrateMdSlots` 在 marked 检查处提前 return，KaTeX 永远走不到——本特性主战场静默失效。修：无 MD 管线分支改为「正文纯文本 + 公式仍 extract/applyMath 回填」（textContent 只含占位符，无注入面），知识库页同口径；补 ui09b 回归断言（practice 页 `.katex>=7`）+ 截图核对。
- **Major-2（已修）**：行内剥 `<p>` 壳正则不容忍 marked 默认输出的尾随换行 → sanitize 结果先 `String().trim()` 再匹配（两处同修）。
- **Minor-4（已修）**：用户正文撞码 `\uE000数字\uE001` 且序号越界时内容丢失 → 越界保留原串不丢字。
- **Minor-1/2（开发中已修，评审前自查发现）**：`PH_SPLIT` 缺 `/g` 导致 applyMath 内层 exec 同位无限匹配**卡死页面主线程**（UI 首跑挂 4 分钟的根因）；补 `/g` 后又因游标管理漏掉首个占位符、以及 TreeWalker 遍历中 replaceChild 断链导致多段落容器只处理首节点——最终形态：两阶段（先收集后替换）+ 每节点双归零。node 离线测试只测 extract 测不到 DOM 层，教训见掉坑笔记。
- **Minor-3（暂缓，已知限制）**：读态页未挂 mhchem，化学 `\ce{}` 公式编辑态正常、读态红字；数学题不受影响，需要时同 vendor 补挂一行。
- **Minor-5（暂缓）**：`hydrateMdSlots`（pm_pages）与 `renderMdInto`（知识库）两条管线仍近似重复，后续可整体沉入 md_render.js 成 `renderInto(el,src,{inline})`。

## 已知限制 / 待办

1. 数学式以纯数字开头且后接数字（如 `$5x$` 表示 5 倍 x）会被货币防误判规则放过，显示原文；此类写法极少，可 `\mathdefault` 或改写规避。
2. 化学 `\ce{}` 语法读态不支持（未挂 mhchem），编辑态支持——口径不一致待 Minor-3 补齐。
3. 选项/答案文字展示从 truncate 截断改为 max-h 滚动约束（长内容现在可滚动看全，视觉行为有变）。
4. 两条 MD 管线（pm_pages/知识库）尚未收敛为单一公共件函数（Minor-5）。
5. `server/logs/_katex_dl/` 为构建 vendor 时的 npm 解包残留目录，可手动删除。

## 用户验收步骤

1. 知识库 → 选学科 → 错题页签：带公式的错题（如求根公式题）题干/答案/解析应显示排版公式。
2. 点「编辑」：弹窗内输入框里公式即时变成排版效果；保存后列表仍是排版公式（内容原文未变）。
3. 「练 → 错题练习」「记 → 错题记忆」：错题行与翻卡里的公式同样渲染。
4. 练习/评估的答题面板与判分结果（含 AI 点评）：公式渲染。
5. 老错题无需任何迁移操作，显示时自动渲染（数据里存的仍是带 `$` 的原文）。

## 验收追加（同日，用户裁定方案 A）：「我的解答」裸 LaTeX 定界规范化

**发现**：用户验收时指出智能分析转录的「我的解答（如实转录）」段落仍显乱码。查库定性：视觉大模型如实转录时输出的是**无 `$` 定界的裸 LaTeX**（`\Delta=(m-2)^{2}…`），而提示词只要求“逐字如实”未要求公式定界——显示管线只认带定界公式，属源头数据不规范而非渲染 bug（同段模型自写的解析带 `$` 渲染正常可交叉佐证）。

**方案 A（用户裁定，治源头不用显示端启发式认裸公式）**：

| 文件 | 改动 |
|---|---|
| `services/error_analyze.py` | 提示词硬性规则 7（所有字段公式必须 `$…$`/`$$…$$` 包裹，内容仍逐字如实）；`_wrap_bare_latex` 确定性保底（assemble_result 五字段全走，不依赖模型自觉）；保守判定四重保护：已带 `$/\(/\[` 定界行跳过、跨行 `\[..\]`/`$$..$$` 块状态跟踪、Windows 路径类无痕迹文本不包、剥除 `{…}` 后公式外中文>4 字的叙述行不包 |
| `tools/migrate_bare_latex.py` | 新建一次性迁移工具（默认 dry-run；--apply 前备份原值 jsonl；复用 `_wrap_bare_latex` 单一口径；题干聚合键整组同步） |
| `tests/test_error_analyze_service.py` | 新增 6 条断言：真实 980 样例逐行包裹、\(..\) 混排行/跨行块/Unicode 中文题干/路径四类误判保护、assemble 集成、空文本 |

**迁移实做**：首轮 dry-run 命中 45 处，逐类抽查发现两类真误判（\(..\) 已定界题干二次包、Unicode 写法中文题干），收紧规则后 45→2 处；已 --apply（eq#980 解析 14 行裸公式包 `$$…$$` + 正确答案），原值备份 `logs/bare_latex_backup_*.jsonl`，幂等复核 PASS。

**验证**：离线 33/33 全绿；迁移后 980 全文经真实渲染管线 extract 自证（14 块级+27 行内全提取，仅货币防误判保留 `$2-m…` 一条原文，属已知限制）；服务重启后 UI harness 12/12 全绿。教训归档掉坑笔记（批量改写必须 dry-run+逐类抽样，禁止直接 apply）。

**新限制**：货币防误判代价首次在本机数据显现——`$2-m\pm|m+2|<4$`（数字开头的真数学式）仍显示原文，不报错不砸排版；如需渲染可改写为 `$(2-m)\pm…$` 或后续细化规则。
