## 追加修复 · 2026-09-28（知识点提取全空白）

- **现象**（用户实测）：录音笔记"提取知识点"提示成功 7 个，但列表全空白无文字；编辑弹窗名称/描述为空；保存后左侧全空；"新增知识点"报"知识点名称不能为空"。
- **根因**：`/api/knowledge/extract-file`（routes_bridge.py）遍历 `processed_points` 时直接读包装层字段，而 LLM 提取结果（`concept_name/core_definition`）实际嵌在 `extracted_point` 内层 → 返回给前端的 name/description 全为空字符串，下游四个症状（列表空白/编辑空/保存 0 条/新增报名称为空）由此连锁产生。
- **修复**：解包 `extracted_point` 后再取名称/描述，兼容两套字段命名；过滤空名称项；全部无效时返回明确错误"未能提取到有效知识点"而非虚假成功。
- **证据**：`server/tests/r10_extract_fix_check.py`（真实 DeepSeek 端到端：注册→落盘笔记→extract-file→batch-save→列表回查→point-new）**8 PASS / 0 FAIL**；全量 pytest **49 passed**。
- **影响面**：仅服务端 routes_bridge.py，无需重打 exe；服务端已重启生效，应用内重新提取即可。
