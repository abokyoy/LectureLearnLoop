# 2026-10-08 判分结果页显示原题选项

## 背景（用户反馈）

「练 → 科目总览 → 从知识点开始练」的熟练度评估（及基于笔记练习/举一反三）批改完成后，结果页只显示"你的答案：A　正确答案：B"这样的字母，**看不到原题的选项内容**，用户无法回看每个选项是什么。此需求此前已提过；本次核查确认**不是 worktree 未合并问题**（仓库只有 main 一个分支/工作树），旧实现只把选项存进了错题本流水（数据层），即时判分结果页从未展示选项。

## 业务变更（业务语言）

1. 熟练度评估、基于笔记练习、举一反三三个通道的**判分结果页**，每道题下方现在完整列出原题选项（A/B/C/D 文本）：
   - 正确答案：绿色浅底高亮 + 对勾；
   - 用户答错的选项：红色浅底 +「（你选的）」标注；
   - 判断题/填空题/简答题无选项的，不显示选项区，保持原样。
2. 原"你的答案 / 正确答案 / 解析 / AI 点评"信息行保留不变。

## 技术实现

- `server/static/js/pm_pages.js`：
  - 公共渲染函数 `optionsHtml(e, markCorrect)` 扩展可选第三参 `userLetter`（误选标注）；不传时与旧版逐字节一致，错题列表/翻卡三个存量调用点不受影响。
  - 误选判定带守卫：答案须落在合法选项字母范围或与选项文本相等才标注（防简答/填空自由文本首字符巧合误标，同口径支持判断题文本答案）。
  - `submitAssess` / `submitPractice` 结果渲染按 `question_index` 从本地题目数组回取原题选项数据，越界/缺失自然降级为空。
- `frontend/tailwind.config.js` + `design/DESIGN.md`：新增设计令牌 `cl-danger-soft #FEECEC`（红色浅底），并重建 `server/static/css/cl.css`。顺带修复存量隐患：错题"错误"徽标此前引用了不存在的 `bg-cl-danger-soft` 类，现在令牌补上后正常显示红底。
- 后端与数据库无改动（选项数据本就在前端本地与落库流水中）。

## 验证

- E2E 断言扩展：`u10_verify.py`（评估通道：选项可见 + 正确项 + 误选标注）、`u13_verify.py`（练习通道：选择题选项在结果页保留），两条全绿、无页面错误。
- CodeReview 子代理评审：无 Blocker/Major；2 个 Minor（缺失样式令牌、误标守卫）均已修复并复跑通过。
- 截图识图闭环：`design/walkthrough/verify_options_result.png` 确认绿底正确项、红底「（你选的）」误选项按设计渲染。

## 已知限制

- 结果页选项展示依赖本次作答题目仍在页面内存中；刷新页面后回看走「错题本翻卡」（该路径选项展示早已实现）。
