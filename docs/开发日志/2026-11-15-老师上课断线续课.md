# 2026-11-15 老师上课断线续课（同一堂课永不自动结束）

## 用户报障（实弹三症状）

1. 学生长时间不说话（看课件/做笔记/低头计算），老师就说「那今天就先讲到这里，拜拜」退下，但每隔 3~5 分钟又吭一声（「安静好一会了，那我先不吵你了」）。
2. 学生想接着提问时，面板显示「连接异常: Get Address Info」，随后「重试 5 次仍失败，请下课后再点上课」——被强制踢下课。
3. 被迫下课→再上课后，老师从零重开（get lesson materials → board show problem → board clear → show problem → write…），接不上上一题，「没有连上上一题」。

**用户裁定**：「老师可以隔一会提醒一下，然后直到用户点击下课。但如果这个时候用户开始说话，应该无缝地衔接上来。只要没有点击下课，他就是同一堂课。」

## 三症状定性（全部代码实锤，非推测）

- **症状①＝小智云 console 待机行为，非本项目缺陷**：2026-11-05 日志已实弹定性——静音超时道别/ periodic 安抚语是云端 console 侧行为，客户端协议层无法注入续课指令（listen.detect 只收唤醒词）。本轮处置：使其**无害化**（客户端永不判死 + 服务端续讲定式），云端道别语本身可在 console 调长待机时间。
- **症状②＝xz_voice.js 重连 5 次判死 + tries 计数泄漏（独立发现，本轮主因）**：`reconnect.tries` 在 onReady 成功时**不清零**，云端每轮待机断线-重连循环消耗 1 次配额，长课攒满 5 次即误判死——DNS 抖动（Get Address Info）只是压死骆驼的最后一根。
- **症状③＝断线后云端会话记忆清零 + 服务端返回文案主动引导重开**：lecture_board.py 取料清单分支的引导语「选一道题，用 board_show_problem…开始讲解」把失忆后的老师直接推上「从零重开」路径；错题课没有 kp 课那样的「续讲…严禁结课道别」定式。

## 修复（两层）

### A 层 客户端 desktop/xz_voice.js——课堂永不自动结束

- 重连改 `RECONNECT_LADDER=[800,2000,3000,5000,8000,15000,30000,60000]` **封顶无限重试**，删除「5 次判死踢下课」；`tries===4`（连续失败超 10 秒）发一次弱提示「课堂网络暂时不通，后台持续自动重连中——恢复后接着上这堂课，不用下课重开」，恰一次、连上即清零。
- `onReady` 成功必 `reconnect.tries = 0`（计数泄漏修复，实弹主因）。
- 课中后台重连走 `register({silent:true})`：不做 registering/idle/error 状态翻转，面板全程保持「上课中」（借鉴安卓 AssistantHub「会话常驻、踢线后台静默重连」先例）。
- `needBind/bound=false` 不再断链：绑定失效属可恢复态，后台继续重试并提示可到设置页重新绑定。
- 下课只由用户驱动（lessonStop/关窗）；BOUNCE 防乒乓熔断（被别的设备顶线）保留——这是唯一非用户触发的断链。
- 评审 W1 竞态修复：重连定时器 `await register()`（真实 OTA 往返）期间用户 lessonStop，回来后复查 `wantLive/session/session.closed`，防止 `_connectSocket(null)` 建僵尸连 + onReady 对 null 取属性抛未捕获异常。

### B 层 服务端 server/services/lecture_board.py——黑板即课堂权威锚

- 新增 `_resume_directive(uid)`：黑板非空即返回「【课堂进行中】…严禁 board_clear、严禁重新上题、严禁从头重讲题干。对照板面状态行找没讲过的卡从最旧接着讲…只有学生明确说要换题才另开新题」。
- 新增 `_board_lesson_on(uid, error_id)`：板非空且 source_error_id==error_id（本题就是当前课堂在讲的题）。
- 三处应用：① 无 error_id 清单分支——板非空时以续讲定式替代「选一道题开始讲解」引导语（评审 W2：有网页点名指派 pre 时**不叠**定式，防相反指令同屏吞掉换题请求）；② 带 error_id 素材重放——题已在板时返回续讲口径且**保留 _suggest_plot**（配图是讲中正常动作，test_30 老用例钉出）；③ board_show_problem 防重复上题——重 show 当前在板题直接拒绝并回续讲定式，不触发换题重开。
- **擦板＝明确结课**：board_clear 后板空、定式返空、防抖不拦，回到正常上题流——结课语义只挂在用户/老师的明确擦板动作上。

## 业务规则变更（同步至业务规则总览 §二十）

- **课堂永不自动结束**：没点下课＝同一堂课；重连无限退避封顶 60s、面板保持「上课中」；被顶线熔断除外。
- **断线续课以板面为权威**：黑板非空时取料/上题返回续讲定式；擦板＝明确结课；网页点名指派压过续讲定式。

## 已知限制

- 云端待机道别/安抚语本身仍由小智云 console 待机设置决定，客户端不拦（拦不住）；本轮保证道别后课堂链路不断、老师回来能接上。用户可在 console 调长待机静音时间进一步减少道别频次。
- 生效前提：lecture_board.py 需重启 9992 Flask 服务；xz_voice.js 需重启 Electron 客户端。
