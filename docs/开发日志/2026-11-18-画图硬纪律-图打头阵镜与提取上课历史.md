# 2026-11-18 画图硬纪律轮：图打头阵镜 + 知识点提取历史 + 上课历史课件

## 背景（用户三问题四需求原话摘要）

1. 「画图还是非常懒惰」→ 增加硬性要求：每次切换段落都必须有图；前面有总览图；每推进一个段落都要有一张大的图打头阵。
2. 图的要求：老师看到自己讲的文字内容落不进当前图，就必须重新生成一张新图；绘图方式太贫瘠，MERMAID、各种数据图、像画 PPT 一样的图都要列出来，确保每句话都能落在图上。
3. 知识点提取：从课文提取过以后应该保留下来，列在右边，用户可以点击展开自己历史提取过的知识点。
4. 上课历史：从课程里点「让 AI 老师讲课」上完课，如果生成了课件，应该在「让 AI 老师讲课」底下显示，让用户知道自己的上课历史。

## 改动清单（业务语言）

### 一、画图硬纪律（三管齐下）

- **指导语前置**（`server/services/lecture_board.py`）：lesson/text/kp 三类取料指导语重写「画图铁律（每个段落图打头阵）」段——每进入新关键点/段落，第一步先 board_draw 一张代表这一段落的图上板再开嘴讲；讲的内容落不进现有图立刻画新图别硬塞旧图；开局先画总览图定场。两个课内重放句同步补打头阵口径。
- **选图速查表**（绘图方式全景）：关系/层级→diagram(flow/tree)、拆原理理思路→mermaid、数量对比→stats(bar)、占比→pie、相关性→scatter、函数变化→function、区间→numberline、角度→unitcircle/polar、几何→geometry、过程步骤→timeline、要点清单/对比表→diagram 排版块（PPT 式版式）——同口径进指导语、镜文案、board_draw 工具描述。
- **图打头阵镜**（新镜，`_plot_lag_mirror`）：黑板记账「上次画图以来的文字卡数」（cards_since_plot：plot 卡入板清零、文字卡累加封顶 20；擦板/换课清零），≥2 张时下次工具返回拦嘴递选图速查表并消费清零。与说了没写镜互补：那镜盯「完全不写」，这镜盯「只写字不画图」。
- board_draw 工具描述补「新关键点图打头阵——先画图再开嘴讲；落不进当前图就画新图」，并为 400 字符闸精简同义反复（438→397）。

### 二、知识点提取历史（需求 3）

- 新表 `lesson_extracts`（user_id/lesson_id/point_name/created_time，UNIQUE 三元组）：`server/database/schema_postgres.py`。
- 端点 `GET/POST /api/course/lessons/<lid>/extracts`（`server/routes_courses.py`）：POST 回写入库成功的知识点名（ON CONFLICT DO NOTHING 幂等、空名清洗、单条名 ≤120、单次 ≤50 条、越权 404）；GET 新提在前最多 200 条。
- 前端（`server/templates/pages/learn_goals.html`）：右栏「从课文提取知识点」按钮上方加「已提取（N）」折叠块（默认收起，展开见名字+日期）；「加入知识点库」成功后自动回写勾选的知识点名并刷新历史块（回写失败静默跳过，不影响入库提示）。

### 三、上课历史课件（需求 4）

- 归属链：课程页指派消费后板上学课 id 常驻 → `board_slide_image` 透传 `course_lesson_id`（新函数 `LB.get_course_lesson_id`）→ `ensure_course` 建课时写进 `micro_courses.source_ref` JSON；`append_slide` 同步带参（首张页建课时记归属）。
- 反查 `list_lesson_courses`：按课文 id 匹配 source_ref（双 LIKE：键后跟 `,` 或 `}`，防 id 前缀撞号——12 不得误中 123），只回有页的课，新在前。
- 端点 `GET /api/board/lesson_courses?lesson_id=`（`server/routes_board.py`）。
- 前端：「让 AI 老师讲课」按钮下方「上课历史」块——列该课文历史课件（标题/页数/日期），点击懒加载逐页缩略图（走既有 `/api/board/lesson` + `/api/board/asset/sign` 签名链），点图新窗口看大图；无历史不显示块。

## 已知限制

- 镜检仍搭 execute_tool 返回尾链递送：老师长段不调工具期间送不进去（结构性老口径，开局窗口靠指导语前置覆盖）。
- 归属只在**建课时刻**记（首张课件页）：本课之前的历史课件（改动上线前上的课）不回补——历史数据无 course_lesson_id 关联，「上课历史」块从本轮起累积。
- lesson_extracts 记录的是「确认入库过的名字」；提取了但没点入库的不留档（与「不白耗积分」口径一致）。
