## 四、目标架构

```
┌─────────────────────────────────────────────────────┐
│  Electron 桌面客户端（本机）                          │
│  ├─ 主窗口：登录/注册 + 7 个功能页面（1:1 迁移旧 UI） │
│  ├─ 悬浮窗：always-on-top 小组件                      │
│  │   · 开始学习(录系统声音)/开始录音(麦克风) 两个入口  │
│  │   · 声波动画 = 正在录音指示                        │
│  │   · 下方小窗 = Deepgram 实时转写字幕               │
│  │   · 📷 截屏按钮 → 全屏矩形框选 → 插入当前笔记      │
│  └─ 音频管道：desktopCapturer loopback → WebSocket ──┼──┐
└─────────────────────────────────────────────────────┘  │ HTTP :6001
┌─────────────────────────────────────────────────────┐ ◄─┘
│  Python Flask 服务端（本机 localhost:6001）           │
│  ├─ /api/auth/*     注册/登录/JWT（新增）             │
│  ├─ /api/knowledge/* 提取/确认/列表（多用户隔离）     │
│  ├─ /api/practice/* 出题/答题/熟练度评估（补齐）      │
│  ├─ /api/notes/*    笔记/段落总结/截屏图片（补齐）    │
│  ├─ /api/asr/stream WebSocket → Deepgram 实时转写代理 │
│  ├─ 业务层：复用旧模块 + user_id 过滤                 │
│  └─ 统一日志：logger_module → logs/debug_trace.jsonl  │
└─────────────────────────────────────────────────────┘
```

**关键设计决定**（架构收敛原则 + 审核后修正）：
1. 旧 Jinja2 模板转为 Electron 加载的静态页面（实测页面内 0 处 url_for/block，模板层静态化几乎零成本）；**保留 base.html 的 SPA 外壳结构不拆**，只做宿主迁移；真正的改造量在 **api.js 把 55 个 pybridge 回调方法扩成完整的 fetch+JWT 兼容层**
2. **Deepgram 实时流由 Electron 主进程直连**（Node `ws`）：渲染进程 AudioWorklet 采集 → 重采样 16kHz + Int16LE PCM → 主进程 WS 到 Deepgram（`encoding=linear16&sample_rate=16000&channels=1&model=nova-2&language=multi`）；密钥不落客户端：登录时从服务端换取**临时流式 token**；Flask 2.0.1 无 WS 能力，不选 Python 代理路线
3. **Electron 用当前 stable（≥31）**；主进程 `session.setDisplayMediaRequestHandler` 免弹框选 source；P4 开工先跑 **10 分钟冒烟测试**（录 5s 系统声→WAV→验 RMS 非零），不通过立即切退路 A
4. Flask 升级到 3.x 一次到位（JWT、新 API、SECRET_KEY 落盘在同一版本基线上做）
5. 新目录：`E:\LLM\LectureLearnLoop\desktop\`（Electron）与 `E:\LLM\LectureLearnLoop\server\`（Python 服务端）；`LectureLearnLoop_new` 作为旧代码参考源，不动它；严禁复制 app_config.json / llm_api_calls_detailed.jsonl
