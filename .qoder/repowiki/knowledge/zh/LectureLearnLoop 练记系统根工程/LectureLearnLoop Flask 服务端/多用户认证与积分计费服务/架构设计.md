模块由三层组成：
- 认证层 `auth.py`：定义 `auth_bp` Flask Blueprint，暴露 `/api/auth/*`（register/login/me/password/profile）和 `/api/asr/config`；通过 `require_auth` / `require_admin` 装饰器把 `g.user_id`、`g.username`、`g.is_admin` 注入请求上下文，使用 HS256 + `JWT_TTL_DAYS` 环境变量签发 JWT。
- 计费核心层 `credits_service.py`：唯一积分读写入口，封装 system_config、user_credits、credit_transactions、activation_codes、user_llm_config 等表的 CRUD，提供 charge_llm / charge_asr / grant_daily_bonus / redeem_code / admin_adjust / precheck 等纯函数，并通过 `threading.local` 在单次调用链内传递计费结果供响应附加。
- 路由层 `routes_credits.py`（用户侧 `/api/credits/*`、`/api/user/llm-config`）与 `routes_admin.py`（管理员侧 `/api/admin/*`）仅做参数校验与 JSON 包装，业务逻辑全部委托 credits_service。
依赖方向单向：routes → auth decorators → credits_service → database.db_adapter；admin 端点复用 require_admin 装饰器，LLM 配置通过 effective_llm_config 合并 .env / runtime_config.json / system_config 表三层优先级。
