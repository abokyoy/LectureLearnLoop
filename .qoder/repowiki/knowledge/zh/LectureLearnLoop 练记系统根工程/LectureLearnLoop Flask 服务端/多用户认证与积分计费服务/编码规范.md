- 所有 HTTP 端点统一返回 `{success, data|error}` 结构的 JSON，错误走 `jsonify({"success": False, "error": ...})` 并附带 HTTP 状态码。
- 鉴权通过装饰器注入上下文：`@require_auth` 设置 `g.user_id/g.username`，`@require_admin` 在其之上再查 users 表校验 is_admin=1。
- 数据库访问一律通过 `_get_db()` / `_conn()` 获取连接并在 `with` 块中使用，异常路径用 `try/except Exception` 捕获后记录 debug_logger 并返回友好错误。
- 敏感字段（密码、API Key）写入前用 werkzeug 的 generate_password_hash / strip 处理，读取时通过 _mask_key 或掩码算法脱敏后再返回前端。
- 可配置的业务参数集中存放在 system_config 表，通过 get_number/get_config_value/list_all_config 访问，并提供白名单 `_EDITABLE_CREDIT_KEYS` 限制管理后台可写键集。
