- 所有 HTTP 端点统一使用 `@require_auth` 装饰器，用户身份从 `g.user_id` 读取，请求体通过 `request.get_json(silent=True) or {}` 安全解析。
- 响应体统一封装为 `{success: bool, data|error}`，成功走 `_ok()`，失败走 `_err(message, code)`，LLM 相关异常直接返回 500 不兜底。
- 数据库访问一律通过 `db_manager.get_connection()` 获取连接，并在方法末尾显式 `conn.close()`，写操作包裹 try/except 后 commit，异常时 rollback。
- 多后端（SQLite / PostgreSQL）通过 `db_adapter.is_postgres()` 分支初始化 DDL，PG 走 `schema_postgres.init_postgres_schema`，SQLite 则内联 CREATE TABLE IF NOT EXISTS。
- 对存量 SQLite 库的列新增使用 try/except ALTER TABLE 包裹，保证幂等迁移；UUID 字段迁移同样采用 try/except 容错。
- LLM 调用统一通过 `LLMProviderFactory().call_llm(...)`，不再保留 DeepSeek/Gemini/Ollama/Qwen 的多级降级链，失败直接向上抛出。
