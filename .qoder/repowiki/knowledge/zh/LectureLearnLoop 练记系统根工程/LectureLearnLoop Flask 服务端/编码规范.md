- 所有业务功能以 Flask Blueprint 形式实现，由 `app.py` 统一 `register_blueprint` 装配，禁止子模块自建 Flask 应用。
- 数据库访问统一经 `DatabaseManager` 提供的连接工厂，避免在路由层直接 `sqlite3.connect`。
- 对外 API 返回统一的 `{success, data}` JSON 结构，错误走 `error_slicer` 切片后回传。
- 敏感配置（SECRET_KEY、LLM Key、ASR Key）一律从 `.env` 读取，不硬编码。
- 日志通过 `debug_logger` 写入 `logs/debug_trace.jsonl`，LLM 调用额外追加 `logs/llm_calls_<date>.jsonl`。
