模块由四个职责清晰的子层构成：
- 应用装配层 `app.py`：通过 `create_app()` 工厂函数构建 Flask 实例，统一启用 CORS、挂载 `pages_bp/auth_bp/kb_bp/bridge_bp/notes_bp/credits_bp/admin_bp` 等蓝图，注册 `/api/health`、`/api/debug/log`、`/api/debug/recent` 三个内置端点，并在 `before_request` 中清理计费上下文；进程启动时强制监听 `127.0.0.1:6001`。
- 配置中心 `config.py`：唯一配置来源，从 `.env` 读取环境变量（SERVER_PORT/JWT_SECRET/DEEPGRAM_* / PG_* / DEEPSEEK_* 等），持久化 Flask SECRET_KEY 到 `data/flask_secret.key`，并通过 `load_config()` 输出兼容旧 `app_config.json` 键名的字典，同时合并 `data/runtime_config.json` 运行时覆盖项（db_path/practice_db_path/vault_dir/db_backend 受保护不可覆盖）。
- 调试日志 `logger_module.py`：线程安全的单例 `DebugLogger`，以 JSON Lines 格式写入 `logs/debug_trace.jsonl`，支持 backend/frontend/mobile 多来源，并提供 `read_recent` 供 Agent 验证。
- LLM 调用日志 `llm_logger.py` + `llm_call_logger.py`：两套并存的 LLM 日志实现——前者按提供商（gemini/ollama/qwen/deepseek）分别写 `*.log` 与 `_detailed.jsonl`；后者用 `LLMCallRecord` dataclass 记录 start→first_byte→end 三段式时序，按天分文件 `logs/llm_calls_YYYYMMDD.jsonl`，并提供统计聚合接口。
依赖方向：`app.py` → `config.py` + 各 blueprint；`llm_call_logger.py` → `config.load_config()`；`llm_logger.py` 独立无外部依赖。
