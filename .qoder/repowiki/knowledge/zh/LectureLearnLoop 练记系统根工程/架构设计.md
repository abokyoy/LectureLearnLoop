根目录作为多端工程的装配层：
- `server/`（Flask）与 `desktop/`（Electron）通过 HTTP API 解耦通信，Electron 作为前端调用 Flask 的认证、知识点、笔记等蓝图接口。
- `docs/` 沉淀架构原则、业务规则与交付说明，是前后端共同遵守的权威契约；AGENTS.md 在根级定义跨子模块的开发流程、调试日志规范与并行开发纪律。
- `start_app.ps1` 是唯一的本地一键入口：先检测并启动 Flask（默认端口 6001），再启动打包后的 `dist/win-unpacked/LectureLearnLoop.exe` 或源码模式下的 Electron（CDP :9222），实现“后端 + 桌面端”的联合运行。
- 所有子模块共享统一的调试通道 `logs/debug_trace.jsonl`，Agent 以此作为功能验证的唯一依据，而非用户主观反馈。
