- 每个 LLM 提供商实现继承 `LLMProvider` 并在 `call` 中遵循 start_llm_call → record_first_byte → end_llm_call 三段式埋点，异常分支一律用 `end_llm_call(..., success=False, error_message=...)` 收尾。
- 对外暴露全局单例（`llm_call_logger`、`llm_factory`、`_llm_logger`）并通过同名便捷函数（如 `start_llm_call`、`call_llm`、`log_gemini_call`）包装，避免调用方直接操作实例。
- Provider 构造时对缺失的 API Key 抛出 `ValueError`，并在 `test_connection` 中用固定 prompt 验证连通性，供上层统一测试。
- 日志文件按日期分片（`llm_calls_{YYYYMMDD}.jsonl`、`*_detailed.jsonl`），每条记录以 `json.dumps(ensure_ascii=False)` 追加一行，便于流式消费。
