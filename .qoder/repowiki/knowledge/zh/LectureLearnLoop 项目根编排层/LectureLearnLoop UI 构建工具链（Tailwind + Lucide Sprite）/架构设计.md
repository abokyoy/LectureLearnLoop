纯构建期工具模块，无运行时 JS，由 package.json 的 scripts 暴露三个命令：`build:css` 调用 tailwindcss CLI 将 `input.css` 编译到 `../server/static/css/cl.css`；`build:sprite` 执行 `build_sprite.js` 从 `lucide-static/icons` 提取白名单图标生成 `../server/static/icons/lucide-sprite.svg`；`build` 串联两者。
- `tailwind.config.js` 定义双轨颜色体系：旧 token（primary/text-gray 等）保留给未迁移页面，新设计系统统一使用 `cl-*` 前缀并与 design/DESIGN.md 对齐；通过 `content` 扫描 `../server/templates/**/*.html` 与 `../server/static/js/**/*.js`，并通过 `safelist` 兜底 JS 动态 classList 切换的类。
- `input.css` 作为 Tailwind 入口文件。
- `build_sprite.js` 维护 ICONS 白名单数组，新增图标需同时维护该数组并重跑构建。
- 依赖方向单向指向 `../server/` 下的模板与静态资源，自身不包含任何业务逻辑。
