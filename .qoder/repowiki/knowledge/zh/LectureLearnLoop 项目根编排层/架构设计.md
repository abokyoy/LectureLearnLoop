根目录不承载业务逻辑，而是作为跨子模块的编排中枢：
- `start_app.ps1` 是单一入口，按序拉起 `server/app.py`（默认 :6001）与 Electron 客户端（生产走 `dist/win-unpacked/LectureLearnLoop.exe`，开发 `-Dev` 走 `desktop/` 源码 + CDP :9222），并复用 V2RAYN 代理访问 Stitch MCP。
- 依赖方向单向收敛：`frontend/` 构建产物直接写入 `server_backend/` 静态目录，再由 `desktop_electron/` 加载；`design/` 作为 UI 契约被 Web 与桌面端共同引用。
- `AGENTS.md` 定义全仓统一的 Agent 工作原则、调试日志格式（`logs/debug_trace.jsonl`）、Stitch MCP 调用规范与 git worktree 并行开发纪律，是所有子模块共同遵守的开发协议。
- 根级 `_*.py` / `_*.js` 为临时脚本或 review diff，不属于正式架构。
