根目录不承载业务逻辑，而是按职责拼装子模块：`server_backend/`（Flask）暴露 HTTP API，`desktop_electron/`（Electron）通过该 API 调用后端并桥接本地能力；`frontend/` 提供 Tailwind + Lucide sprite 的 Node.js 构建管线供 Electron 消费；`design/` 沉淀 Stitch 设计契约与 UI 验收截图；`docs/` 集中架构原则与业务规则，是所有子模块共享的权威参考。跨子模块的统一契约包括：统一调试日志写入 `logs/debug_trace.jsonl`、`.env` 配置加载、V2RAYN 代理网络走向规则，以及 AGENTS.md 中强制的并行开发（git worktree）、超时控制与 CodeReview 流程。
