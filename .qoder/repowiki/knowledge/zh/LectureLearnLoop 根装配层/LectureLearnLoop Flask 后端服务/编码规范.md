- 所有蓝图通过 `app.register_blueprint` 在 `create_app` 中集中注册，禁止子模块自行实例化 Flask 应用。
- 外部敏感参数一律从 `.env` 读取并通过 `config.load_config()` 暴露，禁止硬编码 API Key 或直读 `app_config.json`。
- 数据库访问统一经 `DatabaseManager.get_connection`，新建表需在 `schema_*.py` 中声明并在 `create_app` 时调用初始化函数。
- 跨请求的线程局部状态（如计费上下文）在 `@app.before_request` 中显式清理，防止 Gunicorn/Flask threaded 模式下的 worker 复用污染。
- SQL 编写使用 SQLite 风格语法（`?` 占位符、`CURRENT_TIMESTAMP`、`INSERT OR IGNORE`），由 `db_adapter._translate_sql` 自动翻译为 PostgreSQL 方言。
