典型 Electron 双进程架构，依赖方向单向：渲染层 → preload → main → asr_proxy → ws。
- `main.js` 主进程入口，创建三类 BrowserWindow（主窗口加载 `SERVER_BASE/`、悬浮录音窗 `/overlay`、全屏框选窗 `/capture`），通过 `ipcMain.handle/on` 暴露 `overlay:*`、`asr:*`、`capture:*`、`notepicker:*`、`app:getServerBase` 等通道；处理 `did-fail-load` 重试后端、`window-all-closed` 清理 ASR 会话。
- `preload.js` 使用 `contextBridge.exposeInMainWorld` 暴露最小 API（`llShell`、`llAsr`、`llCapture`、`llOverlayDrag`、`llCaptureSel`、`llNotePicker`），严格遵循 `contextIsolation: true` + `nodeIntegration: false`。
- `asr_proxy.js` 独立主进程模块，封装 Deepgram WebSocket 流式识别会话，维护 open/close 状态、消息队列与事件回调，密钥仅驻留主进程。
- 渲染侧 HTML 由外部 Flask 服务提供（`renderer/index.html` 仅占位），Electron 仅充当宿主壳。
- 屏幕捕获通过 `session.setDisplayMediaRequestHandler({ useSystemPicker: false })` 绕过系统选择器，直接返回第一个屏幕与 loopback 音频。
