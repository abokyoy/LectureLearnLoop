本模块为纯设计资产目录（无代码），由三部分构成：
- `DESIGN.md` 是单一设计契约，声明 `--cl-*` CSS 变量（色彩）、字体族/字阶、圆角/阴影/描边、8px 网格间距、左侧 72px 边栏 + 56px 顶栏 + 1120px 主区的布局骨架，以及按钮、功能卡、徽标、进度条、空态等核心组件规范。
- `stitch_candidates/` 存放 Stitch 工具产出的四组混合主题候选图及对应 JSON 响应（A_corgi_orange / B_indigo_calm / C_mint_fresh / D_orange_mint_mix），其中 D 被标记为用户拍板定稿依据。
- `walkthrough/` 按编号顺序（01_dashboard → 16_practice_errors）与 b1–b9c 系列截图覆盖 Dashboard、在线课程、知识库、设置、LLM Logs、练习、登录、管理员 Credits、笔记选择器、悬浮窗等所有页面的走查截图，供 `server/tests/ui_pw_shot.py` 做截图对比与识图审查。
依赖方向单向：实现层（前端 CSS/Tailwind/Lucide）必须引用 DESIGN.md 中的 token 与组件规范，不得散落自定义色值或行内样式。
