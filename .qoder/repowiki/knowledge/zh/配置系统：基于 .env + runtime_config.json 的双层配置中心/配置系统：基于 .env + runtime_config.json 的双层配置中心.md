## 1. 采用的方案

服务端采用 **`python-dotenv` + 模块级常量 + JSON 运行时文件** 的轻量配置体系，由 `server/config.py` 作为唯一入口。Electron 桌面端通过进程环境变量 `LL_SERVER` 指向 Flask 服务地址，无独立配置文件。

- 部署/环境配置 → `.env`（`dotenv.load_dotenv` 加载）
- 用户可修改的运行时配置 → `server/data/runtime_config.json`
- 路径与密钥持久化 → `server/data/flask_secret.key`、`server/data/knowledge_management.db` 等

## 2. 关键文件

| 文件 | 作用 |
|---|---|
| `server/config.py` | 配置中心：加载 `.env`、定义路径常量、提供 `load_config()` / `save_runtime_config()` / `get_flask_secret_key()` |
| `server/.env.example` | 配置模板，含所有必需环境变量说明 |
| `server/.env` | 实际生效的环境变量（被 `.gitignore` 排除） |
| `server/data/runtime_config.json` | 用户通过设置页保存的运行时覆盖项 |
| `server/data/flask_secret.key` | Flask session 密钥持久化文件 |
| `desktop/main.js` | Electron 主进程，从 `process.env.LL_SERVER` 读取后端地址 |

## 3. 架构与约定

### 3.1 配置分层

```
.env (部署/环境)  ──→  config.py 常量 (SERVER_PORT, JWT_SECRET, PG_*, DEEPSEEK_*)
runtime_config.json (用户设置) ──→ load_config() 合并到 dict
```

- `.env` 中的键名与旧 `app_config.json` 保持一致（迁移兼容），但数据源已切换为 `os.getenv`。
- `load_config()` 返回一个扁平 dict，键名包括 `llm_provider`、`deepseek_api_key`、`similarity_min_score`、`db_path`、`vault_dir`、`http_proxy`、`db_backend` 等，供 `llm_provider_factory`、`knowledge_management`、`auth.py` 等旧模块直接消费。
- `RUNTIME_CONFIG_FILE` (`data/runtime_config.json`) 在每次调用 `load_config()` 时合并，但以下键受保护不可被设置页覆盖：`db_path`、`practice_db_path`、`vault_dir`、`db_backend`。

### 3.2 数据库后端开关

`DB_BACKEND` 是全局后端开关（`postgres` | `sqlite`），默认 `sqlite` 仅为回退能力；生产目标为 `postgres`。当检测到非 postgres 时会打印 WARN 并提示拷贝 `.env`。连接池参数 `PG_POOL_MIN` / `PG_POOL_MAX` 通过 `database/db_adapter.py` 使用。

### 3.3 Flask SECRET_KEY 持久化

`get_flask_secret_key()` 首次启动生成随机 key 写入 `data/flask_secret.key`，后续重启复用，避免会话失效（修复断点 D3）。`app.py` 在工厂中调用它设置 `app.secret_key`。

### 3.4 运行时配置读写

- `save_runtime_config(updates)` 由 `routes_bridge.py` 暴露给前端设置页，以 JSON 形式落盘。
- 调用方负责过滤白名单外的键；函数本身对异常静默返回 `False`。

### 3.5 Electron 端配置

Electron 主进程仅通过 `process.env.LL_SERVER`（默认 `http://127.0.0.1:6001`）定位 Flask 服务，并通过 IPC `app:getServerBase` 暴露给渲染进程。窗口行为（悬浮窗、截屏、ASR 代理）硬编码在主进程中，无外部配置。

## 4. 开发者规则

1. **新增环境变量**：在 `config.py` 中用 `os.getenv("KEY", "default")` 声明，并在 `.env.example` 中添加注释行。
2. **禁止直接读 `app_config.json`**：该机制已在注释中标注废弃，所有新代码必须走 `config.py`。
3. **敏感信息不进仓库**：`.env`、`flask_secret.key` 均被忽略；部署时复制 `.env.example` 后填入真实值。
4. **运行时配置只允许覆盖非保护键**：路径类键（`db_path`、`vault_dir` 等）和 `db_backend` 只能通过 `.env` 修改。
5. **DB_BACKEND 生产必须为 postgres**：worktree 并行开发时务必设置，否则 SQLite 会创建空库造成“数据丢失”假象。
6. **Electron 端后端地址统一通过 `LL_SERVER` 环境变量注入**，不要硬编码端口。
7. **新增 LLM 提供商**：在 `load_config()` 中补充对应键（保持旧键兼容），并在 `llm_provider_factory.py` 中注册。
