## 详细组件分析

### 知识点审核流程
- 触发来源：自动生成或导入的内容进入“待审核”状态。
- 审核步骤：
  - 加载待审条目（支持按课程、标签、时间范围筛选）。
  - 展示内容预览与元数据（创建者、版本、质量初评、违规风险）。
  - 审核员进行判断：通过/打回/修改建议/拒绝。
  - 系统根据策略计算质量分与违规等级，并生成审计记录。
  - 更新内容版本与发布状态。

```mermaid
flowchart TD
Start(["开始"]) --> Load["加载待审条目"]
Load --> Preview["内容预览与元数据"]
Preview --> Decision{"审核决策"}
Decision --> |通过| Score["计算质量分"]
Decision --> |打回| Revise["打回修订"]
Decision --> |拒绝| Reject["标记违规并拒绝"]
Score --> Audit["生成审计记录"]
Revise --> Audit
Reject --> Audit
Audit --> Version["更新版本与发布状态"]
Version --> End(["结束"])
```

### 内容质量评估与违规处理
- 质量评估维度：准确性、完整性、可读性、相关性、格式合规。
- 违规类型：敏感词命中、版权风险、低质重复、不当内容。
- 处理策略：
  - 自动标记：基于规则引擎对敏感词与低质特征进行预标记。
  - 人工复核：审核员对自动标记进行确认或修正。
  - 处置动作：打回修订、限制可见、删除归档、加入黑名单。

### 内容过滤规则、敏感词检测与自动标记
- 过滤规则：
  - 敏感词库：支持动态增删改，匹配模式含精确匹配、正则、上下文语义。
  - 低质检测：重复率、空洞内容、乱码、外链异常。
- 自动标记：
  - 命中敏感词即标记高风险，需人工复核。
  - 低质内容标记为“需修订”，不直接拒绝。
- 策略配置：
  - 阈值可调：敏感度阈值、低质分数阈值。
  - 白名单：特定用户/课程豁免。

```mermaid
flowchart TD
In["输入文本"] --> Pre["预处理(清洗/分词)"]
Pre --> Match["敏感词匹配(精确/正则/语义)"]
Match --> LowQ["低质检测(重复/空洞/乱码)"]
LowQ --> Tag["自动标记(高风险/需修订)"]
Tag --> Review["人工复核"]
Review --> Action{"处置动作"}
Action --> |通过| Publish["发布/入库"]
Action --> |打回| Revise["打回修订"]
Action --> |拒绝| Block["拒绝/归档"]
```

### 内容版本管理、回滚机制与审计追踪
- 版本管理：
  - 每次审核变更生成新版本，保留旧版本快照。
  - 版本差异摘要：关键字段变更、质量分变化、违规标记变化。
- 回滚机制：
  - 支持回滚至指定版本，需审计记录与权限校验。
  - 回滚后自动触发二次审核（可选）。
- 审计追踪：
  - 所有版本变更均记录审计日志，支持溯源与报表。

- 批量操作：采用事务批量更新，减少往返次数，提升吞吐。

- 并发控制：条目级锁或乐观锁，避免多人同时审核导致数据不一致。
- 分页与筛选：审核队列分页加载，避免一次性加载大量数据。

## 故障排查指南
- 审核队列无数据：
  - 检查内容是否进入“待审核”状态。
  - 检查筛选条件是否过严。
- 批量审核失败：
  - 检查权限与参数合法性。
  - 查看事务日志与审计记录定位失败条目。
- 敏感词未命中：
  - 检查敏感词库是否生效与匹配模式是否正确。
  - 检查白名单与豁免策略。
- 版本回滚异常：
  - 校验版本存在性与权限。
  - 查看审计日志中的回滚原因与操作人。
