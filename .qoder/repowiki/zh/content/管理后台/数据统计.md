## 引言
本文件面向LectureLearnLoop的数据统计功能，围绕用户活跃度分析、学习进度统计和内容使用率计算展开，系统说明报表生成、数据可视化图表与趋势分析方法。文档同时覆盖自定义查询、数据导出和多维度分析能力，给出统计指标定义、报表模板配置建议，并解释数据聚合算法、缓存策略与查询优化方法，帮助读者理解数据分析结果的业务价值与应用场景。

## 架构总览
统计功能的端到端流程如下：
- 前端仪表盘加载后，通过JS API发起统计请求
- 后端路由接收请求，校验参数并调用数据库适配器执行聚合查询
- 数据库层根据Schema返回聚合结果
- 后端将结果序列化并返回给前端
- 前端渲染图表并进行交互式筛选与导出

```mermaid
sequenceDiagram
participant FE as "前端仪表盘<br/>dashboard.html"
participant API as "前端API封装<br/>api.js"
participant APP as "应用入口<br/>app.py"
participant RT as "统计路由<br/>routes_admin.py"
participant DB as "数据库适配器<br/>db_adapter.py"
participant PG as "Postgres Schema<br/>schema_postgres.py"
FE->>API : "获取统计数据(时间范围/维度)"
API->>APP : "HTTP GET /api/stats/*"
APP->>RT : "分发到统计路由"
RT->>DB : "执行聚合查询(按日/周/月, 用户/内容)"
DB->>PG : "读取统计相关表结构"
PG-->>DB : "返回表/字段定义"
DB-->>RT : "返回聚合结果集"
RT-->>APP : "序列化JSON"
APP-->>API : "返回统计结果"
API-->>FE : "渲染图表/表格"
```

## 详细组件分析

### 用户活跃度分析
- 指标定义
  - 日/周/月活跃用户数：去重计数
  - 会话次数与平均时长：基于登录/退出或活动事件聚合
  - 连续活跃天数：滑动窗口统计
  - 新用户占比：新增用户/总活跃用户
- 数据来源
  - 用户行为日志、登录记录、页面访问记录
- 聚合算法
  - 按时间粒度分组，结合DISTINCT与COUNT实现去重计数
  - 使用窗口函数或子查询计算连续活跃天数
- 可视化
  - 折线图展示趋势，柱状图对比不同维度（如课程/知识点）
- 导出
  - 支持CSV/Excel导出，包含时间、维度与指标列

```mermaid
flowchart TD
Start(["开始"]) --> Range["选择时间范围与维度"]
```

  - 优先在数据库层完成GROUP BY、窗口函数与聚合计算，减少网络传输
  - 对高频指标建立物化视图或汇总表，降低实时计算压力
- 缓存策略
  - 对热点指标（如近7日活跃）启用短期缓存，设置合理TTL
  - 缓存键包含时间范围与维度，避免脏读
- 查询优化
  - 为常用筛选字段建立索引（用户ID、内容ID、时间戳）
  - 限制返回行数与超时，防止慢查询拖垮服务
- 前端优化
  - 图表按需加载与懒渲染，避免一次性绘制大量数据点
  - 分页与增量更新，提升交互流畅度

## 故障排查指南
- 常见问题

- 定位步骤
  - 查看后端日志与错误堆栈
  - 验证数据库连接与权限
  - 复现查询并在数据库客户端执行，确认结果集
- 恢复措施
  - 调整查询参数或增加索引
  - 清理过期缓存并重试
  - 分批导出大结果集
