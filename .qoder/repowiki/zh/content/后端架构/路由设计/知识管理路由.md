## 简介
本文件为 LectureLearnLoop 的知识管理路由模块提供系统化文档，聚焦知识点（Knowledge）的 CRUD、分类与标签、内容解析与关联分析、搜索与全文检索、智能推荐、版本管理、数据导入导出与批量处理等能力。文档从系统架构、组件职责、数据流、接口契约、错误码规范到性能优化策略进行分层说明，帮助开发者快速理解并扩展该模块。

## 详细组件分析

### 知识点 CRUD 与批量操作
- 创建知识点
  - 端点：POST /api/knowledge
  - 输入：标题、正文、分类、标签、来源、可见性、优先级、版本元数据等
  - 校验：必填字段、长度限制、标签去重、分类存在性
  - 输出：新建知识点对象（含 id、版本号、时间戳）
- 更新知识点
  - 端点：PUT /api/knowledge/{id}
  - 输入：可更新字段子集；支持增量更新或全量替换
  - 行为：生成新版本记录，保留历史版本
- 删除知识点
  - 端点：DELETE /api/knowledge/{id}
  - 行为：软删除或物理删除（由配置决定），清理关联索引
- 查询知识点
  - 端点：GET /api/knowledge/{id}
  - 输出：知识点详情（含分类、标签、版本链）
- 批量操作
  - 端点：POST /api/knowledge/batch
  - 输入：{ actions: [{op, id, data}] }
  - 行为：事务内执行多个动作，返回成功/失败明细

```mermaid
flowchart TD
Start(["接收请求"]) --> Validate["参数校验"]
Validate --> Valid{"校验通过?"}
Valid --> |否| Err["返回400/422"]
Valid --> |是| Op{"操作类型"}
Op --> |创建| Create["创建知识点+初始版本"]
Op --> |更新| Update["更新并生成新版本"]
Op --> |删除| Delete["标记删除/清理索引"]
Op --> |查询| Query["加载详情/版本链"]
Op --> |批量| Batch["事务批量执行"]
Create --> Commit["提交事务"]
Update --> Commit
Delete --> Commit
Query --> Return["返回数据"]
Batch --> Commit
Commit --> Return
Err --> End(["结束"])
Return --> End
```

## 性能考虑
- 查询优化
  - 合理使用分页与过滤条件，避免全表扫描
  - 对高频查询字段建立索引（标题、分类、标签、更新时间）
- 全文检索
  - 使用倒排索引与分词器，缓存热点查询结果
  - 增量更新索引，避免全量重建
- 批量处理
  - 使用事务与分批提交，降低锁竞争
  - 异步任务队列处理耗时操作（导入、索引重建）
- 缓存策略
  - 分类/标签字典缓存
  - 搜索结果短期缓存（带失效策略）
- 资源控制
  - 限制单次导入文件大小与条数
  - 并发控制与限流保护

## 故障排查指南
- 常见错误码
  - 400/422：请求参数校验失败（缺失必填字段、格式错误）
  - 404：资源不存在（知识点/分类/标签）
  - 409：冲突（重复标签、版本冲突）
  - 500：内部错误（数据库异常、解析失败）
- 排查步骤
  - 检查路由参数与校验规则
  - 查看领域服务日志与数据库事务状态
  - 验证索引是否同步、任务队列是否正常
- 定位建议
  - 在路由层打印入参与出参
  - 在服务层捕获并记录异常堆栈
  - 在数据层检查慢查询与锁等待
