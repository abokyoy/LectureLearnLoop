## 引言
本文件面向“LectureLearnLoop 成绩分析与报告系统”，聚焦以下目标：
- 解释成绩计算方法与多维度统计分析方法
- 说明考试模式下的评分规则、答题时间分析与正确率统计
- 文档化报告生成模板、数据导出与分享机制
- 提供分析报告示例与自定义指标配置
- 阐述薄弱知识点识别、改进建议与长期进步追踪

该系统以 Flask 后端为核心，结合前端页面与数据库模型，实现从练习/考试数据采集、成绩计算、知识维度分析到报告展示与导出的完整闭环。

## 项目结构
围绕成绩分析与报告相关能力，主要涉及以下模块：
- 路由层：对外暴露成绩计算、报告生成、数据导出等接口
- 视图层：渲染练习与仪表盘页面，承载交互与可视化
- 数据层：通过数据库适配器访问持久化数据，包含用户、题目、作答记录、知识点关联等
- 配置层：统一加载运行参数（如默认分数权重、时间阈值、导出格式）
- 测试层：覆盖练习循环、题目与结果样例，用于验证成绩计算与分析逻辑

## 详细组件分析

### 成绩计算引擎
- 输入：题目集合、每题分值权重、用户答案、答题时间、知识点标签
- 处理：
  - 正确性判定：逐题比对标准答案
  - 时间惩罚：超过阈值的答题时间按比例扣减
  - 权重加权：按题型/知识点权重汇总
  - 归一化：转换为百分制或等级分
- 输出：总分、各维度得分、时间效率分、知识点掌握度

```mermaid
flowchart TD
Start(["开始"]) --> Load["加载题目与权重"]
Load --> CheckAnswers{"答案是否正确？"}
CheckAnswers --> |是| ScoreBase["累加基础分"]
CheckAnswers --> |否| PenaltyTime["检查答题时间是否超时"]
PenaltyTime --> TimeOK{"是否超时？"}
TimeOK --> |是| Deduct["按超时比例扣分"]
TimeOK --> |否| KeepScore["保持基础分"]
ScoreBase --> WeightSum["按权重求和"]
Deduct --> WeightSum
KeepScore --> WeightSum
WeightSum --> Normalize["归一化为百分制/等级"]
Normalize --> Output(["输出成绩与维度分"])
```

### 考试模式评分规则
- 规则要点：
  - 每题固定分值或按权重计分
  - 超时扣分：超过设定阈值的答题时间按比例扣减
  - 漏答/错答：按题型设置不同扣分策略
  - 附加分：快速完成且全对的题目可获得奖励分
- 输出：
  - 总分与分项得分
  - 时间效率分与排名参考
  - 知识点维度得分与薄弱点提示

```mermaid
flowchart TD
Start(["进入考试模式"]) --> SetRules["加载评分规则与阈值"]
SetRules --> Submit["提交答案与时间戳"]
Submit --> Validate{"答案有效？"}
Validate --> |否| Reject["拒绝提交并提示"]
Validate --> |是| Calc["计算基础分与时间惩罚"]
Calc --> Bonus{"是否满足附加分条件？"}
Bonus --> |是| AddBonus["增加奖励分"]
Bonus --> |否| SkipBonus["跳过奖励分"]
AddBonus --> Finalize["汇总总分与维度分"]
SkipBonus --> Finalize
Finalize --> Result(["输出考试成绩与反馈"])
Reject --> End(["结束"])
Result --> End
```
