## 引言
本文件为“LectureLearnLoop 学习进度跟踪系统”的技术与产品文档，聚焦以下目标：
- 进度数据采集、统计分析与可视化展示机制
- 知识点掌握度计算、练习完成率统计和学习效率评估
- 进度数据存储结构、历史数据查询与趋势分析方法
- 进度报告生成示例与图表展示说明
- 里程碑设置、成就系统与个性化学习建议生成

该系统以服务端 Python 应用为核心，结合前端模板与静态脚本，提供知识管理、练习闭环与学习仪表盘等能力。

## 项目结构
本项目采用前后端分离的 Web 架构：
- 后端服务：Flask 应用，负责路由、业务逻辑、数据库访问与外部服务集成
- 前端页面：Jinja 模板渲染页面，配合静态 JS 进行交互与 API 调用
- 数据层：PostgreSQL（通过适配器封装）存储知识、练习、用户行为与统计数据
- 文档与测试：业务规则、测试用例与开发日志辅助理解与验证

### 知识点掌握度计算
- 输入
  - 知识点关联的练习结果集合（正确率、尝试次数、最近一次作答时间）
  - 知识点状态标记（已掌握/未掌握/复习中）
- 算法要点
  - 加权综合：正确率权重、尝试次数衰减、时间衰减因子
  - 阈值判定：达到阈值标记为“已掌握”，否则进入“复习中”
  - 平滑更新：避免单次作答导致掌握度剧烈波动
- 输出
  - 知识点掌握度分数（0-100）
  - 掌握等级（未掌握/入门/熟练/精通）
  - 建议复习间隔与优先级

```mermaid
flowchart TD
A["收集知识点练习结果"] --> B["计算基础正确率"]
B --> C["应用尝试次数衰减"]
C --> D["应用时间衰减因子"]
D --> E["加权求和得到掌握度分数"]
E --> F{"是否超过阈值?"}
F --> |是| G["标记为已掌握"]
F --> |否| H["标记为复习中"]
G --> I["输出掌握等级与建议"]
H --> I
```

### 练习完成率统计与学习效率评估
- 练习完成率
  - 分母：该知识点关联的题目总数
  - 分子：已完成且正确的题目数
  - 完成率 = 分子 / 分母 × 100%
- 学习效率评估
  - 单位时间内完成题量与正确率的综合指标
  - 考虑平均作答时长与错误重试次数
  - 与历史基线对比，识别提升或退步趋势
- 可视化
  - 折线图展示完成率随时间变化
  - 柱状图展示不同知识点完成率对比
  - 雷达图展示各维度效率评分

```mermaid
flowchart TD

K --> L["计算每题完成状态与耗时"]
L --> M["汇总完成率与平均耗时"]
M --> N["计算效率评分"]
N --> O["生成趋势与对比图表"]
```

### 里程碑设置、成就系统与个性化建议
- 里程碑
  - 条件：知识点覆盖率、练习完成率、连续学习天数

- 成就系统

- 个性化建议
  - 基于薄弱知识点推荐复习材料
  - 根据学习效率调整练习难度与间隔
